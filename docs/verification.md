# 皮影关节链路离线验证

覆盖链路：**关节角度操控 → 多关节联动 → 角色合成**，以及相同输入的重复执行稳定性。

## 运行方式

```bash
npm run verify          # 统一入口：运行全部验证并输出可读的通过/失败汇总
```

退出码 `0` 全部通过，`1` 存在失败，可直接用于 CI / 批处理。

- 仅依赖 Node.js（≥ 22.6，开发环境为 22.20）内置的 `node:test` 与 TypeScript
  类型擦除（type stripping），**不需要 `npm install`、浏览器、网络或外部账号**。
- 输入全部来自本地固定夹具（`tests/puppet/fixtures.ts`）：标准骨架定义、边界/越界
  样例表，以及 LCG 确定性伪随机序列（不使用 `Math.random`）。
- 若同时需要类型检查（需先安装 devDependencies）：`npm run check:tests`。

## 被测代码

| 文件 | 职责 |
| --- | --- |
| `src/puppet/types.ts` | 关节、部件、骨架、姿态等领域模型（与技术架构 5.1 对齐） |
| `src/puppet/joints.ts` | 角度收敛（边界/越界/非有限输入）与阻尼 0.3 的铰链积分 |

## 验证内容（36 项）

**关节角度收敛**（`tests/puppet/joints.test.ts`）
- 范围内输入原样通过；min/max 精确值不被改动。
- 逐关节覆盖：大幅低于/高于边界、`±Infinity` 一律收敛到最近边界。
- `NaN` 保持当前角度（当前值自身越界时也收敛回界内）；归一化落在 `(-180, 180]`。
- 200 个 LCG 批量输入下，收敛结果恒在合法闭区间内。
- 铰链物理：零外力角速度指数衰减至静止；恒定外力收敛到满足阻尼平衡方程的稳态；
  撞边界后停在边界、速度清零、无回弹抖动；非法 `deltaTime` 直接拒绝。

**多关节联动一致性**（`tests/puppet/linkage.test.ts`）
- mirror / ratio 联动后的从动关节角度与驱动关节严格自洽（`linkageViolations` 为零）。
- 驱动越界时先收敛驱动再传播；从动目标越界时从动停在自身边界，约束仍成立（不放宽断言）。
- 多级联动按拓扑序求值，结果与手工逐级计算一致。
- 同一关节被双约束驱动、约束成环、关节不存在、ratio 非有限等情况一律显式报错。

**合成结果与输入对应**（`tests/puppet/compose.test.ts`）
- 零角度静止姿态：全部部件坐标与手工几何计算逐分量相等（整数坐标）。
- 黄金姿态：每个部件旋转严格等于对应关节的收敛后输入；头部坐标用独立三角公式手算核对。
- ±170° 双臂关于身体竖直轴对称；父子部件在铰链世界点处精确连通（无断裂/错位）。
- 单关节变化只影响其子树部件；越界 / 非有限 / 缺失的关节角度直接拒绝合成。

**重复执行稳定性**（`tests/puppet/determinism.test.ts`）
- 同输入连续 20 次“收敛→联动→合成”，结果稳定序列化后逐字节一致。
- 铰链积分轨迹逐帧一致；收敛函数无隐藏内部状态；全量边界矩阵构成固定快照。

## 设计取舍与断言口径

- **不从众放宽容差**：角度比较用严格相等；坐标比较容差固定为 `1e-9`（仅吸收浮点误差），
  违例检查容差同样为 `1e-9`，任何实质性偏差都会失败。
- 合成层**不做隐式钳制**：越界角度直接抛错。收敛只能发生在 `convergeAngle` 这一个入口，
  保证“输入是什么、合成吃的是什么”可追溯。
- 联动冲突（多重驱动、环）选择**报错**而不是给出某种“看起来合理”的结果，避免不确定状态。

## 当前无法稳定离线验证的部分（边界与原因）

以下内容**没有**用放宽断言的方式伪造覆盖，需要后续引入相应手段：

1. **幕布剪影视觉效果**：`drop-shadow` 滤镜、灯光径向渐变、皮革纹理、半透明叠加等属于
   浏览器渲染管线结果，纯 Node 无法得到像素输出。如需验证，应引入固定视口的浏览器
   自动化（如 Playwright）做像素/布局快照对比，而不是用几何结果代替。
2. **实时操纵延迟 < 50ms**：该指标依赖真实事件循环、渲染帧率与机器负载，离线批量执行中
   不存在稳定的计时基准，强行断言会产生假阳性/假阴性。只能在固定硬件或浏览器 profiling
   条件下测量。
3. **`requestAnimationFrame` 驱动的动态行为**：帧间隔由浏览器调度，离线没有等价时钟；
   因此本验证只对**固定 `deltaTime` 的物理步进**负责（收敛规律、稳态、边界行为），
   不覆盖与真实帧率耦合的逐帧表现。
4. **Web Audio 琵琶旋律、Web Worker GIF 编码（10fps/256 色/480px）、Canvas 帧捕获**：
   依赖浏览器 API 与媒体/编码实现，Node 中不存在等价确定性环境。可用 Worker 级单测
   （输入帧序列 → 字节级产物比对）或浏览器端到端验证另行覆盖。
5. **`localStorage` 归档与 JSON 导入导出往返**：当前仓库尚无该功能的实现代码；待落地后
   可按“序列化 → 反序列化 → 再合成，姿态逐字节一致”的方式在本框架内离线覆盖。
6. **皮影路径（SVG path）本身**：目前领域模型中的部件无真实雕刻路径数据；合成验证覆盖
   的是铰链几何，不包含任意路径在旋转平移后是否自交/越出幕布，这类检查需要真实路径夹具。
