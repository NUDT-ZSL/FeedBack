# 浑天仪推演离线验证

不依赖浏览器、网络或外部星历服务，在 Node 中一次性复现并比对整条推演链路
（星体位置 → 可见性/遮挡 → 完成度统计）的全部场景。

## 运行

```bash
npm run verify
```

入口：`verify/run.ts`（编译产物在 `dist-verify/`，已加入 `.gitignore`）。
全部通过时进程退出码为 0；任一检查失败退出码为 1，输出中给出具体 **tick 与星体 id**。

## 被测对象

纯计算核心位于 `src/sim/`，渲染层与验证层共用同一实现：

| 文件 | 职责 |
| --- | --- |
| `src/sim/ephemeris.ts` | 星体位置（开普勒轨道 + 固定恒星），位置是 `(body, tick)` 的纯函数 |
| `src/sim/visibility.ts` | 地平线遮挡、星体互掩、临界相切判定，规则集中在 `VISIBILITY_POLICY` |
| `src/sim/stats.ts` | 单 tick 完成度与区间累计统计（全整数计数，仅最终一步产生浮点） |
| `src/sim/engine.ts` | `Simulation`/`TimelineCursor`，无状态快照接口 |
| `src/sim/fixtures/*` | 本地固定样例（六行星系统、地平线样例、互掩样例） |

## 场景

1. **01 重复推演确定性**：同 tick 反复推演、独立实例、整批复跑，快照逐位一致。
2. **02 回退重放一致性**：前进→回退→再前进，以及乱序进退，结果与首次到达完全一致。
3. **03 地平线遮挡**：高度角与可手算期望比对；临界（h≈0）只校验策略一致性；拱极星恒见、永隐星恒隐。
4. **04 星体互掩与临界**：重合窗口遮挡/窗口外可见；地平线下星体不得作为遮挡者；角距恰等于视半径之和时相切不遮挡。
5. **05 可见性与完成度一致性**：完成度集合恒等于可见集合；不可见星体绝不计入；区间计数与逐 tick 重算吻合。
6. **06 长程推进无漂移**：20000 tick 连续推进，整段统计 = 子段之和；重统计、游标历史均不影响结果。

## 扩展

- 新样例：在 `src/sim/fixtures/` 增加固定输入（不要引入网络数据）。
- 新场景：在 `verify/scenarios/` 增加文件，并在 `verify/run.ts` 的 `scenarios` 列表注册。
- 判定口径变更只需修改 `src/sim/visibility.ts` 中的 `VISIBILITY_POLICY`，
  渲染与验证自动共用新规则。
