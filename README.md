# 笔记线索整理（本地交互应用）

把散落在各处的零散笔记导入后，按语义相近程度自动建立关联、归纳成可回顾的主题线索，并支持手动调整，调整后只重算受影响的线索。

## 启动

```
python server.py
```

然后浏览器打开 http://127.0.0.1:8000 （端口可用环境变量 `PORT` 修改）。
无任何第三方依赖，Python 3.8+ 即可。Windows 下也可双击 `start.bat`。

## 功能与需求对应

1. **导入与自动整理**：支持 JSON 数组或 `来源 | 时间 | 内容` 行格式导入；
   内置示例数据可一键载入。导入后用 词+中文单/二元组 TF-IDF 余弦相似度
   建立关联边（阈值 0.10），连通分量即主题线索，线索主题由跨笔记共现的
   边界对齐短语自动生成。
2. **查看与手动调整**：界面展示每条线索的主题、笔记数、最近记录时间、
   关联强度；展开可看每条笔记的来源、时间和它在线索内的关联边。
   支持：移动笔记到其他线索、合并两条线索、把笔记拆出为新线索。
3. **增量重算 = 全量重算**：手动调整只对受影响线索的闭包（相似边 +
   钉住约束能传播到的笔记集合）重新聚类，闭包外的线索内容与关联完全
   不变；`test_core.py` 中断言了增量结果与 `reorganize_all()` 全量
   重整理完全一致。
4. **移动即解除旧关联**：被移动/拆出的笔记会被"钉"到目标线索，它与原
   线索成员之间的自动关联边立即失效；归属表保证每条笔记全局只属于
   一条线索，不会残留旧归属。
5. **合并保护**：合并保留双方全部笔记并重算主题；若两条线索存在重复
   归属（或合并同一条线索），返回 409/400 并明确提示、阻止操作。
6. **反馈与撤销**：每次调整后界面高亮本次受影响的线索并显示影响范围
   横幅；「撤销」可恢复最近一次手动调整（移动/合并/拆出）。

## 文件说明

- `core.py` — 语义关联与线索引擎（向量化、聚类、增量重算、撤销）
- `server.py` — 标准库 HTTP 服务与 JSON API
- `static/index.html` — 单页界面（原生 JS，无构建步骤）
- `sample_notes.json` — 17 条示例笔记（6 个潜在主题）
- `test_core.py` — 需求验收测试：`python test_core.py`

## API 一览

- `GET  /api/state` 当前全部线索与笔记
- `POST /api/import` `{notes:[...]}` 或 `{text:"来源 | 时间 | 内容\n..."}`
- `POST /api/move`  `{note_id, target}`
- `POST /api/merge` `{thread_a, thread_b}`
- `POST /api/split` `{note_id}`
- `POST /api/undo` / `POST /api/reset`
- `GET  /api/sample` 示例数据
