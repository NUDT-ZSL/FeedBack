# 字幕对齐推演工具（离线）

纯 Python 标准库实现（tkinter），无需联网、无第三方依赖。
用于把一批带时间标注的字幕片段对齐到媒体播放位置，并对推演结论给出依据。

## 运行

```
python main.py                # 载入示例项目并打开界面
python main.py project.json   # 载入指定项目
python -m unittest discover tests   # 运行测试
```

## 功能对照

1. **载入素材**：项目 JSON 含媒体信息（总时长/帧率）、锚点（确认的媒体时刻）、
   字幕片段（起止时刻/文本/来源标记/可选锚点引用）。见 `sample_project.json`。
2. **矛盾保留双方依据**：锚点偏移与上下文插值冲突、重叠、越界等均生成
   `Conflict`，双方证据存入 `evidences`，受影响片段标为「矛盾」，不静默择一。
3. **增量更新**：`update_anchor` / `resolve_conflict` 只重算受影响片段
   （沿锚点依赖链），测试保证与整体重推结果一致。
4. **异常处理**：重叠、越界、时长倒置、锚点缺失分别检测；无法判定的片段
   标为「不可信」并在依据中说明原因。
5. **偏移与漂移**：每段给出相对媒体的偏移量、相邻段漂移与累计漂移，
   列表中可直接观察漂移累积趋势。
6. **界面**：启动即显示时间轴（标尺/锚点/片段条，颜色区分状态）与片段列表；
   可拖拽或在面板中修改锚点、对矛盾做裁决，状态与依据实时刷新。

## 项目文件格式

```json
{
  "media": {"duration": 640.0, "fps": 25.0},
  "anchors": [{"id": "A1", "media_time": 12.0, "label": "片头"}],
  "segments": [{"id": "S01", "start": 10.0, "end": 14.0,
                "text": "开场白", "source": "字幕组A", "anchor_id": "A1"}]
}
```
