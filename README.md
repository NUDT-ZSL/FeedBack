# 组件变体与约束管理台

零依赖单文件离线应用,用于管理界面组件库的属性维度、变体组合与约束。

## 启动

直接双击 `index.html`(或拖入任意现代浏览器)即可使用,无需安装与网络。
数据自动保存在浏览器 localStorage,可点"重置示例数据"恢复初始示例。

## 功能

- 组件管理:多个组件,各自维护一组属性维度(如尺寸/状态/主题)与取值。
- 约束:在取值之间定义"互斥"(不能同选)与"依赖"(前者要求后者),可停用/启用/删除。
- 组合判定:顶部选择器切换取值,立即给出 有效 / 无效 / 不可信 结论及全部判定依据。
- 全部组合:枚举组件下所有组合并标注结论,支持按结论过滤。
- 增量更新:约束或取值变化时只重新评估受影响的组合,状态栏显示受影响数量。
- 不可信标记:约束指向不存在的取值,或依赖约束构成闭环时,相关组合标为"不可信"而非静默跳过。
- 多依据保留:同一组合被多条约束命中时保留全部依据,可逐条停用约束后重新收敛结论。
