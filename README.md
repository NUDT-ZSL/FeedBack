# 财务方案假设敏感性评审工具

纯本地、零依赖、离线运行的评审工具：在浏览器里维护财务方案的关键假设、分段线性响应与决策线，回答“假设推到多少会越线、越线时谁在起作用、改一条假设后哪些结论还成立”。

## 启动

- 双击 `启动.bat`，或直接用浏览器打开 `index.html`。
- 无需安装、无需网络、无需后端；全部数据为界面录入的假设与响应配置。
- 启动即进入可用界面，预置一份示例方案（收入增长率 / 毛利率 / 费用率 / 有效税率 → 净利润 / ROIC）和一条演示 `tax_rate` 冲突用于演示。

## 功能与需求对照

| # | 需求 | 实现 |
|---|------|------|
| 1 | 假设维护与校验 | 面板①登记假设：唯一标识、基准值、上下限、单位；区间非法 / 基准越界 / 标识重复均被拒绝并在表单与日志⑥中指出字段位置 |
| 2 | 分段线性响应校验 | 面板④编辑断点列；断点必须严格递增且恰好覆盖假设区间，断点缺失、重叠、越界均被拒绝并说明原因 |
| 3 | 指标求值与贡献分解 | 面板②实时显示各指标值，并按假设分解贡献，底部校验行显示“贡献合计 = 总变化 ✓” |
| 4 | 方向扰动首次越线 | 面板③设置各假设权重构成方向，扫描给出首次越线位置 t* 及该处全部假设取值 |
| 5 | 非单调 / 平台 | 扫描列出全部穿越点（含上穿/下穿/触及）、贴线平台区间、不可达区间；引擎按标识排序求解，结果与登记顺序无关（自检覆盖） |
| 6 | 冲突保留 | 同一假设/响应被不同来源给出矛盾内容时，双方均保留并在面板⑤生成可读冲突记录（假设、双方来源、各自内容），可一键“采用此来源”解决；解决前该项不参与计算 |
| 7 | 增量一致性 | 引擎按 (指标,假设) 缓存方向剖面并以版本号失效：编辑只影响相关缓存项，未受影响的区间与边界不变；自检断言“增量结果 ≡ 从头全量”且未受影响项不被重算 |
| 8 | 可操作界面 | 拖动假设滑块或修改方向权重即刷新指标、贡献分解、越线扫描与“结论对比”（相对上次修改哪些结论保持/变化）；拒绝原因即时显示 |

## 自检

- 界面右上角“运行自检”，或命令行 `node tests.js`。
- 覆盖：贡献守恒、顺序无关、增量≡全量、局部编辑不变性、非法输入拒绝、冲突保留与解决、平台/非单调全穿越点、首次越线数值正确性。

## 文件

- `engine.js` — 计算引擎（纯函数，无 DOM 依赖）
- `app.js` — 界面渲染与交互
- `tests.js` — 自检用例（node 与浏览器共用）
- `index.html` — 页面与样式（零外部依赖）
