# 配置发布推演台

离线交互工具，用于推演配置规则在多批目标上的发布与撤回。零依赖、零网络：双击 `index.html` 即可使用（需与 `engine.js` 放在同一目录）。

## 文件

- `index.html` — 交互界面（规则编辑区 / 目标清单 / 发布链路 / 批次可信度 / 生效矩阵 / 冲突裁决 / 事件日志）
- `engine.js` — 推演内核（纯逻辑，可独立测试）
- `test.js` — 内核冒烟测试：`node test.js`

## 玩法

1. 在①中填写键、值、作用范围（`env=prod,region=cn`，空=全部）、优先级、生效批次，点"加入编辑区"。
2. 规则先为草稿；点"发布"进入发布链路并获得递增版本号 v1、v2…。
3. 头部"当前时刻"是批次步进：规则只在其生效批次到达后才参与推导；目标只受生效批次 ≤ 自身批次的规则影响（先生效的先覆盖）。
4. ④矩阵给出每个目标每个键的生效值与版本；点击单元格查看全部候选与选择依据。
5. 同目标同键出现优先级+批次并列且取值不同 ⇒ 标红冲突，保留全部候选，点"裁决选定"后才确定生效值。
6. "撤回"或"改范围"只增量重推受影响目标，并在日志中报告与整体重推的一致性校验结果。
7. 某批目标未就绪、或已发布规则范围未命中任何目标/指向不存在的批次 ⇒ 该批在③中被标"不可信"并说明原因，绝不静默跳过。

## 推导规则

候选排序：优先级降序 → 生效批次升序（先生效优先）→ 版本降序。用户裁决优先于自动推导。
