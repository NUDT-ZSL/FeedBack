# 易读 · 低视力阅读排版工具

一个纯本地、零依赖的阅读排版工具：导入长文后可持续放大字号、缩窄栏宽或窗口，
正文实时重排，且当前阅读位置通过"句子级锚点"保持不变。

## 启动

```
python server.py        # 默认 http://127.0.0.1:8765/
python server.py 9000   # 指定端口
```

启动后会自动打开浏览器。也可以直接用浏览器打开 `index.html`
（「载入示例」按钮需要经过本地服务器才能工作）。

## 功能对照

1. **导入长文**：「导入文档」支持 .txt/.md 等本地文件（UTF-8，乱码时自动回退 GBK），
   正文按当前字号与栏宽连续渲染。
2. **实时重排**：字号（A-/A+ 或滑块，16–72px）、行高、栏宽、单/双栏均可调；
   `overflow-wrap: anywhere` 保证任何情况下无横向滚动、无溢出。
3. **位置保持**：视口 35% 高度处为"阅读线"，落在线上的句子被记为锚点；
   重排后该句被滚回原来的视口比例位置，不跳文首、不跳无关段落。
4. **超长段落**：正文为普通文档流，无高度裁切，特大字号下长段落可逐行滚动读完。
5. **位置标记**：左侧 ▶ 标记 + 锚点句底色高亮；工具栏实时显示"第 x / n 句"，
   重排后可确认标记仍指向同一句。
6. **稳定收敛**：连续变化经 requestAnimationFrame 合并到每帧一次；
   调整过程中锚点编号保持不变，滚动取整，结果只取决于最终参数，无累积漂移与闪烁。

## 操作

- `+` / `-`：放大 / 缩小字号
- 滚动：手动滚动停止约 120ms 后，锚点自动更新为阅读线上的句子
- 设置（字号、行高、栏宽、分栏、主题）自动保存在 localStorage

## 文件

- `index.html` / `style.css` / `app.js`：应用本体
- `server.py`：本地静态服务器
- `sample.txt`：示例长文（`gen_sample.py` 生成）
