# 生产链推演工作台

零依赖、可离线运行的本地浏览器应用。

## 启动

方式一：双击 `start.bat`，会自动打开浏览器并启动本地服务。

方式二：直接双击 `index.html`，所有脚本均为本地文件，不访问网络。

方式三：命令行运行：

```powershell
npm start
```

## 验证

```powershell
npm test
```

测试覆盖：层级需求与放大倍数、重复/非正/未知引用/成环拒绝、库存与配方冲突、最早断供、替代配方、停用配方后的增量重推与全量结果一致性。

浏览器冒烟脚本位于 `tests/browser-smoke.js`，使用本机 Chrome 验证首屏自动推演、停用配方和错误提示。
