# 运营指标异常归因分析

本地可启动的交互应用：导入按天记录的运营指标与事件记录，自动识别异常波动区段，
基于事件与指标的历史关联强度给出候选原因排序，支持人工确认 / 排除 / 调权并追踪变更历史。

## 启动

```
python app.py
```

然后浏览器打开 http://127.0.0.1:5050 。可直接点击「加载示例数据」体验完整流程，
或点击「导入本地数据」上传两个 CSV 文件。

## 数据格式

指标序列 CSV（支持中文列名 日期/指标/值）：

```
date,metric,value
2026-07-01,DAU,51230
```

事件记录 CSV：

```
event_id,date,end_date,event_type,description,metric,direction
E01,2026-07-16,2026-07-20,服务端故障,核心机房网络中断,DAU,down
```

`end_date`、`metric`、`direction` 可省略。

## 功能说明

- 异常检测：滚动中位数 + MAD 稳健 z 分数（阈值 3），连续异常点合并为区段，
  给出起止时间、峰值 z 与平均偏离百分比。
- 候选排序：按事件活跃日与非活跃日的指标偏离差计算历史关联强度，
  结合时间重叠度与登记的指标/方向信息打分；历史样本不足或方向矛盾时给出明确标记。
- 人工调整：确认、排除、权重滑杆；调整后仅重算当前区段，其余区段结果保持不变。
- 数据质量：重复上报按日均值合并、缺失日期线性插值，均在页面顶部提示，
  覆盖缺失数据的区段会单独标注其结论为估计值。
- 变更历史：每次调整记录前后排序快照，可在区段详情中对比查看。
