# 经验关联守护者

一个零依赖的本地 Web 应用，用于管理持续改写、合并或废弃的团队经验条目，并持续校验条目之间的关联是否自洽。

## 启动

```powershell
npm start
```

然后打开 <http://localhost:4173>。数据保存在浏览器 `localStorage` 中，不需要数据库。也可以运行 `npx serve .` 等任意静态服务器；不要直接双击 `index.html`，浏览器对 ES Module 的 `file://` 加载有限制。

## 已实现能力

- 浏览条目正文、标签、状态和完整修订记录。
- 基于标签 Jaccard 重合度、正文词汇/中文连续片段重合度推断潜在关联，并展示具体标签和正文线索，不只显示分数。
- 支持人工确认或否决潜在关联。确认/否决会保存当时的内容签名，未发生实质变化时稳定保持。
- 改写条目后，相关显式关联自动进入“待复核”；人工复核后可恢复有效。
- 合并条目时保留源条目和历史，建立“并入”承接关系，并把原有出边标记为需要改挂或重新确认。
- 废弃条目时同步标记失效关系；如指定承接条目，会建立替代关系。
- 同一对条目出现互斥或互指关系时，双方关系都会保留，并在冲突面板和关系图中明确提示。
- “关联影响”面板记录每次修订造成的关系状态、候选关联和冲突增删变化。
- 内置关系图展示有效、待复核、失效和冲突状态，可点击节点切换条目。

## 测试

```powershell
npm test
```

测试覆盖关联推断理由、冲突双方保留、改写复核、废弃失效、合并承接、人工确认/否决稳定性，以及语义一致的反向“替代/并入”不误报。

## 数据结构

状态是一个 JSON 对象：

- `entries`：条目，包含 `body`、`tags`、`status`、`revisions` 等。
- `links`：人工建立的显式有向/无向关系，包含关系类型、说明、建立时间和复核时间。
- `decisions`：候选关联的确认或否决记录，包含决策时的内容签名和分数基线。
- `counters`：本地新增 ID 的计数器。

关系类型包括相关、支持、细化、矛盾、被替代为、并入。候选推断默认产生“相关”，需要表达方向性或冲突时由用户建立显式关系。
