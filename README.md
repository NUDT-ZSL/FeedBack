# 在途异常处置推演台

本地离线运行，零第三方依赖（Python 3.6+ 标准库 + 原生前端）。

## 启动

```
python server.py
```

浏览器打开 http://127.0.0.1:8765 （端口可用环境变量 `DISPATCH_SIM_PORT` 修改）。

## 功能对照

- 运输单含途经节点、计划到达与实际进展；异常信号带发生时刻/类型/严重度/来源，
  可在界面右下角随时追加、修正（revises）或撤回。
- 引擎沿节点顺序推导每单 ETA 与延误，信号按显式区间 / 目的节点 / 当前进展落到节点区间。
- 同一区间出现矛盾信号（恢复 vs 异常、延误估计差异≥30 分钟）时全部来源保留并标冲突；
  未裁决前按保守口径推导，不静默择一。
- 裁决或调整响应动作只失效对应运输单，从受影响区间起增量重推；
  `test_engine.py` 验证增量结果与整体重推完全一致。
- 节点不可达（封闭/故障严重度≥4 且无有效恢复或处置）或响应超时（严重度≥4 超 SLA 未响应）
  时输出中断结论与完整依据链，下游节点不再沿用旧预计。
- 界面启动即展示运输单列表与节点时间轴，支持按状态/类型/来源/严重度筛选，
  冲突裁决、响应动作、中断依据链随操作同步刷新。

## 测试

```
python -m unittest test_engine -v
```
