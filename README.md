# 三维空间标注审查工具(离线)

纯 HTML + 原生 JS 实现,零依赖、零网络。双击 `启动.bat` 或直接用浏览器打开
`index.html` 即进入可操作界面。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `core.js` | 核心模型:对象/标注/关系、校验、变换、投影与遮挡、冲突与失效(浏览器与 Node 通用) |
| `app.js` | 界面层:Canvas 3D 渲染、相机交互、面板刷新 |
| `index.html` / `style.css` | 页面结构与样式 |
| `test.js` | 需求 1~6 的离线验收测试:`node test.js`(18 项) |
| `smoke.js` | DOM 桩冒烟测试,验证界面启动与交互路径:`node smoke.js` |
| `启动.bat` | 一键启动 |

## 需求映射

1. **对象与标注维护** — `Core.addObject / addAnnotation`:重复标识、非正尺寸、
   非法锚点、挂载不存在对象均被拒绝,日志指出具体分量与层级位置。
2. **标注关系** — `Core.addRelation`(reference 引用 / dependency 从属):
   引用不存在的标注会被拒绝并给出涉及链条;BFS 检测成环,拒绝时输出完整环链。
3. **视图推算** — `Core.computeView(state, camera, viewport)`:每条标注输出屏幕
   坐标与状态 `visible / occluded / outside / invalid`,被遮挡与视窗外均显式标记,
   视窗外标注在画布边缘以半透明标记指示,绝不静默隐藏。容器(祖先)对象不计为遮挡物。
4. **变换随动** — `Core.transformObject`:锚点存于对象局部坐标,平移/旋转/缩放后
   世界锚点与屏幕位置实时重算;引用连线同步更新;无关标注的世界锚点不变(测试 4.2)。
5. **删除与改挂** — `Core.deleteObject / reparentObject`:标注冻结删除/改挂瞬间的
   世界锚点作为证据(含局部锚点、正文、原因),状态置为"已失效",不丢弃、不挪移。
6. **多来源冲突** — 同一标注 id 被不同来源提交矛盾锚点/正文时,全部版本保留,
   生成可读冲突记录(标注、双方来源、各自锚点与正文),界面以紫色徽标与冲突面板展示。
7. **可操作界面** — 左侧对象层级树与操作区,中间 3D 视图(拖拽旋转、滚轮缩放、
   双击拾取标注),右侧标注列表(屏幕坐标 + 状态徽标)与冲突记录,底部事件日志
   (拒绝原因/冲突/失效)。所有操作立即刷新。

## 操作速览

- 左侧树中点击选中对象后,可平移(±X/Y/Z)、旋转(±15°)、缩放(1.2x/0.8x)、
  改挂父对象、删除;失效标注以红色叉线标记并保留在原证据位置。
- "新增标注"挂载到当前选中对象;"模拟另一来源矛盾提交"对选中标注注入冲突版本。
- "新增关系"输入两端标注 id 与类型;成环或引用缺失会在底部日志给出拒绝原因与链条。
