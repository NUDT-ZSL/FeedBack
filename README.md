# 多级代理转发推导系统

## 启动

```
python app.py
```

然后浏览器打开 http://127.0.0.1:5000 。

## 功能

1. 载入多级代理规则与请求记录（`sample_data.json`），按请求特征（host / path 前缀 /
   method / header）逐跳推导每跳命中的目标，给出最终落点。
2. 同一跳多条规则同时命中时，全部候选都保留在推导轨迹中，并逐条标出命中依据
   （每个条件是否满足），按优先级选择，不静默择一。
3. 某跳目标不可达或规则被撤回时，先沿该规则的备用目标回退，再沿同跳其他候选、
   再回退到上一跳重新选择；轨迹中记录每次回退事件与最终落点变化。
4. 规则 / 节点 / 请求被修改后，按依赖集做增量重推：只有受影响的请求被重新推导，
   每次修改都会与整体重推核对一致性并在页面顶部展示。
5. 规则链出现循环指向或指向缺失节点时，请求被标为"无法确定"，并给出造成中断的
   那一跳（跳数 + 节点）及全部分支的失败记录。
6. 本地交互界面：左侧为节点可达性开关与请求列表，中间为所选请求的逐跳推导过程
   （候选依据、回退路径），右侧可临时改写 / 撤回 / 新增 / 删除规则，保存后立即
   看到各请求落点变化。

## 接口

- `GET  /api/state`        全部节点、规则、请求与各请求结论摘要
- `GET  /api/trace/<id>`   单个请求的逐跳推导轨迹
- `POST /api/mutate`       修改（rule_update / rule_status / rule_add / rule_delete /
                           node_reachable / request_update），返回增量重推报告
- `POST /api/reset`        恢复示例数据
