# 多人共编协调工具（本地离线）

纯静态、零依赖的本地工具：多个编辑者并行提交对同一份共享内容的修改，系统把修改合成为一份可解释的最终内容，保留并展示冲突，支持裁决、撤回与改写后的增量重推导。

## 运行

直接用浏览器打开 `index.html` 即可（无需网络、无需服务器、无需构建）。

## 概念模型

- **片段（Segment）**：共享内容按有序片段组织（S1、S2…），每个片段有一份基础内容。
- **修改（Edit）**：每条修改包含 来源（编辑者）、发生顺序、目标片段、新内容，持续到达。
- **合成（Derive）**：每个片段独立推导——
  - 无有效修改 → 采用基础内容；
  - 所有有效修改内容一致 → 直接采用（内容相同的修改合并为一项，来源并列展示）；
  - 存在多个不同候选 → **冲突保留**，绝不静默择一，最终内容显示"冲突未解决"。
- **裁决（Resolution）**：对每处冲突可"采纳某一方"或"手动改写"，最终内容与冲突状态立即更新；裁决可撤销。若被采纳的修改之后被撤回，或冲突因撤回/改写而消失，过期裁决自动清理。
- **重推导（Rederive）**：撤回或改写某条修改时，只重新推导受影响的片段，并在界面标出"⟳ 已重新推导"（点击标记可确认消除）。工具栏的"从头校验"会对全部片段重新做全量合成并逐片段比对，证明增量结果与从头合成一致。
- **非法修改**：缺少来源或指向不存在片段的修改不参与合成，在日志中给出可读提示，并在修改记录中标红显示原因；其余内容不受影响。改写该修改使其合法后可重新纳入。

## 界面说明

- 左栏：提交/改写修改的表单 + 修改记录（撤回 / 恢复 / 改写）。
- 中栏：逐片段展示最终内容、参与来源徽标、未决冲突及候选、手动改写入口。
- 右栏：提示与日志（非法修改警告、重推导记录、校验结果）。

## 验证

`node test_engine.js` 运行 21 项引擎冒烟测试（用最小 DOM 桩加载 `app.js`），覆盖：冲突保留、双方候选、裁决、撤回后回落、受影响片段标记、非法修改隔离、跨片段改写、手动改写裁决、裁决自动清理、从头校验一致性。
