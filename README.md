# 浑仪拆装研习

三维交互可视化应用：在浏览器中模拟古代浑仪（六合仪 → 三辰仪 → 四游仪，共 7 个可拆部件）的拆解与组装。

## 运行

```bash
npm install
npm run dev
```

## 拆装状态机

所有拆装判断集中在 `src/assembly/`（纯 TypeScript，零运行时依赖）：

- `machine.ts` —— 步骤状态机：`createSession` / `applyOperation`（局部重推）/ `deriveFull`（整体重推）。
- `types.ts` —— 部件配置、操作、步骤状态、受阻原因、进度结论的类型定义。
- `armillary.ts` —— 浑仪标准 7 部件依赖配置（`detachAfter` 表达“从外到内”约束）。

口径约定：

- 进度结论只由「配置 + 各部件在位集合」决定，与操作历史无关；同一终态任意操作次序结论一致。
- 重复拆下 / 重复装回 / 未知部件为 `invalid`，不改变状态与结论。
- 依赖未满足为 `blocked` 并给出待处理部件清单；依赖成环或指向缺失部件在静态分析中标记为不可达，显式出现在步骤状态与进度结论中。
- `applyOperation` 每次只重推被操作部件及其直接前后依赖；`deriveFull` 整体重推，二者结论可逐字段比对。

UI（`src/store.ts`、组件）只向状态机发操作、读结论，不再各自维护顺序/依赖口径。

## 离线批量推演

```bash
npm run replay
```

读取 `scenarios/*.json`（部件依赖配置 + 操作序列，可声明 `expect` 期望与 `equivalentSequences` 乱序等价序列），逐步校验：

1. 每步操作后局部重推 ≡ 整体重推；
2. 无效 / 受阻操作不改变状态与结论；
3. 同一序列重放结论可复现，乱序等价序列终态结论一致；
4. 最终阶段 / 进度 / 操作统计 / 不可达部件与期望一致。

任一校验失败以非零码退出。
