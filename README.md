# 轨迹停驻/移动分段分析工具

本地运行的轨迹分析工具：把带时间戳的定位点序列切分为**停驻段**与**移动段**，
识别漂移点，标记归属不确定的区间，并支持在地图上核对与人工调整。

## 启动

```
python app.py            # 默认端口 8765，自动打开浏览器
python app.py --port 9000 --no-browser
```

或直接双击 `start.bat`。无需安装任何第三方依赖（仅 Python 3.8+ 标准库）。
启动后自动载入内置示例数据（含漂移点、长断档、低精度点、两台设备）。

## 数据格式

通过界面「载入数据文件」上传 JSON 或 CSV，记录会按时间自动排序。

- JSON：`[{"time": "2026-09-24T08:00:00", "lat": 31.23, "lon": 121.47, "acc": 15, "device": "A"}, ...]`
  - `time` 也接受 Unix 时间戳（秒或毫秒）；`acc`（精度半径，米）与 `device` 可选
- CSV：带表头，列名支持 `time/timestamp, lat/latitude, lon/lng/longitude, acc/accuracy, device`

## 判定逻辑（engine.py / segments.py / analysis.py）

- **漂移识别**：尖刺型离群点（冲出又折返、双向隐含速度超 ~200 km/h）在分析前剔除，
  地图与「漂移提示」面板中可见；精度半径 > 80 m 的点给出整体提示。
- **停驻判定**：生长式聚类，同时满足空间聚集范围（基础半径 60 m 与 2 倍精度中位数取大）
  与最短停留时长（4 分钟），不是只看相邻点距离。
- **待确认段**：相邻点间隔超过 5 分钟（疑似丢点）的区间不强行归类，
  标为「待确认」并说明原因（间隔时长、两端位移）。
- **人工调整**：可将任意段重指定为停驻/移动；相邻同类段自动合并；
  若结果不再满足判定条件会给出提示，但保留用户决定；统计面板显示相对初始结果的变化。

## 界面

左侧地图（滚轮缩放、拖拽平移、点击段选中），右侧为整体统计、漂移提示与分段列表。
点击任一段可在地图上定位；待确认段以橙色虚线和 `?` 标出。
