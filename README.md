# 补贴申请自助申报引导（离线版）

面向第一次办理复杂补贴申请的用户：按步骤回答问题，可随时回头改答；系统沿依赖关系实时判定哪些后续答案可继续沿用、哪些必须重新确认，并逐项说明依据。

## 运行

无需安装、无需联网。直接用浏览器打开 `index.html` 即可（双击或拖入浏览器）。全部逻辑为本地纯前端实现，进度自动保存在浏览器 localStorage。

```
index.html          应用入口
styles.css          界面样式
app.js              界面交互（渲染四态、影响面板、阻止提示）
engine.js           核心引擎（校验 / 依赖图 / 失效判定 / 导航阻止），浏览器与 Node 通用
flows/demo-flow.js  内置演示流程：一次性创业补贴申请
tests/engine.test.js 引擎行为测试
```

## 测试

```bash
node tests/engine.test.js
```

## 功能与需求对应

| 需求 | 实现 |
|---|---|
| 1. 步骤/问题维护，标识重复、引用不存在要拒绝并指出位置 | `FlowEngine.validateFlow()`：重复标识报出两处位置（`questions[1].id` 与首次出现处），悬空引用报出具体路径；界面“自定义流程”对话框载入时同样校验并逐条列出 |
| 2. 依赖不得成环，拒绝时给出链条 | 校验器对“问题依赖 + 步骤条件 + 步骤归属”统一建图做环检测，报错含完整链条（甲 → 乙 → 丙 → 甲） |
| 3. 改答后判定沿用 / 重新确认并说明依据 | `session.setAnswer()` 返回 `impact` 列表：每项含 `outcome`（reconfirm / deactivated / reactivated / keep）、文字依据与依赖链条 |
| 4. 重新确认保留原答案、显式标注，不影响其余 | 待重新确认项原答案保留并标黄，可“确认沿用”或修改；非直接前提的答案判定为“可继续沿用”，状态不变 |
| 5. 步骤失活保留、恢复不丢不重 | 步骤条件不满足时其下答案转为“未激活（保留）”，不计入进度；条件恢复后原样回到流程，进度数字不重复计入（有端到端测试保证） |
| 6. 阻止跳过必答 / 条件未满足前进，且不改动状态 | `next()` / `skip()` / `goToStep()` 被阻止时返回缺失问题清单、判定依据与依赖链，会话状态零改动（测试用序列化快照验证） |
| 7. 四态展示与即时更新 | 左侧步骤序列与问题卡片均呈现 已确认 / 待重新确认 / 未激活 / 未到达 四态；改答后右侧面板立即列出失效范围、判定依据与可用操作 |

## 流程定义格式

```jsonc
{
  "id": "my-flow",
  "title": "我的申报流程",
  "steps": [
    {
      "id": "s1", "title": "基本信息", "phase": "资格核验", "skippable": false,
      // 可选：步骤成立条件，不满足时整步转为未激活
      "condition": { "question": "q-type", "op": "in", "value": ["个体", "企业"] }
    }
  ],
  "questions": [
    {
      "id": "q-type", "step": "s1", "text": "申请人类型",
      "type": "choice",                 // text | number | boolean | choice
      "required": true,
      "options": [{ "value": "个人" }, { "value": "个体" }, { "value": "企业" }],
      // 可选：问题级依赖，全部满足才激活
      "dependsOn": [{ "question": "q-other", "op": "equals", "value": true }]
    }
  ]
}
```

条件表达式支持 `equals / notEquals / in / notIn / answered / notAnswered / truthy / falsy / gt / gte / lt / lte`，以及组合子 `{ "all": [...] }`、`{ "any": [...] }`、`{ "not": ... }`。

## 界面操作

- 左侧步骤序列：四种状态徽标 + 每步进度，点击已到达且激活的步骤可直接跳转。
- 中间问题区：直接作答；待重新确认的问题保留原答案并提供“确认沿用此答案”按钮。
- 右侧影响面板：每次改答后按 必须重新确认 / 转为未激活 / 恢复激活 / 可继续沿用 分组列出判定、依据与链条。
- 底部导航：上一步 / 下一步 / 跳过（仅可跳过步骤显示）/ 确认提交（最后一步）。被阻止时顶部红框列出缺失问题与依赖链，已填内容不受影响。
- 顶栏：导出 / 导入进度（JSON），载入自定义流程定义（先校验后载入），重新开始。
