# 运营实验效果比较台

离线单文件交互工具，围绕**策略变体 × 受众分组 × 观测数据**给出可解释的效果判断。

## 启动

双击 `启动.bat`，或直接用浏览器打开 `index.html`。无需联网、无需后端，数据保存在浏览器 localStorage。

## 功能对照

1. **变体与分组维护**：左栏维护受众分组（含口径定义）与多来源观测（进入/转化/观测时段）；中栏维护策略变体，勾选即建立多对多归属。
2. **冲突保留与标注**：同一分组存在多条来源观测时全部保留并标"观测冲突"，由用户"采信为权威"或"修正/作废"裁决，系统不静默择一；被多个变体共享的分组标"共享"徽标。
3. **增量重算**：裁决或修正观测后仅重算受影响变体，顶栏"增量=全量 ✓"实时校验与从头全量重算结果一致。
4. **可解释判定**：双比例 z 检验给出显著性、提升幅度与可信度（高/中/低）；样本量不足、时段不重叠、分组口径不一致分别显式标注并说明依据。
5. **基准锁定**：任一分组可锁定为基准，其余比较仅按锁定口径计算并标出"口径偏移"（样本量变化），一致性仍与全量重算对齐。
6. **即开即用**：启动即演示数据（含一处待裁决冲突、一处小样本、一处时段不重叠），可直接操作观察结论与可信度实时变化。

## 验证

`node test.js` 运行 19 项逻辑测试（冲突检测、增量=全量、三类不可比情形、基准锁定与口径偏移）。
