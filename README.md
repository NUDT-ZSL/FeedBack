# 阅读消化推演台

一个完全本地离线运行的阅读素材管理与消化状态推演工具。使用 Python 标准库、SQLite 和原生前端，不需要安装第三方依赖，也不会访问网络。

## 启动

```powershell
python run.py
```

启动后会自动打开浏览器；也可以手动访问终端中显示的地址（默认 `http://127.0.0.1:8765/`）。数据默认保存在项目根目录的 `reading.db`。

可通过环境变量指定数据库：

```powershell
$env:READING_DB="D:\notes\reading.db"; python run.py
```

## 数据与推演规则

- 素材包含标题、来源、篇幅、主题和当前推演位置。
- 动作包括：阅读推进 `read`、阅读位置核对 `checkpoint`、标记消化 `finish`、观点/备注 `note`。
- `read` 按推进量累计；`checkpoint` 显式声明位置，后续推进从该位置继续；`finish` 将位置推进到完整篇幅；`note` 不改变位置。
- 进度从 0 到完整篇幅依次推演为：未开始、进行中、已消化。
- 较早记录已到某位置，而较晚记录声明更低位置，或位置超过篇幅时，系统保留双方并生成冲突；冲突裁决前该素材结论为“冲突待裁”。
- 冲突可否定较早记录、否定较晚记录、排除单条越界误登记，或人工接受并存/提示修正篇幅。裁决依据会保留。
- 显式关系支持引用、续读、同主题；相同“主题”字段也会自动形成传播图。传播结果展示关联素材状态和路径，但不会覆盖素材自身依据。
- 新增/修正动作、裁决冲突、修改主题或关系后，只重推种子素材及其可达关联链；测试会校验结果与从全部原始记录全量重推一致。

## 验证

```powershell
python -m unittest discover -s tests -v
node --check static/app.js
```

首次启动会创建一组示例素材和一个待裁决冲突，方便立刻试用界面。删除 `reading.db` 后重启可重新生成示例数据。
