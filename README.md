# 离线协作白板：乐观操作与确定性确认

这是一个无外部依赖、可直接离线运行的本地白板。画布操作先写入本地操作日志并立即渲染；本地服务确认按修订号顺序提交，拒绝或分歧只回退失败根操作及其传递依赖，不覆盖其他分支。

## 运行

直接用浏览器打开 `index.html`，无需安装依赖或启动服务。

右侧“本地服务模拟器”可以：

- 调整 0–3 秒随机确认延迟；
- 让下一次操作被拒绝；
- 让下一次确认返回与本地预期不同的元素；
- 观察确认晚于本地连续操作时的叠加和回退。

## 核心规则

1. 添加、拖动、改色、删除先生成待确认操作并立即应用到本地视图。
2. 每个操作记录 `clientSeq` 和同一元素上的直接前置依赖；级联判定沿依赖链传递。
3. 服务确认携带修订号，乱序到达时先进入缓冲区，只按修订号连续提交。
4. 拒绝时回退根操作和所有传递依赖；分歧时保留服务端权威结果，回退本地预期和后续依赖。
5. 回退组可一键重发；重发操作基于当前权威状态重新计算基础值和依赖。
6. 每次全部确认后，状态机会把权威画布与“按确认修订顺序重放”的结果做一致性断言。

## 测试

```powershell
npm test
```

测试覆盖即时反馈、依赖链、乱序确认、拒绝级联、服务结果分歧、回退重发，以及拖拽手势期间确认返回的场景。
