# 生产链推演工作台

纯静态、可离线使用的本地生产链推演工具：维护资源与配方，按目标产出量逐级推出
各资源需求与缺口，定位断供根源；库存修正或配方停用后仅增量重推受影响资源，
并强制校验与从头全量重推完全一致。

## 启动

- 双击 `start.bat`，或直接用浏览器打开 `index.html`（无需联网、无需安装）。
- 首次打开自动载入示例数据并进入可操作的推演界面；数据保存在浏览器本地。

## 功能对照

1. 资源/配方维护：标识同来源内唯一、库存非负、用量为正，违反即拒绝并指出
   「来源 + 第几条 + 字段」。
2. 上下游依赖：引用不存在的资源或配方成环时整环拒绝，并给出涉及链条。
3. 目标推演：按目标产出逐级展开需求、库存、可产出、缺口、放大倍数与需求来源。
4. 增量重推：改库存/停用配方只重推受影响节点，结果与全量重推一致（界面右上角
   与结果区均显示校验状态，不一致时自动回退全量）。
5. 冲突：同一资源/配方被多来源给出矛盾值时双方均保留，生成可读冲突记录，
   未裁决前明确标注「临时取值」，可一键采用某来源。
6. 断供：缺口无法由库存与替代配方补齐时，标出最早断供层级与根源资源，
   缺口不会当作已满足继续下推。
7. 界面：启动即可用，展示层级、各级需求与缺口、冲突标记；任何修改立即重推
   并显示拒绝原因。

演示：点击「导入第二来源（冲突样例）」可一次看到库存冲突、配方定义冲突、
循环依赖拒绝与缺失引用拒绝。

## 结构

- `index.html` / `css/style.css` / `js/app.js`：界面
- `js/engine.js`：推演引擎（纯逻辑，浏览器与 Node 通用）
- `tests/engine.test.js`：行为测试（含增量=全量的随机模糊测试）

## 测试

```
node tests/engine.test.js
```
