# 错因模式分析工作台

本地交互应用:导入带题目、解题步骤和作答结果的记录,沿每道题的解题步骤
定位学生出错环节,归纳可解释的错因模式,并给出针对性练习建议。

## 启动

```powershell
python app.py
```

然后浏览器打开 <http://127.0.0.1:5050>。点击「载入示例数据」即可体验完整流程。

## 功能

1. **逐步作答轨迹**:每道题的解题步骤按序展示,标出学生实际走到、答对、
   出错及未走到的环节。
2. **错因模式归纳**:同一学生在多道题的相同/相近环节(按技能点+文本共性)
   出错时,自动归纳为一个错因模式,并说明覆盖的题目与步骤。
3. **候选归属与手动调整**:每条错误事件可查看候选归属模式及各自依据
   (技能点一致、步骤文本共性等),可改归其他模式或新建模式,归纳结果立即更新。
4. **增量归纳**:调整某条归属后,只有源模式和目标模式被重新归纳,
   其余模式及其覆盖范围保持不变。
5. **练习建议**:每个模式给出针对性练习建议,并注明依据的错误环节与已覆盖题目。
6. **无法定位的记录**:因步骤缺失、作答中断、步骤 id 对不上等原因无法定位
   错误环节的记录,单独列出并说明缺失位置,不强行归入任何模式。

## 导入数据格式

```json
{
  "questions": [
    {"id": "Q1", "text": "题目文本",
     "steps": [{"id": "Q1-S1", "skill": "技能点", "text": "步骤描述"}]}
  ],
  "records": [
    {"id": "R1", "student_id": "S01", "question_id": "Q1",
     "attempts": [{"step_id": "Q1-S1", "result": "correct"},
                  {"step_id": "Q1-S2", "result": "wrong", "answer": "学生答案"}]}
  ]
}
```

- `result` 取值:`correct` / `wrong`;缺失的步骤视为作答中断。
- 支持文件导入或直接粘贴 JSON,见 `sample_data.json` 示例。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/import` | 导入数据并重新归纳 |
| POST | `/api/sample` | 载入内置示例 |
| GET | `/api/state` | 当前完整状态 |
| GET | `/api/events/<eid>/candidates` | 某错误事件的候选归属及依据 |
| POST | `/api/reassign` | 调整归属 `{event_id, target}`,target 为模式 id 或 `"new"` |
