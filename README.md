# 3D 多发射源粒子系统

基于 Three.js + TypeScript 的浏览器粒子系统，支持可配置的多发射源并行工作。

## 运行

```bash
npm install
npm run dev        # 浏览器交互模式
npm run verify     # 离线批量验证（无需浏览器）
npm run build      # 类型检查 + 生产构建
```

## 架构

- `src/core/engine.ts` — 与渲染解耦的仿真核心 `ParticleEngine`：
  - 每个发射源独立配置：位置、发射方向、扩散角、发射速率、初速度、颜色区间、寿命区间
  - 粒子生成时从所属发射源的寿命/颜色区间采样，并快照全部参数（`emitterId` + `spawnId` 标识归属）
  - 发射源修改/删除只影响后续新粒子；已生成粒子按快照走完生命周期
  - 全局粒子上限按各发射源速率比例分配配额，饱和时记录可观察的 `dropped` 计数
- `src/ParticleSystem.ts` — 渲染层，包装引擎并维护 GPU 缓冲区、拖尾、发射源网格
- `src/controls.ts` — lil-gui 控制面板：全局参数、发射源增删改、每发射源 存活/配额/丢弃 实时统计
- `verify/run.ts` — 离线批量验证（`npm run verify`），覆盖：
  1. 多发射源并行与同位置发射源的粒子归属
  2. 参数中途修改不追溯改写已生成粒子
  3. 发射源删除后孤儿粒子走完生命周期
  4. 全局上限下按配额比例分配、新发射源不被静默饿死
  5. 同帧参数修改与粒子消亡的一致性（无归属错乱、无颜色跳变）
