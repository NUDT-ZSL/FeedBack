# 本地复习规划工具

完全在本机运行的间隔重复复习工具：不依赖任何在线服务，
学习记录保存在同目录的 `data.json` 中。

## 启动

    python app.py

或双击 `启动复习工具.bat`。启动后浏览器会自动打开复习界面
（http://127.0.0.1:8765），按 Ctrl+C 停止服务。

## 功能

- **导入 / 新增**：批量粘贴 JSON 数组（含 title、content、mastery、
  importance、last_review），或手动逐条新增；格式错误会逐条提示。
- **今日复习**：按遗忘曲线 R(t)=exp(-t/S) 估计每条内容的记忆保持率，
  到期条目按「重要度 × 遗忘程度」排序生成今日队列。
- **作答反馈**：答对/答错后更新掌握度与复习间隔，并逐条说明调整原因；
  连续答对会加速间隔增长，连续答错会更快压缩间隔。
- **条目管理**：手动修改掌握度、重要度、上次复习时间或间隔后，
  仅重新推导该条目的安排，其他条目不受影响。

## 文件

- `srs.py` — 遗忘曲线与调度核心逻辑
- `app.py` — 本地 HTTP 服务与数据持久化（仅用 Python 标准库）
- `static/index.html` — 复习界面
- `test_srs.py` — 单元测试（`python test_srs.py`）
- `data.json` — 本机学习记录（首次使用时自动创建）
