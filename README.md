# 本地多维切片探索台

这是一个零依赖的纯浏览器模块，适合对一份已导入的明细数据做反复切片、标记发现和追溯结论。

## 使用

直接用浏览器打开 `index.html`。页面启动时会载入内置示例数据；点击“导入 CSV”可选择本机明细文件。

CSV 要求：

- 第一行是字段名；
- 文本列默认可作为维度；
- 数值列默认可作为度量，也可以改成维度；
- 支持双引号包裹逗号、换行和连续双引号；
- 文件不会上传，所有解析和保存都发生在当前浏览器内。

## 功能

- 自由调整字段角色、参与切片的维度、度量字段和聚合方式；
- 支持文本枚举筛选和数值范围筛选；
- 样本数低于阈值的聚合单元格会用斜纹和“不可信”标出；
- 标记发现时会固化维度组合、维度取值、筛选、聚合口径、阈值、样本数和当时结果；
- 条件改变后，发现会标记为“条件已变更”或“已失效”；
- 发现可引用更早发现，并沿依赖链向上查看；
- 引用的上游被删除或永久移除后，下游会标出断链并保留原引用标题和 ID；
- 发现记录保存在当前浏览器的 `localStorage` 中。

发现与具体数据内容的指纹绑定。重新导入不同数据后，旧发现不会静默沿用，而会明确标记为数据集不一致。
