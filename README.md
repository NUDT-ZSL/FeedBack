# 区域仓网调拨工作台

这是一个零安装、零第三方依赖的本地交互式仓网调拨工作台。核心算法位于 `js/engine.js`，界面位于 `index.html`，所有数据默认只保存在当前浏览器的 `localStorage` 中。

## 启动

任选一种方式：

- Windows 双击 `start.bat`，或在 PowerShell 中运行 `./start.ps1`。
- 直接双击 `index.html` 也可运行；如浏览器限制本地文件，再使用本地服务方式。
- 手动执行：`python -m http.server 8765`，然后访问 `http://127.0.0.1:8765/index.html`。

## 功能

- 维护多地点当前存量、在途、安全库存和未来需求，并可直接编辑、新增、删除地点。
- 自动计算 `可用量 = 当前存量 + 在途` 和 `目标量 = 未来需求 + 安全库存`。
- 自动识别实际缺货、低于安全库存和可调出余量，并列出候选支援地点。
- 维护线路距离、单位运费和调拨时效；单位综合代价为：
  `单位运费 + 距离 × 每公里每件成本 + 时效 × 每天每件时效成本`。
- 使用最小费用流生成调拨路径和建议数量，在满足高优先级缺口的前提下降低总代价。
- P1“实际缺货”优先于 P2“低于安全库存”；同级按缺口率、绝对缺口和地点 ID 稳定排序。
- 资源不足、线路不通或线路超出计划窗口时给出明确提示及取舍说明。
- 任一输入变化后立即重算，变化行、字段和 KPI 会高亮。
- 支持导出完整输入/结果 JSON，以及打印或另存 PDF。

## 验证

```powershell
node --check js/engine.js
node --check js/app.js
node --test tests
```

`tests/engine.test.cjs` 覆盖低成本路径、优先级、余量不足和无线路场景；`tests/browser-harness.html` 用于在真实浏览器 DOM 中验证编辑后立即重算与高亮。

## 文件

- `index.html`：工作台页面结构。
- `css/styles.css`：响应式界面和高亮样式。
- `js/engine.js`：供需归一化、优先级和最小费用流引擎。
- `js/app.js`：本地状态、界面渲染、交互、持久化与导出。
- `tests/`：Node 断言测试和浏览器回归测试页。
