# 学习路径推演台

本地离线交互应用：根据学习者作答记录与知识点前置依赖图谱，推演每个学习者的学习路径与排期。

## 启动

- 直接双击 `index.html`（或 `启动.bat`），无需联网、无需安装依赖；
- 或运行 `python start.py`，自动在本地端口打开。

## 功能对照

1. **图谱校验**：启动即检测依赖环（Tarjan SCC）与指向缺失知识点的依赖，
   受影响知识点及其全部后继的路径结论标为「不可信」（红色），不进入学习路径。
2. **矛盾裁决**：同一学习者同一知识点的作答先按时刻排序、去除完全重复；
   「未掌握→掌握」视为正常进步取最新，「掌握后又未掌握」或同时刻不一致视为矛盾，
   双方来源全部保留在右侧「矛盾裁决」面板，裁决前该知识点不参与推演。
3. **掌握传播与路径**：掌握某知识点会沿依赖向前推断其全部前置已掌握；
   在可信子图上做拓扑排序得到可执行学习顺序，前置未掌握的知识点标为「未解锁」并列出缺哪些前置。
4. **增量重推**：裁决矛盾或点击图谱节点调整掌握判定后，仅重推受影响子集
   （该知识点的祖先与后继），日志中给出重推范围及「与整体重推一致 ✓」的校验结果。
5. **节奏参数**：调整「每日可投入分钟数 / 最短停留天数」后重新排期，
   日志逐条说明哪些知识点前移或后移了多少天。
6. **界面**：左栏学习者列表与节奏参数，中间知识点图谱（点击节点可调整判定），
   右栏矛盾裁决与学习路径排期，切换学习者即时刷新。

## 自测

```
node test.js
```

覆盖图谱校验、记录去重/排序/矛盾识别、掌握传播、解锁条件、
增量重推一致性、排期对比等 17 项断言。

## 文件说明

- `data.js`：内置示例数据（含故意构造的依赖环 KP11↔KP12、缺失依赖 KP13→KP99、
  重复/倒序/矛盾作答记录），替换为真实数据即可复用全部逻辑。
- `engine.js` / `derive.js` / `schedule.js`：图谱校验、路径推导、排期等纯逻辑。
- `app.js` / `ui.js` / `panels.js`：状态管理与界面渲染。
