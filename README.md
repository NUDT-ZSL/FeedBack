# 到货波动与替代链影响分析（离线单页应用）

## 启动

无需安装、无需服务器、无需联网：

- 双击 `start.bat`，或直接用浏览器打开 `index.html`。

启动后即呈现三个可操作视图：① 物料清单（来源/到货量）② 替代关系与路径裁决 ③ 成品配方与产出结论，底部为重推日志。内置示例数据，也可通过"导入 JSON"替换为自己的物料清单、替代关系与配方。

## 数据模型

```json
{
  "materials": [{"id": "M-ST-A", "name": "钢材A", "source": "供应商甲", "arrival": 100}],
  "subs":      [{"from": "M-ST-A", "to": "M-ST-B"}],
  "products":  [{"id": "P1", "name": "机箱", "minOutput": 40,
                 "ingredients": [{"material": "M-ST-A", "qty": 2}]}],
  "decisions": {"M-ST-A": "M-ST-B"}
}
```

`subs` 中 `from → to` 表示 from 可用 to 替代；有效供给 = 沿裁决后的替代链上各物料到货量之和。`decisions` 记录用户对多分支替代链的裁决。

## 需求对应

1. **输入**：界面直接编辑物料（来源/到货量）、替代关系、成品配方（用量/最低产出），或整体导入 JSON。
2. **推导与缺口归属**：每个成品逐项配料核对"需求量 vs 有效供给"，缺口精确到物料并展示所沿替代链（`engine.js` 的 `analyzeProduct`）。
3. **环 / 悬空指向**：`structuralCheck` 对可达替代子图做 DFS，发现替代环或指向不存在物料的边时，所有受影响成品标记为"不可信"并列出问题明细，绝不静默跳过。
4. **增量重推**：到货量修正、替代关系增删、裁决变更时，`incrementalAnalysis` 只重推依赖受影响物料的成品（日志区可见"仅重推受影响成品：…"）；`test_engine.js` 用 30×60 组随机变更验证增量结果与整体重推完全一致。
5. **多路径裁决**：同一物料有多条替代路径时，成品结论为"待裁决"，裁决面板保留每条路径的依据（路径组成、合计供给），用户选择后相关成品结论立即更新。
6. **即时反馈**：所有编辑即时触发增量重推并重绘，缺口、可满足产出、状态徽标同步变化。

## 文件

| 文件 | 说明 |
| --- | --- |
| `engine.js` | 纯推导引擎（浏览器/Node 通用） |
| `app.js` / `index.html` / `styles.css` | 单页界面 |
| `test_engine.js` | 引擎测试：`node test_engine.js` |
| `test_ui_smoke.js` | 界面渲染冒烟测试：`node test_ui_smoke.js` |
| `start.bat` | 一键启动 |

界面上的"注入异常演示"按钮会向示例数据加入一个替代环和一个悬空指向，便于验证"不可信"标记行为。
