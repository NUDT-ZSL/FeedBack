# 减排计划偏差校准台

一个无构建、无第三方依赖、可本地离线运行的交互工具。直接打开 `index.html`，或在本目录运行：

```powershell
npx http-server -p 8080
```

## 数据结构

```json
{
  "periods": ["2024H1", "2024H2"],
  "phases": [
    {
      "id": "P1",
      "name": "设备能效提升",
      "target": 1200,
      "startPeriod": "2024H1",
      "endPeriod": "2024H2",
      "prerequisites": []
    }
  ],
  "measures": [
    {
      "id": "M1",
      "name": "高效电机替换",
      "phaseId": "P1",
      "planned": 700,
      "actuals": { "2024H1": 320, "2024H2": 390 }
    }
  ]
}
```

`actuals` 按考核期保存增量实际减排量。阶段的累计结果为该阶段及其所有前置阶段的目标和实际结果之和，并通过前置链去重，避免分支汇合时重复计数。

## 结论口径

- 未到阶段起始期：`pending`
- 已开始且未到结束期：累计偏差非负为 `on_track`，否则为 `at_risk`
- 已到结束期：累计偏差非负为 `achieved`，否则为 `behind`
- 未达标缺口为 `max(0, 累计目标 - 累计实际)`
- 偏差来源按阶段拆分，展示每个来源阶段对目标和措施计划的偏差

## 异常和不可信传播

工具会显式标出以下问题，并将相关阶段及其下游结论标记为不可信：

- 前置阶段缺失或前置关系形成闭环
- 阶段 id 重复、目标无效、起止考核期缺失或倒置
- 措施缺少有效归属阶段、计划值无效、实际值不是有限数字
- 同一措施 id 被归到多个阶段

窗口外的实际结果会作为警告列出，不计入对应阶段累计。

## 增量重推

- 调整阶段目标：重推该阶段及所有依赖它的下游阶段
- 修正措施结果：重推措施归属阶段及其下游
- 排除或恢复措施：重推对应归属阶段及其下游
- 锁定结论：只替换当前阶段展示结论；不篡改实际/目标，也不会改变其他阶段

界面提供“每次更新后对照完整重推”开关。测试还会比较所有考核期的增量结果与新建引擎完整重推结果。
