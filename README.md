# 位置对象范围推演系统

## 启动

```
python server.py
```

然后访问 http://127.0.0.1:8000 ，启动后直接进入可操作界面（自动载入示例数据）。
仅依赖 Python 3.6+ 标准库，无需安装第三方包。

## 功能

- **导入**：位置对象（坐标、类别、有效期、来源说明）与范围查找请求（圆形/矩形范围、
  类别过滤、有效时点、期望依据）。示例数据见 `sample_data.json`，也可通过
  `POST /api/import` 导入（`mode` 支持 `merge` / `replace`）。
- **冲突保留**：坐标缺失、坐标越界、多来源坐标/类别/有效期互相矛盾时，系统保留全部
  来源并标记不可信；未裁决的不可信对象不参与邻近排序，而是列入“无法判定/待裁决”。
- **查找结论**：每个查找给出命中（按到参考点距离排序）、排除、无法判定三类清单，
  每个对象都附带被纳入或排除的逐条判定依据。
- **增量重推**：对象被修正（补录来源）、撤回或人工裁决后，只重推结论实际受影响的
  查找（界面顶部会显示本次受影响清单），并随时可用“校验一致性”按钮验证
  增量结果与整体重推完全一致。
- **歧义标记**：范围边界重叠（含共同命中对象）、对象恰好落在边界上、类别过滤与
  有效期/类别来源冲突、距离并列等情况都会明确标出并附可追溯说明。
- **界面操作**：左侧态势图可拖动选中范围调整位置、点击对象查看详情；右侧可查看
  命中与邻近结果、逐条依据，并对矛盾字段选择采信来源或录入裁决值。

## 测试

```
python tests.py
```

覆盖冲突保留、判定依据、歧义标记、裁决/撤回/修正后的增量更新与整体重推一致性。

## 文件说明

- `engine.py` — 推演引擎：来源主张、冲突检测、范围评估、增量更新、一致性校验
- `server.py` — HTTP 服务（静态页面 + JSON API）
- `static/` — 单页操作界面
- `sample_data.json` — 覆盖各类冲突场景的示例数据
- `tests.py` — 引擎行为测试
