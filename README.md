# AutoDemo 空间剖切与测量工作台

一个零运行时依赖、可离线使用的浏览器工作台，用于建筑与机械混合场景的空间对象层级维护、有向包围盒（OBB）剖切、距离测量、遮挡判定与多来源冲突保留。

## 启动

直接双击打开 `index.html` 即可使用，不需要联网、构建步骤或外部 CDN。

如需用本地 HTTP 方式访问：

```powershell
npm start
# 打开 http://localhost:8765/
```

## 验证

```powershell
npm test              # Node 原生核心测试
npm run test:browser  # 使用本机 Chrome 的真实页面冒烟测试
```

核心测试覆盖：

- 同来源重复 ID、非正尺寸的拒绝位置。
- 缺失父对象链条与父子成环链条。
- 旋转 OBB 的截面轮廓、面积和重复求解确定性。
- 两对象最近距离、遮挡物、首段可见距离、跨剖切面标记。
- 多来源矛盾变换/尺寸双方保留、来源采用切换。
- 对象局部变换修改后，增量结果与 `Workbench.deriveFull` 从零全量推导深比较一致。

## 数据模型

一个来源包含名称和对象数组：

```json
{
  "name": "CAD-导出",
  "objects": [
    {
      "id": "PUMP-01",
      "parentId": "SKID-01",
      "position": [1.2, 0, 0.5],
      "rotationEuler": [0, 0, 30],
      "size": [1.2, 0.9, 1.0]
    }
  ]
}
```

字段口径：

- `id`：同一来源内唯一；跨来源相同 ID 表示同一对象的多个来源。
- `parentId`：父对象 ID；为空表示根对象。父子关系必须构成森林，不允许成环。
- `position`：相对父对象的局部平移，单位按项目统一（示例按米）。
- `rotationEuler`：局部 XYZ 欧拉角，单位为度。
- `size`：局部包围尺寸，三个值都必须严格大于 0。

非法整批数据会被拒绝，不会半写入模型。拒绝信息包含来源、记录序号、对象 ID 和可读链条。

## 剖切与测量口径

- 对象以局部 TRS 层级合成世界 OBB。
- 剖切面为 `normal · p = offset`，法向会自动归一化。
- 只有严格切开实体才生成截面；平面仅与顶点/边/面相切时不生成截面。
- 截面是平面与 OBB 12 条边交点构成的有序凸多边形，并同时输出世界坐标和对象局部坐标。
- 对象间距离是两个 OBB 的最近点距离；点到对象取点与 OBB 的最近点。
- 测量线段穿过其他对象内部时标记为“被遮挡”，给出几何距离、从起点到第一个遮挡物的首段可见距离、遮挡物和入/出点。
- 线段跨越当前剖切面时保留距离，但单独标记“跨剖切面”，提示审图人员结合截面复核。

## 增量重算

- 修改对象时收集该对象、旧父链和完整子孙闭包，只重算受影响世界变换。
- 截面只重新计算受影响对象，并通过包含平面、中心、轴向、半尺寸的稳定签名跳过未变结果。
- 测量根据引用关系、旧/新 OBB 与测量线段的包围盒相交情况收集脏项；平面移动只重算跨越旧/新平面的测量。
- `Workbench.deriveFull(...)` 用同一套纯几何函数进行从零推导，测试中深比较截面和测量结果，保证增量结果不是近似或另一套口径。

## 多来源冲突

同一对象由不同来源给出矛盾的父级、平移、欧拉角或尺寸时：

- 两个来源的原始记录都保留。
- 生成可读冲突记录，列出对象、双方来源、记录序号和各自取值。
- 默认按来源名和记录序号稳定选择一方参与几何求解。
- 可在左侧冲突面板切换采用值；未采用的一方仍可查回。

## 文件结构

- `index.html`：工作台界面。
- `styles.css`：界面样式。
- `js/core.js`：校验、层级、世界变换、截面、距离、遮挡、冲突与增量引擎。
- `js/app.js`：Canvas 三维正交视图和浏览器交互。
- `js/data.js`：内置建筑/机械混合示例。
- `tests/core.test.js`：核心自动化测试。
- `tests/browser-smoke.js`：真实浏览器交互冒烟测试。
