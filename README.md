# AutoDemo 离线分段接收与转换

这是一个零第三方依赖的纯本地静态应用。直接用现代浏览器打开 `index.html` 即可运行；页面没有外部脚本、字体、图片或网络接口。

## 功能

- 添加一个或多个本地文件并设置分段大小，按顺序接收分段。
- 每个分段独立显示等待、接收中、已接收、失败、冲突和转换中状态。
- 接收失败只重试失败分段；已成功分段和转换结果不会被清空。
- 所有接收字节、哈希、冲突双方和转换 checkpoint 都写入 IndexedDB。
- 转换在 Web Worker 中运行，中断或关闭页面后从下一段继续。
- 重新读取的分段与原哈希不一致时保留新旧双方，标出字节差异范围，由用户选择保留原分段或采用新分段。
- 裁决只删除受影响分段及其后续转换结果，更早分段保持不动；恢复后的最终指纹与整体重推一致。
- 可导出 JSON 接收/冲突/转换报告，并按原顺序重组下载转换产物。

## 使用

1. 打开 `index.html`。
2. 选择文件并设置分段大小（字节，默认 65536；大于 64 KiB 的文件最小使用 65536 字节，避免分段过多）。
3. 在某一行勾选“下一次失败”，即可只模拟该分段的一次接收失败。
4. 失败后点击“只重试此段”或“只重试失败分段”。
5. 转换时可点“中断转换”，随后从检查点继续。
6. 对已接收分段点击“模拟内容变化”可生成本地冲突候选；也可在外部修改同名同大小文件后点“重新读取比对”。
7. 冲突面板会显示字节范围和双方哈希，裁决后只重算受影响的转换尾部。

浏览器安全模型不允许网页在刷新后持久保存本机文件句柄。刷新后，IndexedDB 中的已接收分段仍存在；如需继续未完成接收或重新比对源文件，请点击“重新选择源文件”。

## 转换与一致性

演示转换对每个字节执行确定性的 XOR `0x5A`，并对转换后的分段计算 SHA-256。最终指纹是带文件大小、分段数、分段序号和分段哈希的滚动 SHA-256：

```text
a0 = SHA256(version,fileSize,chunkCount)
an+1 = SHA256(an,index,chunkHash,transformedLength)
```

每个 `an` 都是可恢复 checkpoint。采用冲突新分段时，系统加载该分段之前的 `an`，删除该分段及之后的转换产物，再从该分段继续；因此结果与从头全量转换相同，但已确认的较早分段不重读、不重算。
