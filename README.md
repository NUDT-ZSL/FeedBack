# 批注锚点重映射系统

根据编辑操作序列（插入/删除/替换）将批注锚定区间映射到最新文档版本，
并维护三种状态：已解决、待确认、失效。

## 结构

- `anchors.py` — 核心引擎。每条批注内部跟踪其锚定文本中每个原始字符的
  当前位置集合；区间由存活字符的 min/max 派生。这保证任意多次编辑叠加后，
  映射结果与"对初始文档直接应用全部编辑"完全一致（需求 6）。
- `app.py` — Flask 后端，内置一个示例场景（初始文档 + 3 条批注）。
- `static/` — 前端界面：最新文档高亮、批注列表、保留/删除操作、追加编辑。
- `test_anchors.py` — 单元测试 + 300 组随机编辑序列的模糊测试。
- `ui_smoke.py` — Playwright 界面冒烟测试。

## 状态规则

- 锚定文本被完全删除（含被整体替换）→ 失效，不再高亮。
- 锚定区间被部分修改但仍有重叠文本 → 待确认，高亮存活的重叠文本。
- 未受影响或用户在界面上点击"保留"→ 已解决；点击"删除"则移除批注。

## 运行

```
python app.py            # http://127.0.0.1:5071 (PORT 环境变量可改端口)
python -m unittest test_anchors -v
python ui_smoke.py       # 需要 playwright 及 chromium
```
