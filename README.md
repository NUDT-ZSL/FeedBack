# 经验条目关联管理系统

面向团队经验沉淀的关联管理工具：条目会被持续改写、合并、废弃，系统负责
推断潜在关联、给出可读理由、在修订后同步关联状态、暴露冲突并保留人工裁决。

## 启动

```
python server.py        # 默认 8000 端口，可 python server.py 8017 指定
```

或双击 `start.bat`。浏览器打开 http://127.0.0.1:8000 即可操作。
首次启动从 `seed_data.json` 载入示例数据并写入 `data.json`，之后所有修改
持久化在 `data.json`；界面右上角“重置数据”可恢复种子状态。

## 功能与需求对应

1. **条目模型**：每条经验含正文、标签、指向其他条目的关联（关联/依赖/取代/矛盾）
   和按时间排列的修订记录，条目间可互相引用。
2. **关联推断**：`engine.infer_between` 依据共同标签与正文共同线索（共同英文词 +
   极大公共中文片段）推断潜在关联，理由以“共同标签：…；正文共同线索：…”呈现。
3. **修订同步**：改写/合并/废弃后自动同步受影响关联——推断依据消失的标记
   “已失效”，目标被废弃/合并或正文实质变化的标记“待重新确认”。
4. **冲突保留**：双向关联关系互相矛盾（如互相“取代”）时双方均标记“冲突”
   并保留，界面顶部出现冲突横幅，绝不静默丢弃。
5. **人工裁决稳定**：确认/否决结果在后续修订中保持不变；仅当相关正文发生
   实质变化（相似度低于阈值）时，已确认关联转为“待重新确认”。被否决的
   推断不会在后续修订中复活。
6. **可操作界面**：左侧条目列表与变更动态，右侧条目详情、关联卡片（含理由
   与确认/否决按钮）、修订时间线，支持新建、修订、合并、废弃。

## 验证

```
python test_engine.py    # 11 项引擎单元测试
python verify_api.py     # 端到端 API 验证（需服务器运行在 8017 端口）
```

## 文件

- `engine.py` 关联引擎：推断、修订同步、冲突检测、合并/废弃传播
- `server.py` 标准库 HTTP 服务与 REST API，数据落盘 `data.json`
- `static/` 单页界面（无构建、无外部依赖）
- `seed_data.json` 示例数据（含一对互相“取代”的冲突样例）
