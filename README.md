# 资产价值周期推演工具

本地离线运行的单页应用：维护资产及其价值调整动作，沿使用周期逐月推导账面价值，
计算处置损益，并标出依据不足或相互矛盾的数据。零依赖、无需联网、无需安装。

## 运行

直接用浏览器打开 `index.html` 即可（推荐 Edge / Chrome）。
数据自动保存在浏览器 localStorage，可用“导出 / 导入 JSON”备份或迁移。

## 功能与需求对照

1. **录入与修改**：左侧资产列表 + 基本信息表单；每项资产可添加任意条价值调整
   （发生时刻、类型：减值 / 增值 / 重估、金额、备注），可勾选“待核实”，
   可修改、排除或删除。
2. **逐期推导**：以月为最小期间直线折旧（不低于残值）；调整在发生当月期初生效，
   之后按剩余期间重算折旧。逐期推导表区分“当期折旧”与“价值调整”两列。
3. **冲突保留**：同一资产同一时点出现 ≥2 条未排除调整时，全部来源保留、
   同时参与推导，曲线与表格均红色标记，绝不静默择一。
4. **增量重推**：任何修改只重推受影响资产；顶栏“一致性”徽标实时比对
   增量结果与整体重推结果（`node test.js` 第 5 组测试证明二者逐字节一致）。
5. **可信度标记**：缺启用时刻 / 年限 / 残值，或调整导致账面价值 <0 / 超过成本，
   结论标为“不可信”并逐条说明原因。
6. **可视化**：SVG 价值曲线（调整菱形标记、冲突红圈、待核实虚线框、残值虚线、
   处置竖线）+ 调整明细表 + 逐期推导表；裁决（排除 / 删除 / 修改）后
   曲线与处置损益立即刷新。

## 推导规则

- 期间：自启用时刻起共 `使用年限 × 12` 个月；设定处置时刻则截断至处置当月。
- 每月期初先应用当月全部未排除调整（重估 = 设为指定价值，减值 = 减，增值 = 加），
  再按 `(当前价值 - 残值) / 剩余月数` 计提折旧。
- 处置损益 = 处置收入 - 处置当月期末账面价值。
- 被“排除”的调整保留记录但不参与推导，也不构成冲突。

## 文件结构

- `index.html` / `style.css` / `app.js` — 界面与交互
- `engine.js` — 纯函数推导引擎（浏览器与 Node 通用）
- `test.js` — 引擎行为测试：`node test.js`
- `test-ui.js` — 界面链路冒烟测试（迷你 DOM 桩）：`node test-ui.js`
