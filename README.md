# 物料循环去向推演工具

本地离线运行，无第三方依赖（仅需 Python 3.6+）。

## 启动

双击 `启动.bat`，或执行：

```
python server.py
```

启动后自动打开 http://127.0.0.1:8765/ ，界面中可直接登记批次与流转记录、
处理冲突、修正记录，去向与损耗结论即时更新。数据保存在 `data/store.json`。

## 功能对应

- 批次投入/来源/初始去向登记，沿转出链路推导各去向累计量与损耗。
- 同批次同时刻多条矛盾记录全部保留并标出冲突，不静默择一。
- 冲突裁决与记录修正只重推受影响批次链路（增量），
  界面实时显示“增量与全量一致”校验结果，也可点“一致性校验”复核。
- 转出指向不存在批次（前置缺失）或形成循环引用时标记链路异常并说明原因。
- 去向闭合校验：投入 = 回收 + 再利用 + 损耗 + 转出 + 未闭合差额，
  差额逐批次给出计算依据。
- 修正与裁决均保留原始记录与沿革（superseded / rejected），可追溯。
