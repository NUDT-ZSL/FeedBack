# 媒体素材生产档期编排（离线交互应用）

直接双击 `index.html` 即可在浏览器中离线使用，无需任何服务或依赖。

## 功能

- **示例数据**：打开页面自动加载 16 个任务的示例（素材来源 / 工序 / 耗时 / 可用通道 / 前置依赖），立即展示甘特图编排结果；也可通过「导入本地JSON」加载同格式文件（见 `sample-data.json`）。
- **排程推导**：沿前置依赖推导最早可开始时刻，再按通道占用串行排布；因通道争抢或等待前置而顺延的任务会以徽标和金框标出。
- **增量重推**：在右侧编辑任务的耗时、通道或前置依赖后点击「应用修改」，仅受影响（依赖下游 + 相关通道时间段）的任务重新推导；顶栏显示本次重推项数，并自动与整体重排比对（一致 ✓ 徽标），极端情况下自动回退整体重排保证结果正确。
- **异常检测**：点击「注入异常示例」可看到缺失前置、依赖闭环的任务被标为不可排期并给出原因，不会被静默跳过或强行安排。
- **约束**：在任务详情中勾选「锁定档期」可将任务固定在某个开始时刻；右上方可排除某条通道；顶栏实时显示整体完工时刻的顺延变化和排布变化项数。
- **排布依据**：点击任意任务，右侧展示其等待的前置及完成时刻、占用的通道区间、最早可开始时刻与具体顺延原因。
