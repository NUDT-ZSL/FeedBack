# 地理围栏推演工具

本地可启动的地理围栏规则验证工具：在地图上绘制多边形围栏并配置规则，
导入带时间戳的轨迹点后，按时间顺序推演进入 / 离开 / 停留超时 / 超速事件，
并在时间轴上展示事件序列与触发依据。

## 启动

- 双击 `start.bat`，或执行 `python server.py`（仅依赖 Python 标准库，无需联网）。
- 浏览器自动打开 `http://127.0.0.1:8000/`。

## 功能

1. **围栏绘制与编辑**：工具栏「绘制围栏」单击加点、双击/回车完成；
   「平移/编辑」模式下点击围栏选中，拖动顶点修改形状；每个围栏可配置
   进入、离开、停留超时、超速规则及阈值、优先级、最小停留/离开确认时长。
2. **轨迹推演**：粘贴 CSV（`time,lat,lng`）或 JSON 数组，或选择文件导入；
   系统按时间排序逐点判定所属围栏并生成事件。
3. **防抖过滤**：进入需持续在围栏内 ≥ 最小停留确认时长、离开需持续在外
   ≥ 最小离开确认时长才触发，边界抖动与短暂穿越被自动过滤。
4. **冲突消解**：同一时刻多个围栏/规则产生候选事件时，按围栏优先级
   （数值小者优先）与规则类型顺序保留唯一事件，其余在时间轴中标注为
   「被压制的候选事件」并注明原因。
5. **实时重推演**：调整围栏形状、规则阈值或重新导入轨迹后自动重新推演，
   时间轴与地图事件标记同步更新；点击事件可定位到触发位置查看判定依据。
6. **无效点处理**：缺少时间戳或坐标非法的点被跳过，在左侧面板逐条列出
   原因，不影响其余点的推演。
