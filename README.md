# 语义树无障碍工作台

这是一个完全本地运行的离线工具，帮助无障碍工程师整理界面元素的父子关系、语义角色和屏幕阅读器朗读顺序。

## 启动

方式一：双击 `start.bat`，工具会启动本机服务并打开浏览器。

方式二：在当前目录运行：

```powershell
npm start
```

然后访问 `http://127.0.0.1:4173`。也可以直接双击 `index.html` 使用；本地服务模式可避免个别浏览器对 `file://` 存储的限制。

## 数据格式

批量录入支持元素数组：

```json
[
  {
    "id": "dialog-1",
    "role": "dialog",
    "name": "账户设置",
    "parentId": null,
    "order": 1,
    "hidden": false
  }
]
```

字段说明：

- `id`：当前元素的唯一标识。
- `role`：语义角色，例如 `button`、`textbox`、`tabpanel`。
- `name`：屏幕阅读器可读名称，不能为空。
- `parentId`：父元素 ID；顶层节点设为 `null` 或空字符串。
- `order`：同一父级下的整数顺序，从小到大采用深度优先朗读；同一父级内不能重复，但允许有空缺。
- `hidden`：是否对辅助技术隐藏；隐藏节点及其后代都会进入跳过列表。

## 校验与预览

每次添加、移动或编辑元素都会先生成候选树。候选树存在以下问题时，调整不会生效：

- 元素 ID 缺失或重复。
- 角色缺失或不在支持列表中。
- 可读名称缺失。
- 顺序不是非负整数。
- 同一父级下多个元素使用相同顺序。
- 父级 ID 不存在而产生孤立节点。
- 节点直接或间接形成循环归属。
- 某个节点的上级链进入循环，导致其无法到达界面根。

冲突面板会显示被阻止的操作、涉及元素、具体关系（如 `a → b`）以及完整循环路径。成功调整后，页面会同时展示语义树、朗读项数量、跳过项数量、逐序号朗读内容及跳过原因。

`presentation` 和 `none` 角色自身不产生朗读项；`hidden: true` 的元素及其所有后代也不会朗读。

## 历史方案

每次成功调整都会保存一个不可变快照。用户可以：

- 在历史方案之间来回切换查看。
- 切回旧方案后基于旧状态继续调整。
- 在旧方案上继续派生子方案；这不会覆盖当时的快照。

当前项目会尝试保存到浏览器 `localStorage`；即使存储不可用，页面当前会话仍可正常工作。

## 验证

运行核心规则测试：

```powershell
npm test
```

测试覆盖初始树构建、深度优先朗读、隐藏子树、无语义角色、缺失名称、缺失父级、重复顺序、直接/间接循环、录入顺序无关的循环检测、非法调整阻断和相邻顺序移动。
