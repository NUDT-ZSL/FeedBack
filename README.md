# 多步骤表单认知负担推演工具（本地离线）

检查一份长流程表单在拆成不同步骤后，每步的阅读量、必填压力、跨步骤记忆与
前后依赖是否会让使用者记不住或跳错。纯前端实现，**无需联网、无需构建**，
直接双击打开 `index.html` 即可使用（数据保存在浏览器 localStorage）。

## 使用

1. 直接用浏览器打开 `index.html`（或在本目录运行 `npx serve .` 后访问）。
2. 界面启动即展示内置的「员工入职信息登记」示例（5 步 12 字段，含一条
   填写要求冲突和一条后置依赖）。
3. 每个字段卡片上可以：
   - 调整所属步骤（下拉框）；
   - **锁定**：锁定后自动收敛不再移动该字段，下拉框禁用；
   - **排除**：字段离开分步方案，依赖它的字段会被标记为前置缺失、所在步骤不可完成；
   - 编辑：改名称、阅读量、填写要求、备注，或删除字段。
4. 顶部操作：
   - **收敛分步**：依据全部依赖、锁定与排除，对未锁定字段做一次全量重推，
     给出满足约束的归属方案；
   - **+ 新字段 / + 新依赖**：维护表单结构。依赖理由里写上“必填”或“选填”，
     即视为该依赖对字段提出的填写要求（依据会保留）；
   - **重置示例**：清空本地修改。

## 界面如何回答六项需求

1. **维护结构与归属**：字段带有所属步骤、阅读量、填写要求；依赖带方向
   （`前置步骤 / 同一步骤 / 后置步骤`）与理由，均可增删改，归属可直接调整。
2. **沿依赖全链路推演**：前置关系沿依赖闭包传递（A 依赖 B、B 依赖 C，则
   A 也依赖 C）。每步指标包括：阅读量（字段估算字数之和）、必填压力
   （必填/选填计数与压力分）、跨步骤回溯记忆量（需要回忆早前步骤内容的字数）、
   前置未满足项。
3. **后置前置 => 不可完成**：某字段依赖的字段被排到更靠后的步骤时，该步卡片
   标红显示「不可完成」徽章，并列出具体是哪条依赖（字段、前后步骤、理由）。
4. **锁定 / 排除后收敛，且与整体重推一致**：求解器是纯函数——同一份
   「字段步骤 + 锁定 + 排除 + 依赖」永远推出同一结果。每一步增量操作后重推
   与一次性整体重推结果相同（见测试里的随机属性测试，40 组操作序列）。
5. **要求冲突保留全部依据**：同一字段被多条依据提出互斥的必填/选填要求时，
   右侧冲突面板列出自身声明与每一条依赖依据，不静默选择；字段卡片标
   「要求冲突」。结构冲突（同一步骤与异步骤矛盾、锁定与依赖矛盾、正环）
   同样保留约束链依据。
6. **启动即可操作**：打开页面直接展示分步结构，所有调整实时重算并更新
   每步负担与不可完成提示；未应用收敛建议时以蓝色虚线提示建议步骤。

## 求解方法（js/model.js）

- `same` 边用并查集合并为「组件」（必须同一步骤的字段集合）；
- `before / after` 边统一编码为差分约束 `step[v] >= step[u] + 1`；
- 锁定字段成为组件的固定值，排除字段移出图并登记为「缺失前置」；
- 上下界传播（最长路径）求出每个组件的可行区间，`lb > ub` 或正环即结构冲突；
- 收敛时在拓扑序上取最接近使用者偏好的可行值，再做前/后向单调修复，
   保证所有未锁定组件满足约束；锁定组件不移动，冲突显式保留。

## 测试

```bash
npm test
```

- `tests/model.test.js`：核心推演 10 项断言 + 40 组随机一致性序列；
- `tests/ui.test.js`：jsdom 中加载真实页面，模拟移动/锁定/排除/收敛/新增，
  验证界面渲染与状态持久化（共 15 项检查）。

## 文件结构

```
index.html          入口页面
css/style.css       样式
js/model.js         纯推演内核（无 DOM 依赖，可被 Node 直接引用）
js/storage.js       localStorage 持久化（不可用时降级）
js/app.js           界面编排（每次状态变化整体重推、整体重渲染）
tests/              Node 测试
```
