# 年度预算分配推演台

本地离线运行的预算分配推演工具：把资金上限、项目优先级、最低投入和前置依赖
放在一起求解，约束调整后立即重新收敛，并给出每个项目的取舍依据。
纯静态页面，无任何网络请求与外部依赖，双击 `index.html` 即可使用。

## 运行

- 直接用浏览器打开 `index.html`（推荐 Chrome / Edge）。
- 运行求解器测试：`node --test test/solver.test.js`

## 使用方式

1. 在“项目申请”表中为每个项目填写：申请金额、优先级（数字越大越高）、
   可接受的最低投入、前置项目（填项目 ID，多个用逗号分隔）。
2. 顶部修改总资金上限；任意字段修改后结果立即重算。
3. “锁定金额”填入数值后该项目金额固定，其余项目围绕它重新推导；
   勾选“排除”则该项目不参与分配。
4. “分配结果”表中：金额变化的项目会高亮并显示与上一次的差值；
   每个项目标注当前状态、满足程度和主导约束（取舍依据）。

## 分配规则

1. 前置项目未获足额支持（实得 < 申请额）时，本项目不进入可分配状态；
   该判定迭代至不动点，前置后来补足的项目会重新进入分配。
2. 锁定金额先行扣减；其余项目先保最低投入。
3. 余额按优先级从高到低分层分配；同优先级层内做均衡注水
   （等额推进、触及申请额即退出），小额申请先被填满，
   整体尽量逼近各自申请额，而不是按比例平摊。
4. 求解器是纯函数且确定性的：锁定 / 排除 / 调整后的重推结果，
   与用同样输入从头完整推导的结果必然一致。

## 冲突提示（不静默跳过）

- **依赖闭环**：列出闭环上的全部项目，闭环内项目均不可分配。
- **最低投入超支**：最低投入与锁定金额合计超过可用资金时，
  列出无法获得最低投入的项目名单。
- **锁定超支**：锁定金额合计超过总资金上限时单独提示。

## 文件结构

- `solver.js` — 分配求解器（纯函数，浏览器 / Node 通用）
- `app.js` — 界面逻辑（编辑、即時重算、变化标记）
- `index.html` / `styles.css` — 页面结构与样式
- `test/solver.test.js` — 求解器行为测试（node:test）
