# 记忆复习规划器

本地离线网页应用：双击 `index.html` 即可在浏览器中使用，无需网络与服务器。
所有数据保存在浏览器 localStorage 中，并支持导出 / 导入 JSON 备份。

## 功能

- **知识点管理**：新增知识点（名称、预计复习耗时、初始掌握程度），可删除。
- **复习记录**：每次复习后记录回忆质量 0-5，系统据此更新记忆稳定度 S 与遗忘速度。
- **遗忘曲线**：保持率 R(t) = 0.9^(t/S)，当 R 降至 0.8 即到期；复习质量越高 S 增长越快，间隔动态变化，而非固定周期。
- **需要加强**：回忆质量 <=2，或保持率很高却仅勉强想起（q=3）时，自动缩短间隔并打上"需要加强"标记。
- **今日清单**：在"今日时间预算"内，从已到期与 24 小时内临近到期的知识点中按紧迫度贪心选入，并逐项说明入选理由。
- **状态调整与记录删除**：手动调整（良好 / 模糊 / 遗忘）与删除历史记录都作为事件流重放重算，排期与清单立即保持一致。

## 使用

1. 双击打开 `index.html`。
2. 在"新增知识点"中添加要学习的内容。
3. 每天打开页面，按"今日复习清单"逐项复习，复习后点击回忆质量（0-5）。
4. 顶部可调整当天时间预算；右侧可导出 / 导入数据备份。
