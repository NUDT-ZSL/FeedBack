# 收支情景推演（Cashflow Sandbox）

本地可启动的资金推演小应用：维护基础收支计划，叠加“收入延迟 / 支出提前 / 金额上浮”
三类情景参数，实时查看资金曲线变化与缺口出现的时点及原因。

## 启动

- 双击 `start.bat`，或运行 `python start.py`，浏览器会自动打开应用；
- 也可以直接用浏览器打开 `index.html`（无任何外部依赖，离线可用）。

## 功能

1. **基础收支计划**：每笔收支含名称、类型、金额、起始日期、重复规律
   （一次性 / 按月 / 按季）与可选结束日期，可增删改。
2. **逐日推演**：系统把每笔收支展开到具体日期，逐日计算余额与累计缺口，
   作为情景推演的基准曲线（灰色）。
3. **情景叠加**：收入延迟（天）、支出提前（天）、金额上浮（%，可作用于
   支出 / 收入 / 全部）三类参数同时叠加后重新推演（蓝色曲线）。
4. **缺口定位**：情景余额首次跌破安全线时，标出日期、当时余额，并列出
   自“最后一次高于安全线”至跌破当日共同造成缺口的全部收支明细。
5. **确定性更新**：任何参数调整立即重算；同一输入永远得到同一结果，
   已标出的缺口时点与原因不会因无关改动而漂移。
6. **单页界面**：左侧编辑计划与情景参数，右侧即时显示曲线、统计与缺口明细。

数据保存在浏览器 localStorage 中，刷新不丢失。
