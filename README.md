# 本地离线异步检索浏览

这是一个零构建、零第三方依赖的离线演示应用。它模拟检索服务按批次返回结果，并保证视图始终只由当前浏览上下文派生。

## 启动

直接双击 `index.html`，或在浏览器地址栏打开该文件。也可以在当前目录运行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 验证路径

1. 提交第一个检索，在批次陆续到达时修改关键词、筛选或页码并再次提交。
2. 观察新上下文立即成为当前视图；旧上下文的后续批次不会覆盖当前结果。
3. 点击顶部旧上下文标签回到原页面，已到达的批次可立即复用，后台继续到达的批次仍进入该上下文。
4. 点击“注入同位置矛盾批次”，同一 `locationId` 的不同内容会同时保留并标出矛盾。
5. 对矛盾点选择采用版本，或在侧栏排除/恢复批次；这些裁决只存放在对应上下文。
6. 旧运行被重新触发取代后，迟到批次会进入“过期与后台到达”列表，可一键回到该上下文并重新触发。

## 关键实现

- `core.js`：上下文存储、运行身份校验、批次缓存、派生视图、矛盾与裁决状态。
- `app.js`：模拟异步调度、过期/后台事件提示和界面渲染。
- `data.js`：本地确定性数据生成器与矛盾样本。
- `tests/store.test.js`：竞态、缓存复用、旧运行拒绝、矛盾、隔离与最终一致性测试。

## 测试

```powershell
npm test
```

测试只使用 Node.js 内置测试运行器，不需要联网或安装依赖。
