# 创作版本回看工作台

一个纯本地、离线运行的单页应用，用于管理长文档在多人多轮编辑后的版本血缘关系。

## 启动

直接双击 `index.html` 用浏览器打开即可（无任何外部依赖与网络请求）。首次启动自动载入内置示例数据；之后界面上的补录与修正会保存在浏览器 localStorage，刷新不丢失。

## 功能对照

1. **载入与补录**：点「载入版本记录(JSON)」导入本地 JSON（数组或含 `versions` 字段），每条含 `id / parent / author / time / summary`；右侧表单可继续补录新版本或修正已有记录；「导出当前记录」可存回本地。
2. **问题标记**：父版本不存在的记录、以及互相指向形成血缘闭环的记录（Tarjan 强连通分量检测），会在图中标红并列入「问题标记」面板，绝不静默丢弃或强行挂接。
3. **任意两版本对比**：在血缘图点击两个版本，系统沿父链求最近公共分叉点，列出分叉点两侧各自的改动摘要，并标明差异依据来自哪些版本。
4. **精准失效**：对比结论按「依据版本集合」缓存。修正某条摘要或撤销版本时，只使结论集合中包含该版本的缓存失效并即时重算，其余结论保持不变（顶部黄色条会显示「更新 N 条，保持 M 条不变」）。
5. **撤销与待处理后代**：撤销有后代的版本时，其直接子版本标为「待处理」（橙色），并给出建议的新父版本（最近的未撤销祖先），可一键接受或手动指定，不会悬空。
6. **即时联动**：所有修正、撤销、重接操作立即重算血缘图、问题面板与当前对比结论。

## 文件

- `index.html` — 界面骨架与样式
- `app.js` — 全部逻辑（血缘推导、闭环检测、对比缓存、编辑操作）
- `sample-versions.json` — 可导入的示例数据（含一个父缺失记录 v10 和一对闭环 v11↔v12，便于验证问题标记）
