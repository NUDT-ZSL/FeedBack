# 决策回放（Decision Replay）

一个纯前端的个人决策复盘工具：记录每次选择时的依据与主观权重，
随后追加新信息、重新评估，并对比同一决策在不同时间点的判断演变。

## 启动

直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge）。
无需服务器与构建步骤，数据保存在浏览器 localStorage 中。
首次启动会载入一个示例决策，便于直接体验各项功能。

## 功能对照

1. **录入决策与初始快照**：新建决策 → 添加选项 → 为每个选项添加依据
   （支持/反对方向、主观权重 1-10、半衰期），形成初始判断。
2. **追加新信息并重算**：新信息可挂到选项（作为新依据）或已有依据上
   （强化权重 / 推翻使其失效），提交后自动重算并显示各选项分值变化（▲/▼）。
3. **权重衰减与失效标注**：依据权重按半衰期指数衰减，卡片中实时显示
   衰减百分比；被推翻的依据保留但划线标注"已失效"及推翻它的信息；
   每次重算生成快照，旧结论全部保留。
4. **多时间点对比**："演变对比"展示各选项评估值的轨迹图、每个时间点的
   主导依据更替；详情页底部的"评估历史"表格列出每次重算的分值、
   增减量与失效依据。
5. **冻结已执行/已放弃选项**：标记后该选项评估值冻结，卡片置灰，
   不再参与后续重算；其余待定选项继续正常参与。
6. **即时可见**：启动即显示决策列表 + 详情面板，所有操作即时刷新界面。

## 文件结构

- `index.html` — 页面骨架与对话框
- `styles.css` — 样式
- `model.js` — 数据模型、衰减评分引擎、快照、冻结逻辑
- `views.js` — 列表 / 详情 / 时间线 / 对比图渲染
- `main.js` — 事件装配与对话框交互
