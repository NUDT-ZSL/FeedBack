# 长期资产价值轨迹工作台

这是一个完全在本地运行的零依赖交互式工作台，用于评估多项长期资产在使用周期中的账面价值变化、价值调整影响和警戒线触发年份。

## 启动方式

方式一：双击 `启动工作台.bat`，浏览器会打开 `http://localhost:5173`。

方式二：在当前目录运行：

```powershell
npm start
```

然后访问 `http://localhost:5173`。

## 功能

- 录入多项资产：初始投入、启用年份、预计使用年限、残值率。
- 为任意使用年度追加价值调整，负额表示减值或冲减，正额表示增值或补提。
- 参数或调整变更后即时重算受影响资产；计算按资产独立执行，其他资产结果不变。
- 调整可单条撤销；撤销后按剩余确认调整重建轨迹，不影响其他年份。
- 年末账面值低于“初始投入 × 警戒比例”时，标红该年份并展示首次触发依据。
- 同一界面展示组合汇总、所有资产迷你轨迹、单项资产图和逐年明细。
- 数据只保存在当前浏览器的 `localStorage`，不会上传服务器。

## 计算口径

- 折旧方法：直线法。
- 正常年度折旧：按当年年初账面值与预计残值的差额，在剩余使用年限内平均分摊。
- 调整在年末入账：年末账面值 = 调整前账面值 + 调整金额。
- 调整后的下一年度，用新的年末账面值继续在剩余年限内折旧到原预计残值。
- 预计残值 = 初始投入 × 残值率。
- 警戒线 = 初始投入 × 警戒比例；严格低于该线时触发。

## 数据矛盾处理

以下情况会标出具体资产和问题，且该资产不会进入汇总：

- 初始投入不大于 0。
- 启用年份或使用年限不是合理整数。
- 残值率小于 0 或大于等于 100%。
- 调整年份超出 1 到预计使用年限。
- 调整金额为 0 或非数字。
- 调整导致年末账面价值为负。
- 同一年存在多条调整。

## 验证

```powershell
npm test
```
