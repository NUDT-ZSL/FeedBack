# 位置对象范围查找推演台

导入带标识、坐标、类别、有效期和来源说明的位置对象，以及若干范围查找请求，
推演命中对象、邻近顺序与判定依据。所有来源记录全程保留；坐标缺失/越界、
有效期或类别互相矛盾的对象被标记为不可信并排除在邻近排序之外，等待人工裁决。

## 启动

- 直接双击 `index.html`（或运行 `start.bat`）即可进入可操作界面，启动时自动载入示例数据。
- 运行引擎测试：`node test/engine.test.js`

## 界面操作

- 左侧画布：拖动范围图形移动，拖动边缘手柄调整大小，点击对象查看来源。
- 右侧“查找结论”：命中对象按到范围参照点的距离升序排列，展开可见每个对象的
  纳入/排除依据；歧义（压线、范围重叠、类别与有效期冲突）单独列出。
- “对象来源与裁决”：查看全部来源记录（含已撤回留痕），对矛盾字段下拉选择后裁决，
  可撤回来源、提交修正来源。每次操作只增量重推受影响的查询，并记录在“事件与影响”中。
- 工具栏“增量/整体一致性校验”：随时对比增量结果与整体重推结果。

## 导入数据格式（JSON）

```json
{
  "world": { "minX": 0, "minY": 0, "maxX": 100, "maxY": 100 },
  "objects": [
    { "objectId": "obj-a", "source": "gps-1", "coord": { "x": 20, "y": 20 },
      "category": "beacon", "validFrom": "2026-01-01", "validTo": "2026-12-31",
      "note": "来源说明" }
  ],
  "queries": [
    { "id": "Q1",
      "shape": { "type": "circle", "cx": 30, "cy": 30, "r": 15 },
      "filters": { "categories": ["beacon"], "asOf": "2026-09-24" },
      "expectedBasis": ["来源记录一致性", "有效期覆盖基准日"] }
  ]
}
```

- 同一 `objectId` 可有多条来源记录；`shape` 支持 `circle`（cx/cy/r）与
  `rect`（minX/minY/maxX/maxY）；`categories` 为空表示不限类别。

## 事件类型（引擎 API / 界面操作对应）

- `correct`：追加修正来源记录 `{ record }`
- `withdraw`：撤回某来源 `{ objectId, source }`（记录保留留痕）
- `adjudicate`：人工裁决字段取值 `{ objectId, field, value, by }`
- `updateQuery`：调整范围或过滤条件 `{ query }`

## 判定规则

- 字段在所有在册来源中一致（或经裁决）才可信；坐标缺失、坐标越出世界边界、
  坐标/类别/有效期来源矛盾（含有效期区间互不相交）均使对象不可信。
- 不可信对象不参与邻近排序，但在每个查询的“排除对象及原因”中列出完整理由。
- 对象恰好落在边界上按“闭区间含边界”纳入，同时标记压线歧义（阈值 0.75）。
- 查询范围两两部分重叠时，双方结论中都给出重叠歧义说明。
- 增量重推只刷新受影响查询；对象可信状态翻转时会刷新全部查询的排除理由，
  可用一致性校验验证增量结果与整体重推完全一致。
