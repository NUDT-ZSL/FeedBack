# 离线风格规范审查工具

完全本地运行，仅依赖 Python 标准库（3.6+），无任何在线服务依赖。

## 启动

```
python run.py
```

启动后自动在浏览器打开审查界面（http://127.0.0.1:8000）。

## 功能

- 载入长文档（`data/document.md`，按 `# 标题` 分章）与风格规范（`data/rules.json`）。
- 规范类型：`terminology`（术语用词）、`tone`（语气倾向，正则）、
  `consistency`（跨章节称谓统一）、`section_presence`（章节必备要素）。
- 逐章节推导每项规范的符合情况，违反位置标注章节与上下文片段。
- 同一位置触发多条规范时，每条依据独立保留（界面中红色高亮，点击可见全部依据）。
- 修改/删除规范后仅重推受影响的 (规范 × 章节) 结论，其余复用缓存；
  每次重推自动与整体重推校验一致性并显示结果。
- 规范指向缺失章节、目标词不存在、正则无效等情况，结论标记为「不可信」并说明原因。
