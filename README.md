# 财务方案评审台（离线）

评审财务方案用的纯本地工具：不接任何真实财务系统，全部数据来自本地录入的假设与响应配置。

## 启动

无需安装、无需构建、无需网络：**直接用浏览器打开 `index.html`** 即进入可用界面（已预置一份示例方案：5 个假设、2 项指标、2 个来源、2 处冲突登记）。

也可以起个静态服务（可选）：`npx serve .` 或 `python -m http.server`。

## 运行测试

```bash
node tests/core.test.js   # 17 项内核行为测试
```

## 文件

| 文件 | 作用 |
|---|---|
| `core.js` | 纯逻辑内核（无 DOM 依赖，浏览器 / Node 通用）：登记校验、贡献分解、方向扫描、冲突记录、增量重算与全量校验 |
| `sample-data.js` | 内置示例方案（含非单调响应、平台段、双来源冲突） |
| `app.js` / `index.html` / `styles.css` | 界面 |
| `tests/core.test.js` | 内核测试 |

## 需求对应

1. **假设与指标维护** — `registerAssumption` / `registerMetric`：唯一标识、基准值、上下限、单位；区间非法（下限≥上限、基准越界）与标识重复（同来源）均拒绝并给出 `path` 位置。
2. **分段线性响应** — `registerResponse`：段区间须首尾相接、不重叠、完整覆盖假设取值区间；断点缺失、重叠、越界逐段拒绝并说明原因（`validateSegments`）。
3. **指标值与贡献分解** — `computeDecomposition`：指标值 = 基准值 + Σ（响应值 − 响应基准值），贡献之和按构造恒等于总变化，界面实时显示校验 ✓。
4. **方向扰动首越线** — `sweepDirection`：沿 `x(t)=当前值+t·权重` 扫描至任一假设触界，给出首次越线 t*、该处全部假设取值、以及越线时贡献前三的假设（"谁在起作用"）。
5. **非单调 / 平台** — 列出全部穿越点（穿越 / 触及 / 跳变 / 平台重合区间）、越线区间、不可达说明与值域缺口；所有遍历按键序排序，结果与登记顺序无关（有测试保证）。
6. **多来源冲突** — 同一假设 / 响应的矛盾登记双方均保留在 `variants` 中，`getConflicts` 生成可读记录（假设、双方来源、各自内容），界面可切换采用哪一方。
7. **增量一致性** — `recompute` 只重算受影响指标，未受影响缓存原样保留；`verifyConsistency` 每次变更后与从头全量求解比对，顶栏实时显示「增量 = 全量 ✓」。
8. **即用界面** — 打开即显示假设滑杆、方向权重、决策线、贡献瀑布图、M(t) 扫描曲线与冲突标记；拖动或改方向立即重算，非法录入在表单下方与日志中给出拒绝原因。

## 界面速览

- **左列**：假设表（滑杆 + 数值 + 基准 + 区间 + 方向权重），登记 / 修改假设与指标的表单。
- **中列**：每个指标一张卡 —— 当前值与决策线状态、贡献分解瀑布图（含和校验）、沿扰动方向的扫描曲线（越线区阴影、穿越点、平台、首越线 t* 标注）、全部穿越点与不可达说明。
- **右列**：响应段编辑器（每行 `x0, y0 → x1, y1`）、冲突记录（可切换采用来源）、操作日志。
