# 本地遗忘曲线复习规划工具

这是一个完全运行在本机的桌面复习工具，不使用在线服务、数据库服务或第三方 Python 包。学习记录保存在 `data/review_data.json`，首次启动会自动载入 `data/sample_items.csv` 中的示例。

## 启动

双击 [run.bat](run.bat)，或在本目录运行：

```powershell
python app.py
```

需要 Windows 自带的 Python 3，并启用标准库 Tkinter（当前环境已验证可用）。

## 使用方式

- 启动后直接进入“今日复习安排”，按紧迫分从高到低排序。
- 选择条目后查看内容、当前掌握度、估计留存率、目标留存率和排序原因。
- 点击“答对”或“答错 / 想不起来”，系统立即更新掌握度、记忆强度、连续趋势和下次复习时间，并显示调整原因。
- “手动编辑”可调整标题、内容、掌握程度、重要度、上次复习时间、下次复习时间和备注。
- 下次复习时间留空时由遗忘曲线自动推导；填写后会保留为手动指定。
- “导入”支持 UTF-8 CSV 或 JSON；可按 `id` 合并，也可替换全部数据。
- “导出备份”会把完整本地数据另存为 JSON。

## 批量导入字段

CSV 表头支持中文或英文：

| 中文名 | 英文名 | 说明 |
| --- | --- | --- |
| 编号 | `id` | 可空；空则自动生成 |
| 标题 | `title` | 必填 |
| 内容 | `content` | 题干、提示或答案线索 |
| 掌握程度 | `mastery` | 0-100 |
| 重要度 | `importance` | 1-5 |
| 上次复习时间 | `last_reviewed` | `YYYY-MM-DD` 或 `YYYY-MM-DD HH:MM` |
| 下次复习时间 | `next_review` | 同上，可空 |
| 备注 | `notes` | 可空 |

## 调度规则

系统使用指数遗忘曲线：

```text
R = e^(-t/S)
```

其中 `R` 是估计留存率，`t` 是距上次复习的天数，`S` 是记忆强度。重要度越高，目标留存率越高：重要度 1-5 对应 75%-89%。系统用当前留存率与目标留存率的差距、逾期天数、重要度和是否从未复习计算紧迫分。

答对会提高掌握度并增强记忆强度；连续答对会逐步拉长间隔。答错会降低掌握度并削弱记忆强度；连续答错会更快缩短间隔，安排当天或次日再次复习。

手动修改单条内容只重新计算该条目及其在队列中的位置，其他条目的下次时间和数据不会被改写。
