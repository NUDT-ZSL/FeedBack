# 素材渠道适配工作台

本地启动的交互式工作台,帮助设计团队把素材按不同交付渠道的规格做适配评估与裁切规划。

## 启动

- 双击 `start.bat`(需要本机安装 Python 3),浏览器自动打开 `http://localhost:8321`
- 或手动执行: `python -m http.server 8321` 后访问该地址

首次启动自动载入一批示例素材与渠道规格,之后数据保存在浏览器 localStorage,
可通过顶栏"导出 JSON / 导入 JSON"迁移或备份。

## 功能

1. **素材与渠道管理**
   - 素材:名称、用途标签、原始宽高、格式、可裁切区域(取图范围)、关键内容区域
   - 渠道:目标宽高、宽高比(由目标尺寸推出)、安全边距、接受格式
2. **适配判定**:选择素材与渠道后给出 可适配 / 需裁切 / 不可适配 结论,
   并明确指出差距在尺寸、比例、安全边距还是格式。
3. **裁切方案**:在可裁切区域内给出满足目标比例与安全边距的裁切框,
   画布中叠加显示安全区(黄色虚线)与关键内容区域(绿色),
   关键区域可能丢失时给出醒目警告。
4. **实时联动**:任何素材参数或渠道规格的修改保存后,
   所有素材卡片上的渠道徽标、结论与裁切方案立即重算,不保留旧结论。
5. **多渠道折中**:勾选多个渠道后给出共享裁切区(紫色虚线)与各渠道子裁切,
   表格标注每个渠道是否可满足及失败原因。
6. **即开即用**:启动后直接进入工作台,左侧选素材、右侧选渠道,
   中间即时显示结论与裁切预览。

## 测试

```
node test-engine.js
```

多渠道折中、参数变更重算等)。
