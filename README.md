# 程序化地牢生成与可达性检查器

这是一个零运行时依赖的网页工具，用于按种子和地形参数生成地牢，并立即检查出生点到每个目标点的连通性。

## 运行

```powershell
# 仅运行自动化测试
npm test

# 启动静态服务器
python -m http.server 8000
```

然后打开 `http://localhost:8000/index.html`。也可以直接用现代浏览器打开 `index.html`。

## 功能

- 使用 FNV-1a 哈希与 mulberry32 PRNG，相同种子和参数生成完全相同的结果。
- 校验地图尺寸、房间数量、房间边长、目标数量、走廊宽度和地形占比。
- 房间采用非重叠布局；密集地图会使用确定性网格兜底，避免随机摆放导致残缺地图。
- 每个房间通过最近邻走廊连接；走廊不会被水域覆盖。
- 水域只能生成在房间内部，并会阻挡四方向通行；草地可通行。
- BFS 从出生点计算可达开放格，红色覆盖所有不可达区域，并列出不可达目标的 1 基坐标。
- 摘要展示房间数、走廊数、目标可达比例、不可达格数、实际地形占比和本次种子。

## 可达性模式

- “强制目标可达”开启时（默认）：生成器最多执行 30 次确定性尝试；仍无法保证目标全部可达时拒绝生成并明确提示可达性约束被破坏。
- 关闭该选项时：允许生成带阻断的地图，用于观察高水域参数如何改变可达性。界面会显示红色不可达区域和具体目标位置。

## 代码结构

- `src/dungeon.js`：参数校验、地牢生成和 BFS 可达性分析。
- `src/rng.js`：确定性哈希与伪随机数。
- `src/render.js`：Canvas 地图渲染。
- `src/app.js`：界面状态、即时重生成和摘要更新。
- `test/dungeon.test.js`：确定性、约束、可达性和非法参数测试。
