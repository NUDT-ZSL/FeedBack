# 文档评审工作台

纯前端单文件离线应用，双击 `index.html` 即可在浏览器中使用，无需联网、无需安装依赖。

## 功能

- 左侧为可编辑文档正文，右侧为评审意见列表与状态汇总进度。
- 在文档中选中文字即可新建意见，意见通过「原文 + 前后上下文」锚定，可追加讨论回复。
- 文档编辑后自动重新定位全部意见：原文平移 → 正常高亮；原文被轻度改写 → 标记「位置待确认」并自动吸附到最相近片段；原文被删除或大幅改写 → 标记「定位失配」并给出可读原因。
- 每条意见可标记 采纳 / 驳回 / 待定 / 重新打开，驳回必须填写理由；状态即时反映在列表、筛选器和顶部进度条中。
- 同一段文字上的多条意见在文档修改后统一定位、一致更新。
- 通过筛选器查看「失配」「待处理」清单；失配意见可点击「重新绑定」，在文档中选中新位置后确认，恢复追踪。
- 数据自动保存在浏览器 localStorage，支持导出 / 导入 JSON 备份。
