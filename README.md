# 线索笔记

一款本地优先的个人知识整理工具。每条笔记包含标题、标签和自由文本；系统会在当前笔记与其他笔记之间寻找共同标签、最长中文共享短语、英文词或数字线索，并解释每条关联的来源。

## 使用

直接双击打开发布文件即可，无需安装依赖或联网：

[dist/index.html](dist/index.html)

笔记保存在当前浏览器的 `localStorage` 中。清空浏览器站点数据会删除这些笔记。

## 功能对应

- 点击“新建笔记”后空白笔记立即进入列表和编辑区。
- 选中笔记后，右侧关联按相关分从高到低排列。
- 每张关联卡分别展示共同标签、文本短语、标题命中和正文摘录。
- 标签或正文修改后，自动保存并基于当前数据重新计算；关联结果不做缓存。
- 点击关联卡会把目标加入浏览线索；顶部路径中的任意节点都可回退。
- 没有有效标签或文本线索时显示“这条笔记当前是孤立的”，不会显示空列表或强行连接。

## 关联规则

- 共同标签总是形成关联，多个标签会提高相关分。
- 中文文本提取最长共享短语，避免把“项目复盘会议”拆成多个重叠片段重复计分。
- 标题命中、稀有短语和较长短语权重更高；常见泛化词语会被过滤。
- 英文词、带连字符的标识符和数字按精确词匹配。

## 开发与验证

```powershell
npm test       # 运行关联规则测试
npm run build  # 重新生成可直接双击的 dist/index.html
npm run verify # 构建并测试
```

源码文件：

- `core.js`：无 DOM 依赖的标签解析与关联规则。
- `app.js`：界面、编辑状态、本地持久化和浏览路径。
- `build.mjs`：把样式与脚本内联为单文件发布页。
