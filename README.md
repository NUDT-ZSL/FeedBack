# 太上丹房 · 并行炼丹台

TypeScript + React + Canvas 2D 的古代炼丹模拟器。单炉炼制已扩成可并行开多炉的炼丹台，
每炉各自维护投料记录、火候、元素集合与成丹判定，支持冲突裁决、单炉回退与全程追溯。

## 运行（离线）

```bash
npm install      # 首次安装依赖
npm run dev      # 浏览器中打开炼丹台
npm run build    # 类型检查 + 生产构建
```

## 批量验证入口（零依赖，无需 npm install）

```bash
npm run batch    # 等价于 node scripts/batch.ts
```

`scripts/batch.ts` 基于 Node 22 原生 TypeScript 运行能力，不依赖任何 npm 包，一次性覆盖：

1. **多炉并行**：各炉炉温按自身风量独立推进；鼓风只作用于当前选中炉；切换选中炉不改变任何炉状态；未选中炉在后台继续推进。
2. **冲突裁决**：相克（如木克土）投料当下判为炸炉，同属性重复投料判为废丹；冲突双方药材来源均保留；他炉判定不受牵连。
3. **单炉回退**：撤销最近一次投料后，元素集合、火焰颜色、炉温与成丹判定恢复投料前状态，且与从头重投同样药材的结果逐字段一致。
4. **混合可追溯**：切换/并行/冲突/回退交织操作时，每炉事件日志连续有序、不串炉，成丹依据含相生判定、药材来源与火候记录。

## 结构

- `src/engine/model.ts`：引擎数据模型（炉状态、冲突备案、成丹判定、事件日志、快照）。
- `src/engine/derive.ts`：纯函数推导（五行生克、火焰调色、火焰高度、冲突检测、成丹配方）。
- `src/engine/workshop.ts`：多炉工作台引擎（开炉/选炉/投料/鼓风/回退/清理/逐帧推进），无 React、无随机性副作用（可注入确定性 RNG）。
- `src/Furnace.tsx`：丹炉 Canvas 表现层，渲染引擎传入的选中炉视图，按炉 `key` 隔离粒子与动画。
- `src/App.tsx`：多炉工作台组装（炉位切换、右侧炉况/冲突/判定/日志面板）。
- `src/PillResult.tsx`：丹药收藏与葫芦架。

## 规则说明

- **相生**：木生火、火生土、土生金、金生水、水生木；形成相生组合且无冲突时成丹。
- **相克 → 炸炉**：新投药材与炉中任一药材互为克制（木克土、土克水、水克火、火克金、金克木），炉毁丹伤，需回退或清理炉膛。
- **重复 → 废丹**：同属性药材重复投入，药性淤积，不予成丹。
- **回退**：每次投料前保存该炉快照（投料、炉温、成丹判定），回退即恢复快照并由投料序列重推元素与火焰，保证与从头重投一致。
