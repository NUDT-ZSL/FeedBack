# 素材适配工作台

完全本地运行的素材适配推导工具, 不依赖任何在线服务或外部账号。
后端仅使用 Python 标准库, 前端为原生 HTML/JS, 数据持久化到本地 `data.json`。

## 启动

```
python server.py        # 默认 http://127.0.0.1:8000
python server.py 8123   # 指定端口
```

启动后直接呈现素材列表与交付规格面板, 无需任何配置。

## 功能

- **素材维护**: 名称、尺寸、最小可读区域, 可新增/编辑/删除。
- **交付规格维护**: 目标尺寸、安全边距、允许的适配策略(缩放/裁切/重新构图)。
- **自动推导**: 素材分配到规格后, 按宽高比差异自动选择适配方式:
  - 宽高比一致(差异 ≤ 2%) → 缩放;
  - 差异较小(裁切量 ≤ 30%) → 裁切;
  - 差异过大 → 重新构图(提示人工介入)。
- **冲突检测**: 安全边距过大导致安全区不存在、最小可读区域放不进
  安全区或可见窗口、所选策略不被规格允许, 都会逐条标出原因。
- **结果独立**: 每个 (素材, 规格) 组合单独推导, 修改一个规格不会
  影响其他规格下同一素材的结论。
- **手动覆盖**: 可对单个分配强制指定适配方式, 其余分配仍自动推导;
  「撤销覆盖」即恢复自动结果。

## 测试

```
python -m unittest test_fitlogic
```

## 文件

- `fitlogic.py` — 适配方案推导逻辑(纯函数)
- `server.py` — 本地 HTTP 服务与 JSON API
- `static/` — 前端页面
- `data.json` — 运行数据(首次启动自动生成种子数据)
