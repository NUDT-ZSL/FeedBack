# 本地多维切片发现台

这是一个零依赖、可离线运行的浏览器应用。直接双击打开 `index.html` 即可使用，不需要启动服务，也不会连接外部服务。

## 使用流程

1. 启动后会自动载入一份内置销售明细；点击“导入 CSV / TSV”可换成自己的明细数据。
2. 在左侧把列指定为“维度”或“度量”，勾选参与切片的维度，并选择度量列与聚合方式。
3. 通过维度取值复选框或度量数值范围调整筛选；结果区会实时显示聚合值、样本数和“样本不足”标记。
4. 点击单元格旁的“标记发现”，填写结论并可选引用更早的发现。系统会同时保存当时的字段口径、筛选条件、结果、样本数和可信度。
5. 修改当前视图后，系统会重新计算每条发现。条件或结果不一致的记录会显示“已失效”和具体原因。
6. 删除某个被引用的发现时，其信息会以墓碑形式保留；下游记录会显示“含断链”，并保留原引用 ID、标题、条件和断点位置。

## 验证

- 核心算法：`node tests/core.test.js`
- 浏览器端到端冒烟测试：`node tests/browser-smoke.mjs`
- 语法检查：`node --check app.js`

发现记录通过浏览器 `localStorage` 保存在当前本机浏览器中。若导入的明细过大导致存储配额不足，发现仍会尝试保存，但明细本身可能只在当前页面会话中保留。
