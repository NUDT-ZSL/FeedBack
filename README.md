# 三维部件标注工具

纯前端、零依赖的三维场景标注工具。直接用浏览器打开 `index.html` 即可使用。

## 功能

- **场景搭建**：新建部件（位置/旋转/尺寸/缩放均可编辑），或导入/导出 JSON 场景。
- **三维观察**：左键拖拽旋转，右键或 Shift+拖拽平移，滚轮缩放。
- **表面标注**：点「标注模式」后点击部件表面，标注记录的是**部件 ID + 部件局部坐标系锚点**，而非世界坐标。
- **变换链重推导**：每帧沿 部件局部 -> 世界 -> 相机 -> 屏幕 的变换链重新推导所有标注的屏幕位置；部件旋转/缩放/移动后锚点仍落在同一局部表面位置。
- **失效提示**：部件被删除或锚点越出部件边界时，标注保留在视图中，以红色虚线叉标记 + 侧栏警告提示，不会静默丢弃；边界恢复后自动复原。
- **单标注编辑**：修改文字或拖拽标签微调偏移，只更新该标注对应的 DOM 标签，其余标注不受影响。

## 文件结构

| 文件 | 职责 |
| --- | --- |
| `math3d.js` | 向量、TRS 矩阵正/逆变换、射线与有向包围盒求交 |
| `scene.js` | 部件/标注状态、锚点重推导与失效判定、序列化 |
| `render.js` | 轨道相机、透视投影、Canvas 盒体渲染 |
| `panel.js` | 侧栏部件/标注列表与编辑器 |
| `app.js` | 主循环、相机交互、表面拾取、标签 DOM 管理 |
