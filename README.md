# 移动模式复核工具（本地离线）

把带噪声的位置点序列变成可复核的「停留 / 移动 / 同行」结论。
纯 Python 标准库 + 原生前端，无需安装任何依赖、无需联网。

## 启动

```
python server.py        # 默认 8017 端口
```

浏览器打开 http://127.0.0.1:8017/ 。Windows 也可双击 `start.bat`。
左侧导入区可粘贴 CSV/JSON，或直接选择 `sample_data.csv`（内置示例，
含时间倒序、重复上报、明显漂移三类异常点）。

## 功能对照

1. **导入与异常保留**：位置点含目标标识、时刻（epoch 或
   `YYYY-MM-DD HH:MM:SS`）、经纬度。时间倒序 / 重复上报 / 明显漂移
   （隐含速度超阈值）的点会被标记并保留在表格中，绝不静默丢弃；
   漂移点不参与停留聚类，避免一个跳点破坏分段。
2. **停留 / 移动分段**：沿时间轴推导。停留需同时满足空间聚集
   （`stay_radius_m` 内）与最短持续（`stay_min_seconds`）；每段给出
   起止时刻、依据点列表与判定参数。
3. **同行关系**：两目标轨迹在重叠时段按固定步长重采样，持续接近
   （`co_radius_m`）形成同行区间；时长达到 `co_min_seconds` 判为
   「稳定同行」，否则为「偶发接近」，并给出覆盖率、平均间距等置信依据。
4. **增量更新**：修改位置点只重推该目标的分段与涉及该目标的同行对；
   调整参数只重推受影响的层级。页首徽标实时校验「增量结果 == 整体重推」。
5. **同行变化标注**：每次修改后，左栏列出新增 / 消失 / 区间变化的
   同行关系。
6. **时间轴视图**：每个目标一行显示停留（蓝）/ 移动（绿）分段；
   同行区间以橙色横带跨目标行显示，并在下方专用泳道逐条列出；
   点击任一段查看依据点与判定参数。

## 验证

```
python tests.py
```

覆盖异常标记、分段正确性、同行分类、增量与整体重推一致性、
关系差异事件（新增 / 消失 / 变化）。

## 文件说明

- `server.py` — HTTP 服务与 API（stdlib）
- `store.py` — 状态与增量重推编排、一致性校验
- `segments.py` / `cotravel.py` / `anomalies.py` / `geo.py` — 算法层
- `static/` — 单页前端（时间轴 SVG、点位编辑、参数面板）
- `gen_sample.py` / `sample_data.csv` — 示例数据
- `tests.py` — 自动化验证
