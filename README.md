# 反馈需求线索聚类模块（离线）

纯 Python 标准库实现，无任何外部依赖、不访问网络服务，
数据保存在本地 `data.json`。

## 运行

    python app.py

浏览器打开 http://127.0.0.1:8321 （可用环境变量 PORT 改端口）。

## 验证

    python run_tests.py

## 功能与需求对应

1. **反馈管理**：界面左侧可新增反馈（来源/原文/标签，时间自动
   记录），每条反馈可编辑、删除，即改即存。
2. **自动聚类**：字符 1-2 gram TF-IDF + 余弦/Dice 融合相似度，
   确定性层次凝聚聚类；每簇给出代表描述（中心句）与关键词。
3. **边界依据保留**：相似度落在阈值边界带（±0.05）内的簇对，
   其相似度、共同特征与归并/不归并判定全部保留并在界面顶部
   红色区域提示，阈值微调不会造成分组无声跳变。
4. **人工调整**：支持移动单条反馈到其他簇、勾选拆分簇、
   合并两簇，操作后立即重算并刷新界面。
5. **顺序无关**：人工调整被固化为"钉住"约束（pins），最终分组
   永远是（反馈集, pins, 阈值）的纯函数，每次操作后从头重算，
   不存在增量状态漂移；测试验证了重载、重复计算、不同录入
   顺序下分组完全一致。
6. **可展开追溯**：每个簇可展开查看全部原始反馈（来源/时间/
   标签）、簇内最强相似对及其共同特征、自动归并日志，
   人工固定的条目有橙色标记。

## 文件说明

- `similarity.py` 离线文本相似度（分词、TF-IDF、融合相似度）
- `clustering.py` 确定性聚类、归并日志、边界对、代表描述
- `store.py` 反馈存储、人工约束、确定性分组重算
- `view.py` 组装界面所需的完整状态（含判定依据）
- `app.py` 标准库 HTTP 服务与 JSON API
- `static/index.html` 单页操作界面
