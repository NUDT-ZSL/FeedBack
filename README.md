# 运营实验比较台

离线可启动的交互式实验比较工具：围绕**策略变体 × 受众分组 × 观测数据**给出可解释的效果判断。
零第三方依赖（Python 3.6+ 标准库），数据持久化在本地 `data/store.json`。

## 启动

```
python server.py
```

然后浏览器打开 <http://127.0.0.1:8787>。Windows 也可双击 `启动.bat`。
首次启动自动载入内置演示数据（含三类冲突与样本不足场景），可在界面右上角重新载入。

## 功能对照

1. **变体与分组维护**：分组含进入人数/转化人数/观测时段/口径标识与版本；变体与分组多对多归属。
2. **冲突保留与标注**：一组被多变体覆盖、同变体内口径版本冲突、同口径时段重叠，三类冲突全部保留来源并列出，裁决只标记排除（excluded），绝不静默删除。
3. **增量更新**：修正观测或裁决冲突后只重算受影响变体的结论；每次变更后端都会与从头全量重算比对，页头实时显示「增量更新 ✓ 与全量重算一致」。
4. **可解释判定**：区分样本量不足 / 时段不重叠 / 分组口径不一致，输出双比例 z 检验 p 值、绝对差、相对提升与 高/中/低 可信度及依据。
5. **基准锁定**：可将任意分组锁定为基准；锁定后其余比较结论仍与全量重算一致，并标注相对锁定口径的「口径偏移」。
6. **即开即用**：启动即进入可操作界面，可圈定受众、配置变体、录入/修正观测，实时看到结论、冲突与可信度变化。

## 测试

```
python -m unittest test_engine -v
```

含 120 步随机变更序列的性质测试：每一步增量结果都必须等于全量重算。

## 文件

- `engine.py` 核心引擎：数据模型、冲突检测、效果判定、增量更新、一致性校验
- `stats.py` 双比例 z 检验与样本量充足性判断
- `server.py` 标准库 HTTP 服务与 JSON API
- `static/` 单页前端（原生 JS）
