# 储能充放电方案对比决策工具

## 启动

直接双击 `storage-compare.html` 用浏览器打开即可，完全离线、无需安装任何依赖。

## 功能

- 内置 4 套候选调度方案（两充两放 / 一充一放 / 长时平滑 / 大功率短时），逐时仿真充放电、电费价差收益与电池衰减成本。
- 左侧滑杆可调整峰/平/谷电价、负荷峰值、电池年衰减率，所有结果即时重算。
- 每个参数自动扫描全量程，用彩色区间条标出"哪段参数下哪套方案最优"，并列出具体翻转点。
- 不可行方案红色标记，并逐条说明被突破的约束（SOC 上下限、额定功率、变压器容量、日循环次数）。
- 每个参数可"锁定"（固定当前值、退出翻转分析）；也可固定某方案为偏好方案，界面会显示它与最优方案的差距及其占优区间（黄框段）。
- 点击方案卡片可并排查看其 24 小时调度曲线（功率柱 + SOC 曲线 + 电价时段底色）。

## 模型说明（简化假设）

- 效率仅计充电侧（放电按 1:1 交流电量），SOC 每日从下限起始仿真。
- 衰减成本 = 放电量 × 更换成本 / (循环寿命 × DoD) × (年衰减率 / 4%) × 高倍率系数。
- 年净收益按 350 个运行日估算。
- 敏感性扫描为单因素扫描：其余参数保持当前值。
