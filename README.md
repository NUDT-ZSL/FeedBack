# 反馈聚类工作台（离线版）

把零散的原始反馈自动整理成可解释的需求线索：相似问题自动归簇、
每条线索可追溯到原始反馈、人工调整可回放且结果稳定。
纯 Python 标准库实现，无外部依赖、无网络请求，数据只存本地 JSON。

## 启动

```
python run.py            # 默认 http://127.0.0.1:8765
python run.py --port 9000 --data mydata.json
```

浏览器打开后：上方添加反馈（来源/原文/标签），左侧为问题簇列表，
右侧为"边界相似对"判定依据面板。

## 功能与需求对应

1. **接收与维护反馈**：界面添加/修改/删除反馈，含来源、时间、原文、
   可选标签；改动后立即重新聚类。
2. **自动归簇**：字符 n-gram TF-IDF 余弦相似度 + 确定性凝聚聚类，
   每个簇给出代表性描述（中心反馈摘要）与关键词。
3. **边界可解释**：相似度落在阈值 ±带宽 内的反馈对，无论归并与否，
   都保留判定记录（相似度、共同特征、判定原因），阈值微调时可核对，
   不会因阈值微小变化出现无法解释的分组跳动。
4. **人工调整**：界面上支持移动单条反馈到其他簇、拆分簇、合并两个簇，
   操作后立即全量重算并刷新展示。
5. **顺序无关的稳定性**：人工操作不直接改簇，而是记录为
   must-link / cannot-link 约束集合；页面展示的分组永远等于
   "从头重算"的结果，调整顺序不影响最终分组（有测试保证）。
6. **可展开追溯**：每个簇可展开查看全部原始反馈（来源/时间/标签），
   以及簇内/簇间的相似判定依据。

## 目录

```
feedback_app/
  similarity.py   文本向量化与相似度
  clustering.py   确定性约束聚类 + 边界证据
  store.py        状态、约束、持久化（data.json）
  server.py       本地 HTTP API + 静态界面
  static/         单页界面（原生 JS）
run.py            入口
tests/            单元测试：python -m unittest discover -s tests
scripts/e2e_check.py  端到端冒烟：python scripts/e2e_check.py
```
