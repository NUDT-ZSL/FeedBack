# 资金情景推演台

一个零依赖、可本地启动的家庭/小团队收支计划推演工具。

## 启动方式

方式一：双击 `启动应用.bat`，浏览器会自动打开应用。

方式二：在当前目录运行：

```powershell
npm start
```

默认地址为 `http://127.0.0.1:5173`；若端口被占用，服务会自动尝试后续端口。

## 已实现能力

- 维护基础收支计划：名称、类型、金额、起始/结束日期，以及按月、按季、一次性三种重复规律。
- 按日期逐日展开和滚算，得到每日收入、支出、余额、当日缺口和最大累计缺口。
- 在同一次推演中叠加“收入延迟天数、支出提前天数、支出金额上浮百分比”，同时显示基准虚线和情景实线。
- 自动标记余额首次跌破安全线的日期、当时余额、缺口金额，并在图上给出红色标记。
- 缺口明细追溯到具体收支发生记录，列出基准日期、情景日期、基准金额、情景金额和原因标签。
- 任意参数变化立即重新推演；首次跌破由实际现金流确定性计算，不受跌破日之后的无关发生记录影响。
- 数据保存在浏览器 `localStorage`，不会上传到网络。

## 测试

```powershell
npm test
```

测试覆盖重复规律展开、三类情景叠加、首次跌破定位与归因，以及无关参数不改变缺口时点。
