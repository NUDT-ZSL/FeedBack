# 教研评分工作台（离线）

面向培训机构教研组的多维表现评分工具：导入采证记录，按可配置规则
计算综合等级，每条结论可追溯到具体采证。

## 启动

双击 `启动工作台.bat`，或执行 `python server.py`，浏览器会自动打开
工作台界面（http://127.0.0.1:8765）。仅需 Python 3.6+ 标准库，无需联网。

## 功能对照

1. **批量导入**：工作台「导入采证」粘贴 JSON 数组，字段为
   `student / dimension / evaluator / recorded_at / value`，
   同一维度可有多位评价者的多条记录。
2. **可配置规则**：「评价规则配置」中调整每个维度的权重、达标线、
   前置维度，以及等级分数线和等级→分值映射；保存后立即重算。
3. **冲突保留**：同一维度多位评价者取值不一致时，全部记录保留并标红；
   综合等级按冲突区间（最低/最高取值）分别计算，两端等级一致则标记
   「结论稳定」，否则给出等级区间并提示复核。
4. **缺测处理**：未采证维度显式标注「未采证」，不按零分计入，其权重
   从综合分母中剔除，并在综合结论中说明影响。
5. **增量更新**：补录采证只重算该学员；修改规则只重算变化维度及其
   传递后继所影响的学员。「一致性校验」按钮会用全部记录从头重算并与
   增量结果逐一比对。
6. **工作台界面**：启动即进入；左侧学员列表（等级/冲突/缺测标记），
   右侧维度依据明细（评价者、采证时刻、原始取值、归一分值），
   调整规则后立即刷新综合等级。

## 测试

```
python -m unittest test_workbench -v
```

覆盖：缺测不计零、冲突保留与稳定性、前置阻断、增量与全量重算一致。

## 文件

- `engine.py` 评分引擎（纯函数）
- `store.py` SQLite 持久化 + 增量重算 + 一致性校验
- `server.py` 本地 HTTP 服务与 API
- `static/index.html` 工作台界面
- `test_workbench.py` 单元测试
