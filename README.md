# 离线上下文感知检索浏览器

这是一个零依赖、可本地离线启动的检索浏览原型。打开 `index.html` 即可使用；核心逻辑不依赖网络、构建步骤或第三方包。

## 启动

直接用浏览器打开 `index.html`。也可以在本目录运行：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 验证

```powershell
npm test
```

测试覆盖批次异步返回、上下文切换后的过期判定、返回旧上下文时复用、同位置矛盾、上下文局部裁决/排除、恢复提示，以及乱序到达与完整等待的一致性。

`scripts/browser-smoke.mjs` 是供本机核对界面的 Chrome DevTools 冒烟脚本。先用独立临时用户目录启动无头 Chrome 并开放一个远程调试端口，再运行：

```powershell
$env:SMOKE_DEBUG_PORT = "9224"
node scripts/browser-smoke.mjs
```

## 关键模型

- 浏览上下文由规范化后的关键词、类型和页码标识。
- 每个批次进入应用后只归入它出生时的上下文；当前上下文不匹配时不会渲染，但会继续缓存并生成恢复提示。
- 切回旧上下文直接读取已经到达的批次，晚到批次继续补入同一上下文，无需重新等待全部结果。
- 同一位置按内容指纹归并；不同内容并存为多个 claim 并标记矛盾，用户可裁决。
- 裁决和批次排除都保存在具体上下文内，其他上下文不受影响。
- 重新触发不会让旧传输失效；旧、新传输中到达的缺失批次会幂等归并，重复批次只保留一份。
