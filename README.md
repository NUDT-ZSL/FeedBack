# 素材渠道适配工作台

一个零依赖、本地启动的交互式设计运营工作台，用于批量检查素材对不同交付渠道的适配情况。

## 启动

```powershell
npm start
```

启动后会在本机打开 `http://127.0.0.1:5173`；端口被占用时会自动顺延，也可用 `$env:PORT=5273` 指定端口。

## 验证

```powershell
npm test
```

测试覆盖：目标尺寸、宽高比、安全边距、格式转换、可裁切区域变化、渠道规格变化、多渠道折中主裁切和失败渠道标注。

## 数据结构

素材字段：

- `name`：素材名称
- `tags`：用途标签
- `width` / `height`：原始宽高
- `format`：源格式
- `allowedCrop`：允许裁切区域，格式为 `{x,y,w,h}`
- `keyAreas`：必须保护的关键区域，支持多个

渠道字段：

- `targetWidth` / `targetHeight`：目标尺寸
- `safeMargin`：上、右、下、左安全边距百分比
- `acceptedFormats`：可交付格式

界面顶部可导出 JSON，也可载入同结构的 `{ "assets": [], "channels": [] }` 数据。

## 判定规则

- 可适配：原图几何条件可直接满足；若源格式不被接受，导出时转换格式。
- 需裁切：目标比例或原图安全边距不满足，但能在可裁切区域内找到裁切框，并让所有关键区域进入安全区。
- 不可适配：可裁切区域分辨率不足，或不存在同时满足目标比例、分辨率和安全边距的裁切框。

多渠道模式会生成覆盖各渠道取框的统一主裁切；仍无法满足的渠道会单独列出尺寸、比例、边距或格式原因。
