# 移动模式复核台

一个零运行时依赖的本地离线交互工具，用于把带目标标识、时刻和经纬度的位置点推导为可复核的停留段、移动段与同行关系。

## 启动

方式一：直接双击 `index.html`。

方式二：在当前目录运行：

```powershell
python -m http.server 8765
```

然后打开 `http://localhost:8765/`。

## 导入格式

CSV 使用 UTF-8 编码，首行为表头：

```csv
id,targetId,time,lat,lon
P001,A,2026-09-22 10:00:00,31.23040,121.47370
P002,B,2026-09-22T10:00:00+08:00,31.23046,121.47376
```

也支持 JSON 数组，字段相同。页面打开后会自带一份包含采样抖动、时间倒序、重复上报、非法坐标和明显漂移点的样例。

## 判定规则

- 时间倒序：按原始到达顺序检测，点不会删除；正式推导时按时刻重排。
- 重复上报：同目标、同时刻、同坐标的后续上报保留并标记，依据归并到首报。
- 同时刻冲突：同目标同一时刻不同坐标全部保留；首报参与推导，其余不参与插值。
- 明显漂移：高速离开又高速返回原轨迹的点保留并标记为严重异常，不参与连续插值。
- 速度异常：相邻点速度超阈值时保留并提示，供人工复核。
- 停留段：依据点相对聚集中心不超过聚集半径，并且持续时间达到最短停留时长。
- 移动段：不满足停留条件的连续轨迹，停留段之间的连接点会作为端点依据保留。
- 同行：两条轨迹在共同观测区间连续位于同行距离内；超过最大插补空档会断开区间。
- 稳定同行：同行区间达到稳定同行最短时长；否则为偶发接近。
- 多目标群体：同一时间由稳定同行边连通的目标集合，例如 A-B 与 B-C 同时稳定接近。

置信度综合直接观测比例、采样节奏、平均距离、持续时间和共同观测覆盖率。点击任一段、同行区间或点，可查看依据点、共同观测距离、生效参数和异常记录。

## 增量更新

编辑一个点时，只重新规范化该目标，并只重算与该目标相关的目标对；修改聚集半径或最短停留时只更新目标分段；修改同行参数时只更新同行关系。漂移速度改变会影响异常规范化，因此会整体重算规范化结果。

`tests/run-tests.js` 会对局部更新和整体 `analyzeAll` 的结果做结构化深度比较，确保增量结果与整体重推一致。

## 验证

```powershell
node tests/run-tests.js
node tests/browser-smoke.js
```

浏览器冒烟测试默认使用 `C:\Program Files\Google\Chrome\Application\chrome.exe`，页面和分析脚本本身不依赖网络或第三方资源。
