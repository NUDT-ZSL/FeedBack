# 素材适配工作台

纯本地运行的素材适配管理工具：不依赖任何在线服务或外部账号，素材与交付规格都在本机维护，数据保存在浏览器 localStorage 中。

## 启动

直接用浏览器打开 `index.html` 即可；或运行 `start.bat`（等价于 `python -m http.server 8000` 后访问 http://localhost:8000 ）。

启动后直接显示：素材列表、交付规格面板、分配矩阵、适配结论表。首次打开会载入一组示例数据，可随时点「恢复示例数据」重置。

## 功能

- **素材维护**：名称、尺寸、用途、最小可读区域，可新增 / 编辑 / 删除。
- **规格维护**：目标尺寸、安全边距（%）、允许的裁切 / 缩放 / 重新构图策略。
- **自动推导**：在分配矩阵勾选「素材 × 规格」后，按用途与尺寸差异自动给出结论：
  - 宽高比一致 → 直接缩放；
  - 比例不同 → 优先裁切（覆盖式缩放后居中裁切），裁切会破坏约束时退为等比缩放留边；
  - 缩放与裁切都满足不了约束 → 重新构图（需规格允许）。
- **结果隔离**：每个结论只由对应的（素材, 规格, 覆盖）决定，修改某个规格只会重算该规格所在的行，不会静默改变其他规格的结论。
- **冲突标记**：当安全边距与最小可读区域无法同时满足时，行会标红并逐条说明是哪项约束不满足（附可读区 / 安全区 / 可见区的具体数值）。
- **手动覆盖**：结论表中可对单个「素材 × 规格」强制指定缩放 / 裁切 / 重新构图，覆盖后按新策略重新校验约束；其余素材仍按规则自动推导。点「恢复自动」或把覆盖选回「自动」即可撤销。

## 文件

- `index.html` / `styles.css` — 界面
- `engine.js` — 适配推导引擎（纯函数）
- `store.js` — 本地状态与持久化
- `ui.js` — 渲染与交互
- `test-engine.js` — 引擎校验脚本：`node test-engine.js`
