# 仓库月台作业编排工具

纯离线、单文件应用（`index.html`），无需安装任何依赖、无需联网。
双击 `启动.bat` 或直接用浏览器打开 `index.html` 即可使用。

## 功能

1. **载入任务与资源**：左侧表格维护到货任务（到达时窗、作业时长、优先级、
   工作量、可指定班组），上方设置月台数量与各班组产能；支持导入/导出 JSON。
2. **自动编排**：为每个任务确定到达时刻、占用月台与班组，保证同一月台不重叠、
   班组任一时刻总作业量不超过产能、到达时刻落在各自时窗内。
3. **优化目标**：可行解中优先最小化任务等待时长；等待相近时高优先级任务
   优先挑选更早的时段。
4. **稳定性**：在表格勾选"确认"可锁定该任务的编排；之后修改其他任务时，
   已确认的安排保持不变，仅受影响（被修改或冲突）的任务重新编排。
   "全局优化重排"会在保持确认任务不变的前提下重新优化其余任务。
5. **不可行诊断**：若调整后无法满足全部约束，顶部红色面板会列出不可行任务，
   并指出冲突时段与资源（哪个时段月台全满、哪个班组产能不足、被谁占用）。
6. **可视化与操作**：右侧展示月台占用时间线（点击色块定位任务行）和各班组
   负载图（红色虚线为产能上限）；每次调整自动入栈，可点"撤销调整"逐步回退。

## 数据格式（导入 JSON）

```json
{
  "docks": 3,
  "crews": [{"name": "装卸一组", "capacity": 6}],
  "tasks": [{"id": "T01", "name": "冷链-鲜奶", "earliest": 480, "latest": 600,
             "duration": 60, "priority": 5, "workload": 3, "crew": "",
             "confirmed": false, "assignment": null}]
}
```

时间均为 0:00 起的分钟数（480 = 08:00）；`crew` 为空字符串表示任意班组。
