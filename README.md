# 程序化地牢生成 · 连通性检查工具

面向策划的地牢生成预览与可达性验证工具。纯前端实现，无需构建与服务器。

## 使用

直接用浏览器打开 `index.html` 即可。修改左侧任意参数（种子、地图尺寸、房间数量、
走廊数、水域/岩浆比例、目标点数量）会即时重新生成；也可以点击「生成地牢」或
「随机种子」。支持通过 URL 参数分享配置，例如：

```
index.html?seed=flood-0&waterRatio=0.45&lavaRatio=0.3&extraCorridors=0
```

## 功能对照

- 相同种子 + 相同参数必然生成完全一致的地图（FNV-1a 种子哈希 + mulberry32 PRNG）。
- 参数不合法（尺寸倒挂、比例越界、空间不足等）时明确报错，不产出残缺地图。
- 房间经最小生成树 + 额外环路走廊连接，保证基础结构连通；水域/岩浆为不可通行地形。
- 从出生点 BFS 判定每个目标点可达性；不可达的可通行区域在地图上红色高亮，
  左侧面板列出不可达目标坐标与被破坏的约束（水域 / 岩浆 / 复合地形 / 走廊结构）。
- 修改参数导致可达性变化时，黄色提示框说明哪个目标、哪条约束发生了变化。
- 摘要面板展示本次种子、房间数、走廊数、地形格数与可达目标比例，便于对比。

## 文件

- `index.html` — 界面与交互（内联脚本）
- `dungeon.js` — 生成与可达性分析核心（浏览器 / Node 通用）
- `test.js` — 核心逻辑测试：`node test.js`
- `ui-test.js` — 界面交互逻辑测试（DOM 桩）：`node ui-test.js`
