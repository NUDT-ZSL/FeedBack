# 组件变体与约束管理台（离线版）

纯前端、零依赖的交互应用，用于管理界面组件库的属性维度、变体组合与约束规则。

## 启动

直接双击 `index.html` 用浏览器打开即可（Chrome / Edge / Firefox 均可），无需联网、无需安装任何东西。数据自动保存在浏览器 localStorage，可用「导出 / 导入 JSON」迁移。

## 功能对照

1. **录入组件与维度**：顶栏管理多个组件；左侧为每个组件增删属性维度（如尺寸、状态、主题）及其可选值。
2. **组合判定**：右侧「组合判定」选择一组取值，立即显示「有效变体 / 被约束排除 / 结论不可信」，并列出具体依据（哪条互斥冲突、哪条依赖未满足）。
3. **全量列表 + 增量更新**：下方表格列出组件下全部组合及结论；修改维度、取值或约束后只重评受影响的组合，统计栏显示「重评 X / 总数 Y」。
4. **不可信标记**：约束引用了不存在的取值（黄色「引用失效」）或依赖关系构成闭环（紫色「依赖闭环」，Tarjan 强连通分量检测）时，相关组合标为「不可信」，绝不静默跳过。
5. **多依据裁决**：同一组合被多条约束命中时保留全部判定依据；可在约束卡片上点「裁决：忽略」临时排除某条约束，结论即时收敛，也可随时「恢复启用」。
6. **即时反馈**：所有增删改操作即时刷新界面，非法操作（重名、空值、自引用约束等）以 toast 提示错误。

## 约束类型

- **互斥（mutex）**：A 与 B 两个取值不可同时出现在一个变体中。
- **依赖（requires）**：选择了 A 就必须同时选择 B（单向）。
