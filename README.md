# 轨迹分段分析工具

把带时间戳的定位点序列切分为停驻段与移动段,并在地图上核对、调整。

## 启动

```
python app.py
```

或双击 `启动.bat`,然后访问 http://127.0.0.1:5050 (地图瓦片需联网)。

## 功能

- 漂移点识别:乒乓瞬移点自动剔除,精度差的点给出提示,均显示在地图和顶部告警区。
- 停驻判定:同时考虑空间聚集范围(默认 60m)、停留时长(默认 3 分钟)与定位精度(精度差时放宽聚集半径)。
- 待确认段:采样间隔超过 5 分钟(丢点)时,该间隔标为"待确认"并说明原因,不强行归类。
- 分段列表:每段显示起止时间、覆盖范围、里程、平均速度、点数;点击卡片定位到地图。
- 手动调整:每段可重新指定为停驻/移动;相邻同类型段自动合并;不满足原判定条件时给出提示但保留用户决定;整体统计显示调整前后变化。

## 输入格式

JSON 数组 `[{"time":..., "lat":..., "lon":..., "acc":...}]` 或 CSV(表头可选)`time,lat,lon,acc`。时间支持 Unix 秒/毫秒或 `YYYY-MM-DD HH:MM:SS`,`acc`(精度半径,米)可省略。
