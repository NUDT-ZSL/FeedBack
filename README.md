# 专注会话恢复工作台（本地离线）

一套在本地浏览器里**完全离线**操作的专注会话恢复工作台：把阶段时间线、实际计入的工作时长、
剩余额度、净打断区间、多源冲突和「继续进入」的位置全部摊开。打断可事后补报、自动裁剪越界、
扣减重复计入；同一打断的多源矛盾会被完整保留而不是静默择一。

## 启动

直接双击 **`index.html`**（或在浏览器中打开它）。启动即进入可用界面，并预载一份示例会话。

- 零依赖、零构建、零网络请求；断开网络也能用。
- 数据保存在浏览器 `localStorage`，刷新不丢；「清空」可重置。
- 兼容 Chromium/Edge/Firefox/Safari（`core.js` 同时是浏览器经典脚本和 Node CommonJS 模块）。

## 规则如何对应需求

| # | 需求 | 实现位置 |
|---|------|----------|
| 1 | 阶段顺序唯一、预算为正，非法即拒绝并指出位置 | `core.js: validateStages`（错误带 `index/order/message`） |
| 2 | 打断带来源/区间/消解状态；零长、起止颠倒拒绝；重叠区间确定性归并 | `validateInterruptions`、`buildNetIntervals` |
| 3 | 由净打断推出计入时长、剩余额度与恢复位置；重复推导完全一致 | `computeSchedule`（纯函数、无随机/时钟）、`derive` |
| 4 | 事后补报回填、重推受影响阶段及后续起点、越界裁剪并说明、未受影响阶段不变 | `addSourceReport`、`diffSchedules` |
| 5 | 净打断与已计入片段交叠时扣减、给来源台账；同一时刻不计两次；计入+剩余=预算 | `diffSchedules.doubleCountDeductions`、`conservation` |
| 6 | 多源区间/消解结论矛盾时保留双方并生成可读冲突记录，不静默择一 | `detectConflicts` |
| 7 | 时间线/净打断/计入/剩余/冲突标记即时反映补报与消解，并显示拒绝原因 | `index.html` + `src/app.js` |

### 关键模型

- **时间轴**：会话相对「挂钟分钟」，起点 `t=0`；界面以 `HH:MM` 显示（也接受直接填分钟数）。
- **占用窗**：阶段按顺序首尾相接。沿时间轴单趟扫描——工作间隙累计工作分钟，遇到净打断整段
  跳过，攒满预算即窗终点。净打断横跨阶段边界会被精确切开，同一打断不会被重复计入。
- **计入与剩余**：`已计入` = 阶段占用窗内、位于「当前时刻」之前的工作片段总长；
  `剩余 = 预算 − 已计入`，二者之和恒等于预算（界面每行有守恒标记）。
- **当前时刻**：可在右上角手动设定；留空（「自动」）时按连续的「已完成」阶段前缀推断。
- **净打断**：只合并消解结论为「确认成立」的来源记录；排序键
  `(start, end, interruptionId, sourceId)` 全序确定，因此输出与输入顺序无关、可重复。
- **补报**：区间早于 `0` 或晚于当前会话末端会被裁剪并弹出说明；裁剪后为空则拒绝写入。
  回填后与旧的「已计入片段」交叠的部分生成扣减台账（精确到来源与交叠区间）。
- **冲突**：同一打断的来源区间不一致且有重叠 → 区间矛盾；同时存在「成立」与「否决」→
  消解矛盾。双方记录都保留，冲突卡片可一键采纳/否决/标待消解，结果立即重推。

## 界面区块

- **恢复横幅**：继续进入的阶段、已计入与剩余额度。
- **阶段时间线**：占用窗、已计入片段（蓝）、净打断（红）、净打断总览道、当前时刻虚线、
  恢复点三角、冲突圆点；悬停任意元素有明细。
- **冲突标记 / 净打断区间 / 计入与剩余表（含守恒列与迷你占比条）**。
- **阶段维护**：行内改顺序/名称/预算/状态，非法值即时拒绝并标位置。
- **打断记录与多源消解**：每条打断下列出来源、区间、消解结论下拉；底部表单可补报来源。

## 运行测试

```bash
node --test        # 22 个用例，覆盖上述全部规则（含跨边界打断、裁剪、扣减台账、守恒、冲突双方保留）
```
