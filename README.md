# 嵌套标注画布

在同一张可缩放平移的画布上管理可嵌套的矩形标注框，内置移动 / 缩放 / 框选三种手势的仲裁。

## 运行

直接用浏览器打开 `index.html` 即可（无构建、无依赖）。

## 手势仲裁规则（pointerdown 时一次性判定并锁定）

1. 中键或按住空格 → 平移画布（最高优先级）
2. 指针落在某框的边角手柄容差内 → 缩放该框
3. 指针落在已选中的框内部 → 框选
4. 指针落在未选中的框内部 → 选中并移动该框（Shift 追加选择）
5. 其余（空白处）→ 框选

手势类型在按下瞬间锁定，整个拖动期间不再重新判定——框选拖到框内不会变成移动。

## 嵌套语义

- 命中检测最深优先，同层后绘制者优先：拖子框不会带动父框
- 移动父框时整棵子树（所有后代）一起移动，层级顺序不变
- 框选实时高亮所有与选框相交的框，松开后写入选中集（Shift 并集）

## 文件结构

- `index.html` / `style.css` — 页面与样式
- `src/model.js` — 纯逻辑层（数据模型 + 仲裁），无 DOM 依赖
- `src/app.js` — Canvas 渲染与指针状态机
- `test/model.test.js` — 逻辑层单元测试：`node test/model.test.js`

## 操作

滚轮缩放（以指针为中心）· 空格/中键拖动平移 · 拖动框移动 · 拖边角缩放 ·
空白或已选框内拖动框选 · Shift 追加选择 · Delete 删除选中 · Esc 取消/清空
