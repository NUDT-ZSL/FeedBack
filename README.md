# 版式推演工具（本地离线）

检查一组内容块在容器尺寸、对齐关系和间距规则下能否稳定排布，给出可解释的布局结果与冲突原因。零依赖、纯本地：直接用浏览器打开 `index.html` 即可，无需服务器与网络。

## 文件

- `index.html` / `app.js`：界面（布局画布、块编辑器、冲突清单、约束依据面板）
- `engine.js`：纯函数布局引擎，浏览器与 Node 通用
- `sample.json`：示例内容块集合（界面“导入 JSON”可加载）
- `tests/engine.test.js`：引擎单元测试，`node tests/engine.test.js` 运行

## 数据模型

每个内容块：固有尺寸 `intrinsicW/H`、伸缩倾向 `flexGrow`、边界 `minW/maxW/minH/maxH`（空表示不限）、可换行标记 `canWrap`、基线对齐 `baselineAlign`、用户固定尺寸 `fixed:{w,h}`。容器：宽度、内边距、块间距、行距。

## 推导规则

1. 基础尺寸：固定值优先，否则固有尺寸夹到 `[min, max]`；固定值越界时冲突双方均保留并上报。
2. 换行：按顺序贪心填行，行宽不足时 `canWrap` 块移到下一行；不可换行块保留在原行并标记溢出冲突。
3. 行内分配：剩余空间按 `flexGrow` 水位法分配（受 `maxW` 约束）；空间不足按权重压缩（受 `minW` 约束）。压到最小宽度仍不足时间距与最小宽度都不丢弃，整行标记溢出，冲突清单列出全部参与者。
4. 纵向：行高由行内最高块与基线组共同决定；基线对齐块共享行基线，其余顶对齐；内边距、间距、行距共同决定每块坐标。
5. 固定尺寸变更只重推变更块所在行及后续区域（增量重推），界面实时校验增量结果与全链重推哈希一致。

同一输入必得同一输出（结果带哈希，界面右上角可见）。
