# 分段上传与后台转换（本地全栈应用）

围绕“分段接收 → 后台转换 → 界面重试”管理一次大文件上传的完整链路。

## 启动

```powershell
python server.py
```

然后打开 http://127.0.0.1:8766 （可用环境变量 `PORT` 改端口）。
依赖：fastapi、uvicorn（环境中已安装）。

## 功能与对应实现

1. **分段上传 + 暂停/继续**：前端按 2MB 切片逐个上传，网格实时显示每段状态；
   “暂停”停止发送队列，“继续”从断点接着传。
2. **断网重连不重复写入**：每个分段落盘前写临时文件再原子改名；服务端按
   `(upload_id, idx)` 幂等记录，重复分段校验和一致时直接返回 `deduped`，
   不计入 `bytes_written`。客户端用 `client_key`（文件名+大小+修改时间）复用
   会话，重连后先拉取已接收分段列表，只补传缺失分段。
3. **分段失败定位与单独重试**：失败分段在网格中标红，悬停显示原因，点击该
   分段即可单独重试；也可点“继续”重试所有失败分段。
4. **自动后台转换**：最后一段落库后自动进入转换队列，后台线程逐段转换，
   界面每秒轮询显示转换进度与状态。
5. **转换失败断点续转**：每段转换结果先写 `.tmp` 再原子改名并记录到
   `chunk_outputs` 表；失败后已完成分段结果保留，“从失败点恢复转换”从
   失败分段继续，不重做已完成部分。界面提供“模拟转换失败”按钮用于演示。
6. **结果与状态记录**：转换完成后出现下载链接（统一容器格式 `.adc`，
   含原始文件名与每段 SHA-256 校验头）；“状态变化记录”面板展示本次上传的
   全部事件（建会话、每段接收、转换开始/失败/恢复/完成）。

## API 概览

- `POST /api/uploads` 创建/复用上传会话
- `PUT /api/uploads/{id}/chunks/{idx}` 上传分段（幂等、去重）
- `GET /api/uploads/{id}` 查询状态（含已接收分段列表、转换进度）
- `POST /api/uploads/{id}/conversion/resume` 从失败点恢复转换
- `GET /api/uploads/{id}/events` 状态变化记录
- `GET /api/uploads/{id}/result` 下载结果
- `POST /api/uploads/{id}/debug/fail-at` 演示用故障注入

运行数据（SQLite、分段文件、结果）保存在 `data/` 目录。
