# 离线工单同步台

现场人员弱网/断网可继续编辑工单，恢复连接后与服务端逐字段对账合并的全栈演示。零依赖，只需要 Node.js。

## 启动

```
npm start
```

打开 http://localhost:3000 ，直接进入工单编辑界面。

## 演示流程

1. 点「断开连接」，对工单的标题/正文/负责人做多次编辑——界面即时更新并标记「待同步」，右侧面板可见操作队列。
2. 同一字段改多次时，队列中只保留最终意图参与合并，展开「过程记录」可回看每次修改的旧值/新值与顺序号。
3. 点某工单的「模拟服务端变更」（模拟其它终端改了同一工单）。
4. 点「恢复连接」→「立即同步」：服务端未变的字段安全应用；已被服务端改过的字段判定为冲突。
5. 冲突卡片并列展示本地意图与服务端当前值，可选保留一方或手工输入合并结果，提交裁决。
6. 裁决只重算受影响工单的受影响字段，其它已同步结果保持不变（见同步日志中的版本变化）。

## 机制说明

- 每条离线操作记录 `{seq, woId, field, oldValue, newValue, ts}`，持久化在 localStorage，刷新页面不丢。
- 提交前按字段合并（coalesce）：`baseValue` 取首次修改前的值，`value` 取最终值，按工单顺序提交。
- 服务端逐字段判定：当前值 == baseValue → 安全应用；== value → 幂等跳过；否则返回冲突三元组 `{baseValue, localValue, serverValue}`。
- 冲突不静默择一，必须由用户在界面上裁决（本地 / 服务端 / 手工合并）后走 `/resolve` 提交。
- 服务端数据存 `data.json`，删除后重启即恢复种子数据；界面「重置演示」一键还原。
