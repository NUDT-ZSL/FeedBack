# 版本回看工作台(本地离线)

管理长文档多人多轮编辑的版本血缘,支持问题标记、任意两版本对比、
修正后仅受影响结论精准更新、撤销后后代待处理重接。

## 启动

```
python server.py
```

浏览器打开 http://127.0.0.1:8765 (仅依赖 Python 标准库,完全离线)。

## 使用

- 左侧为版本血缘图:红框=问题版本(缺失父版本/血缘闭环),黄框=待处理,
  灰虚线=已撤销。单击节点查看详情,双击设为对比 A,Shift+双击设为 B。
- 右上对比面板:显示分叉点、两侧各自独有的改动摘要,以及差异依据的版本链。
- 选中版本面板:可修正摘要(仅依赖该版本及其后代的对比结论会被重算,
  其余缓存结论在"对比结论缓存"面板中标注为"保持不变")。
- 撤销版本:其直接后代自动标为"待处理",并在详情中给出可选新父版本
  (祖父优先、同作者优先),指定后血缘立即重接。
- 顶部"补录版本"可继续录入新记录;数据持久化在 `data/versions.json`,
  首次启动从 `data/seed_versions.json` 复制。

## 文件

- `core.py` 血缘校验(缺失父/闭环)、分叉点与差异计算、对比结论缓存精准失效
- `server.py` 本地 HTTP 服务与 JSON API
- `static/index.html` 单页界面
- `test_core.py` 核心逻辑自测:`python test_core.py`
