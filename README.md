# 技能训练营评分工作台

面向教练的评分工具：维护评分方案（维度、权重、等级划分），逐项打分后实时得到总分、等级与可读的评价依据。

## 启动

直接用浏览器打开 `index.html` 即可；或运行：

```
npm start        # 在 http://localhost:8000 启动静态服务
```

## 功能

- **评分方案维护**：若干评分维度，各有权重、缺省分、缺分策略与等级划分；权重合计不为 100 时界面告警，可一键归一化（计算时始终按归一化权重保证整体一致）。
- **实时重算**：调整任何维度的原始分或权重，总分、各维度等级与得分贡献立即刷新，正在输入的框不丢焦点。
- **评价依据**：说明总分构成，指出拉高/拉低结果的维度（与总分对比），并标出落在最低档、触发降级的关键维度。
- **缺分处理**：每个维度可配置缺省策略——按 0 计、按缺省分计、或剔除该维度并将其权重分摊到其余维度；缺分维度在界面和依据中均有明确标注。
- **等级变化对照**：分数或权重调整导致总分跨越等级边界时，界面顶部弹出提示，并在「等级变化对照」中保留改动前后的总分、等级与完整依据文本。
- **多学员**：可切换、新增学员，数据保存在浏览器 localStorage。

## 结构

- `engine.js`：纯评分逻辑（计算、解释、等级变化检测），浏览器与 Node 共用。
- `app.js` / `index.html` / `styles.css`：工作台界面。
- `test/engine.test.js`：引擎单元测试；`test/ui.smoke.test.js`：基于 jsdom 的界面冒烟测试。
