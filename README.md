# 版式推演工具（本地离线）

检查一组内容块在容器尺寸、对齐关系和间距规则下能否稳定排布，给出可解释的布局结果与冲突原因。纯 HTML + 原生 JS，零依赖、零网络，直接双击 `index.html` 即可使用。

## 文件

- `index.html` / `styles.css` / `app.js` — 界面：布局画布、冲突清单、块属性编辑、约束依据
- `engine.js` — 推演内核（纯函数，浏览器与 Node 通用）
- `sample-blocks.json` — 示例内容块集合（界面"读取 JSON"可载入）
- `test-engine.js` — 内核验证：`node test-engine.js`

## 功能对照

1. **读取与编辑**：载入/导出 JSON；每块含固有尺寸、grow/shrink 伸缩倾向、min/max 边界、可换行标记、基线偏移，均可在右侧面板编辑。
2. **整链重推与确定性**：容器宽度或任一块属性变化即重推整条布局链；内核为纯函数，同一输入输出完全一致（测试 [1] 验证）。
3. **冲突保留**：同一轴向冲突（如固定宽度 vs 自身边界、行最小需求 vs 容器宽度）双方均保留在冲突清单中，被挤压块标橙、溢出块标红，不静默丢弃（测试 [3][4]）。
4. **对齐与间距共同推导**：相邻间距 gapX、行基线对齐（行基线 = 行内最大基线偏移）、容器内边距在同一条推导链中共同决定每块位置（测试 [2]）。
5. **手动固定与增量重推**：勾选"手动固定宽"后只从受影响行起重推，前缀行复用；每次增量结果都与整链全量重推逐块比对，顶栏显示"与整链全推一致 ✓"，不一致自动回退全量（测试 [5][6]，200 组随机场景全过）。
6. **即时可视化**：画布按状态着色（固有/拉伸/压缩/被挤压/溢出/固定），行分隔线与基线参考线直接画出；点击任意块或冲突项即可看到该块的约束依据与推导过程。

## 推演链顺序

1. 贪心断行（仅在 `canBreakBefore` 的块前允许换行）
2. 行内轴向分配：剩余空间按 grow 比例分配（受 maxW 钳制）；超出按 shrink×固有宽加权压缩（受 minW 钳制）
3. 固定尺寸为硬约束，与边界/容器冲突时记录 `pin-vs-bounds` / `overflow`
4. 行高由基线对齐共同决定：行基线 = max(基线偏移)，行高 = 基线 + max(基线下余量)
5. 位置 = 内边距 + 间距累计

## 验证

```
node test-engine.js
```

20 项断言：确定性、间距/内边距/基线联合定位、冲突双方保留、固定值不被钳制、增量==全量（200 组随机场景）、增量只重推受影响行。
