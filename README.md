# 点云 LOD 查看器

本地可启动的三维点云查看器，面向大规模点云：八叉树 LOD、视距驱动细节选择、
视锥裁剪、按需加载、密度平滑过渡、实时 HUD 状态面板。

## 启动

```
run.bat                 # 生成示例数据并启动服务（自动打开浏览器）
# 或
python scripts/make_sample.py
python server/app.py --port 8791 --load data/sample.ply
```

打开 http://127.0.0.1:8791/ ，在左上角面板中：

- 选择本地点云文件上传（.ply / .xyz / .txt / .csv / .pts），或
- 输入服务器上的文件路径点击「加载路径」，或
- 点击「加载示例数据」。

## 交互

左键旋转，右键平移，滚轮缩放。勾选「按细节层次着色」可直观看到
近处高层级（细节多）、远处低层级（细节少）的分布。

## 实现要点

1. **解析**：后端 numpy 解析 PLY（ascii / binary_little_endian）与 XYZ 类文本，
   提取坐标与 RGB 颜色。
2. **LOD 构建**：八叉树递归划分；每个节点按网格采样保留一份代表性子集
   （每点只存于一个节点），层级越深采样越密。
3. **按需加载**：前端每帧从根节点遍历，依据节点采样间距的屏幕张角
   （约 2 像素阈值）决定细化或停留；视锥外的子树直接跳过，未加载的
   节点异步请求（并发上限 8），只拉取可见所需节点。
4. **平滑过渡**：层级阈值带 30% 滞回（hysteresis）防止边界抖动；
   每个节点的显示权重随时间缓动，点级别用稳定哈希随机值做密度渐显/渐隐，
   跨层级切换无闪烁、无跳变。
5. **占位**：目标节点未就绪时渲染最近的已加载祖先节点作为低细节占位，
   数据到达后自动替换。
6. **HUD**：实时显示帧率、绘制点数、已加载/加载中节点、占位节点数、
   各层级节点分布条形图；自适应点预算（默认 250 万点）在超预算时
   自动提高阈值以稳定帧率。
