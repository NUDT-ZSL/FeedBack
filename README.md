# 运营指标异常归因推演台

零依赖本地应用，用于导入按天记录的运营指标与事件记录，识别异常区段、排序候选原因，并支持人工确认、排除、调权和结论版本对比。

## 启动

Windows 双击 `start.bat`，或在当前目录执行：

```powershell
python serve.py
```

浏览器会自动打开 `http://127.0.0.1:8765/index.html`。启动后会自动载入一份订单量与运营事件样例，可直接体验完整流程。

## 数据格式

指标 CSV 至少包含时间列和数值列，可选指标名称列：

```csv
date,metric_name,value
2026-09-01,订单量,12034
```

事件 CSV 至少包含时间列和事件类型列，可选描述：

```csv
date,event_type,description
2026-09-01,营销Push,暑期活动推送
```

兼容的列名包括 `date/time/timestamp/日期/时间`、`value/metric_value/指标值/数值`、`metric_name/name/指标名称`、`event_type/type/event/事件类型`。

## 主要能力

- 使用滚动稳健基线（中位数、MAD/IQR）识别连续异常波动，默认连续 2 天异常或单日 Z 分数 ≥5.5，输出起止日期、方向、峰值偏离、Z 分数和影响天数。
- 根据区段开始前的历史事件命中率、提升度、相关性和 0–3 天时间临近度排序候选原因，避免后续数据反向泄漏。
- 标记证据不足、历史方向矛盾、事件共线混杂，以及缺失/重复数据对具体区段的影响。
- 候选原因支持确认、排除和 0.1–2 倍权重调整；仅重算当前区段，其他区段结论保持不变。
- 记录每次归因调整，可查看调整前后的主因、份额和候选状态差异。
- 可导出包含结论、证据、数据质量和变更历史的 JSON。
