# 本地离线三维层级变换推演工具

零依赖、可离线运行的场景层级与父子变换链检查工具。直接双击打开 `index.html`，或在本目录运行任意静态服务器后访问该文件。

## 功能

- 新建、导入、导出对象树；每个对象包含局部位移、XYZ 欧拉旋转和三轴缩放。
- 左侧显示场景层级，支持拖拽对象到另一个对象上来改变父级。
- 中间 3D 预览显示父子连线、对象形状、镜像/剪切警告、锁定标记和世界轴。
- 右侧显示局部 TRS 与推导出的世界位置、朝向、缩放、行列式和诊断原因。
- 沿父子链用完整仿射矩阵 `T_parent * T_local` 合成世界变换。
- 修改对象时只重算它的子树；状态栏显示重算对象和世界矩阵实际变化对象。
- 锁定对象的最终姿态后，修改祖先会自动在目标与锁之间选择最近的可动补偿节点，用新的局部 TRS 冻结锁定子树。
- 若目标与锁之间没有可动对象，或补偿必须引入剪切/奇异矩阵，操作整体回滚并给出原因。
- 重挂父级时默认保持对象世界姿态；新父级不可逆或会导致剪切时拒绝操作。
- 明确标记缺失父级、父子环、零缩放/不可逆矩阵、非均匀缩放与旋转混合产生的剪切。
- 负缩放造成的镜像作为警告显示，同时保留原始仿射矩阵和行列式；规范显示的 XYZ 缩放不被误认为普通缩放。
- 撤销/重做使用整场景快照；撤销后重新求解并同步锁定、异常标记和增量诊断。

## 操作

- 左键拖动物体：在当前视角平面内移动。
- 拖动物体上的红/绿/蓝轴：沿世界轴方向移动。
- 空白处左键拖动：旋转视角；滚轮缩放。
- 左键单击层级或物体：选择并在检查器编辑。
- `Ctrl+Z` 撤销，`Ctrl+Y` 重做。

## JSON 格式

```json
{
  "nodes": [
    {
      "id": "root",
      "name": "根对象",
      "parent": null,
      "translation": [0, 0, 0],
      "rotation": [0, 0, 0],
      "scale": [1, 1, 1],
      "locked": false,
      "color": "#67b7dc",
      "shape": "box"
    }
  ]
}
```

`rotation` 使用角度制 XYZ 欧拉角；`parent` 为父对象 `id` 或 `null`。导入时允许缺失父级和父子环存在，系统会把相关对象标为不可信，而不是静默忽略。

## 验证

```powershell
npm test
npm run test:browser
npm run check
```

核心回归覆盖：世界合成、增量与全量一致、锁定补偿、不可动锁定链回滚、剪切识别、镜像警告、缺失/成环结构、重挂保姿态和撤销恢复。浏览器冒烟会用本机 Chrome 的 DevTools Protocol 实际加载页面。

## 文件

- `src/math.js`：矩阵、欧拉角、仿射逆变换和剪切/镜像/奇异性分析。
- `src/core.js`：层级求解、增量更新、锁定补偿、结构诊断、撤销重做。
- `src/app.js`：层级树、3D Canvas 预览、检查器和文件交互。
- `src/scene.js`：内置示例场景。
- `tests/core.test.js`：Node 核心算法回归。
- `tests/browser-smoke.mjs`：真实 Chrome DOM/运行时冒烟。
