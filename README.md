# 三维结构部件锚定标注工具

基于 Three.js 与 Vite 的自包含示例，用于在三维结构部件表面创建标注，并在相机移动、部件移动、旋转、缩放或父子层级变化时持续重新推导锚点。

## 启动

```powershell
npm install
npm run dev
```

生产构建与测试：

```powershell
npm run build
npm test
```

## 操作

- 鼠标左键旋转、右键平移、滚轮缩放。
- 勾选“表面点选标注”后点击部件表面，可创建标注。
- 取消勾选后点击部件，可使用移动、旋转、缩放控件。
- 在左侧面板可编辑名称、位置、朝向、尺寸、颜色和父级部件。
- 标注文字、像素偏移和局部锚点可单独编辑；文字和偏移只更新该标注的显示。
- 删除部件、父级链断裂、尺寸非法、锚点越界或不在表面时，标注会保留并显示失效提示。

## 数据模型

标注不保存世界坐标，只保存依附部件和该部件局部坐标系下的锚点：

```json
{
  "parts": [
    {
      "id": "part-1",
      "name": "主梁",
      "parentId": null,
      "position": [0, 0.5, 0],
      "rotationDeg": [0, 20, 0],
      "size": [4, 0.6, 0.8],
      "color": "#4f8dd6"
    }
  ],
  "annotations": [
    {
      "id": "ann-1",
      "partId": "part-1",
      "anchor": [0.5, 0.25, 0],
      "text": "检测点",
      "offset": { "x": 28, "y": -24 }
    }
  ]
}
```

盒体几何采用单位局部盒，局部锚点有效范围为 `[-0.5, 0.5]`，且至少一个坐标必须位于表面。世界矩阵为父级世界矩阵乘以部件局部 TRS 矩阵；表面法线使用该矩阵的法线矩阵变换，以支持非均匀缩放。

## 关键文件

- `src/core.js`：变换链、锚点校验、法线和屏幕投影。
- `src/sceneView.js`：Three.js 相机、控制器、拾取、遮挡检测和部件场景图。
- `src/main.js`：状态、导入导出、标注渲染、面板编辑和失效提示。
- `src/core.test.js`：变换链、缩放、失效与投影测试。
