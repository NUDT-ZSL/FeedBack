# 地理围栏推演工具

纯本地、零依赖的单页应用：在地图上绘制多边形围栏并配置规则，导入带时间戳的轨迹点后，
按时间顺序推演进入 / 离开 / 停留超时 / 超速事件，并在时间轴上展示事件序列、触发位置与判定依据。

## 启动

- 双击 `start.bat`，或直接用浏览器打开 `index.html`（无需服务器、无需联网）。
- 也可以 `python -m http.server 8000` 后访问 http://localhost:8000 。

## 功能与规则语义

1. **围栏绘制与编辑**：工具栏「绘制围栏」连续点击加点、双击或回车完成；「编辑/选择」模式下
   拖拽顶点调整形状、右键顶点删除、点击围栏选中；滚轮缩放、空白处拖拽平移。
   每个围栏可配置：优先级、进入、离开、停留超时（阈值秒）、超速（限速 km/h）、
   最小停留时长、最小穿越时长。
2. **轨迹推演**：导入轨迹后按时间排序，逐点判定所属围栏，生成进入 / 离开 / 停留超时 / 超速事件。
   速度列缺失时由相邻点距离 / 时间差自动推算。
3. **抖动过滤**：出界持续时间短于「最小穿越时长」判定为边界抖动，不产生离开 / 再进入；
   入内持续时间短于「最小停留时长」判定为短暂穿越，进入 / 离开被过滤。
   被过滤的候选会记录在「被压制的候选事件」面板中。
4. **冲突消解**：围栏重叠时，每个点只归属优先级数值最小的围栏；其余围栏在该时刻的候选事件
   被压制并标注原因，保证每个时刻只有唯一事件结果。离开事件按出界前最后一个内部点判定归属。
5. **重新推演**：修改围栏形状、规则阈值或重新导入轨迹后，点击「重新推演」
   （或勾选自动推演）即可看到事件序列、触发位置和判定依据的变化。点击时间轴上的事件，
   地图会高亮触发位置并显示判定依据。
6. **无效数据**：缺失时间戳、坐标非法或经纬度超范围的点会被跳过，并在「数据提示」面板
   逐行列出，不会中断推演，也不会对无效点产生任何事件。

## 轨迹数据格式

CSV（支持表头，列名识别 time/x/y/lat/lon/speed）或 JSON 数组：

```csv
time,x,y,speed
2026-09-22T10:00:00,100,120,30
```

- 坐标默认为局部平面米坐标（x, y）；列名含 `lat`/`lon` 时按经纬度处理（自动投影到局部平面）。
- `time` 支持 ISO 字符串、epoch 秒 / 毫秒；`speed` 单位 km/h，可省略。
- `samples/track-jitter.csv`：含边界抖动、短暂穿越、停留、超速的完整轨迹（配合「加载示例场景」的围栏）。
- `samples/track-invalid.csv`：含缺时间戳、非法坐标的脏数据，用于验证跳过与提示。

## 测试

引擎与 UI 解耦（`js/engine.js` 纯函数），可直接用 Node 运行单元测试：

```
node test/engine.test.js
```

覆盖：基本进入 / 停留 / 离开、边界抖动过滤、短暂穿越过滤、超速分组、
重叠围栏优先级消解、规则开关。
