# 响应式布局规则推演工作台

离线、零依赖的交互应用：把设备预设、布局规则与多设备结果比较放在同一个工作台里推演。
直接双击 `index.html` 即可在浏览器中打开（无需网络、无需构建）；也可运行 `start.bat` 用本地静态服务打开。

## 功能与需求对应

1. **设备预设**：左栏维护设备（视口宽度 / 像素密度 / 方向），支持增删改，点击卡片切换预览目标。
2. **布局规则**：中栏维护规则（适用宽度区间 / 优先级 / 一组 `key=value` 布局属性），同一属性可被多条规则命中。
3. **冲突裁决**：同一属性被多条规则命中时，先按优先级、再按区间收窄程度裁决；被压制候选及其依据完整保留在预览表格中，绝不静默择一。完全并列时标记为"未裁决冲突"，由用户人工选定。
4. **来源可追溯**：预览中每个设备每个属性都显示最终取值及其来源（规则名或人工裁决），人工裁决可撤销。
5. **增量更新**：修改规则 / 调整优先级 / 人工裁决后，只重算受影响设备预设的结论；点击顶栏"全量重推校验"可随时验证增量结果与全量重推完全一致。
6. **缺口标出**：规则区间未覆盖的宽度段、同优先级区间重叠、无规则命中的设备，都会在诊断面板与预览中标红，系统不提供默认值。

## 目录结构

- `index.html` / `css/styles.css` —— 页面与样式
- `js/engine.js` —— 裁决引擎（纯逻辑，浏览器与 Node 通用）
- `js/app.js` —— 状态管理、增量更新调度、渲染
- `test/engine.test.js` —— 引擎单元测试（含 500 轮随机"增量==全量"验证）
- `test/app.smoke.test.js` —— jsdom 端到端冒烟测试

## 运行测试

```
node test/engine.test.js        # 纯引擎测试，无需依赖
npm install                     # 仅冒烟测试需要 jsdom
node test/app.smoke.test.js
```

数据保存在浏览器 localStorage 中，顶栏"重置示例"可恢复内置演示数据。
