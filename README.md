# 用户反馈聚类工作台

把零散用户反馈自动聚成问题簇，支持人工修订，并生成需求线索。

## 运行

```
python app.py
```

打开 http://127.0.0.1:5050 （端口 5000 常被占用，故用 5050）。

## 功能与需求对应

1. **导入**：界面粘贴（每行一条）或上传 txt 文件，导入后立即展示每条反馈及初始归属。
2. **自动聚类**：BAAI/bge-small-zh-v1.5 语义向量 + average-linkage 层次聚类
   （模型不可用时自动回退字符 n-gram TF-IDF），每簇给出 medoid 代表性描述。
3. **人工修订**：成员下拉移动到其他簇/新簇；勾选簇合并；勾选成员拆分，界面实时刷新。
4. **一致性**：聚类结果不落地保存，每次操作后由「反馈全集 + must/cannot-link 约束」
   从头全量重算，服务端返回 `consistent` 校验位（每条反馈恰好归属一个簇）。
5. **冲突裁决**：相似度超阈值却分属不同簇的反馈对会列入「相似冲突」面板，
   研究员选择"保留同簇"或"保持分开"，决策写入日志并作为约束参与重算。
6. **需求线索**：由最终聚类结果派生，关联来源反馈 ID，默认按簇规模降序，可点击表头切换。

## 验证

```
python verify.py
```

覆盖：导入聚类、移出/移入、拆分、合并、冲突双向裁决、每步一致性校验、线索排序。

## 文件

- `app.py` — Flask 后端（聚类引擎 + REST API）
- `static/index.html` — 单页工作台
- `static/sample_feedback.txt` — 示例反馈
- `verify.py` — 端到端验证脚本
- `state.json` — 运行后生成的持久化状态（反馈 + 约束 + 决策日志）
