# 无障碍语义树与朗读顺序工具（本地离线）

帮助无障碍工程师把界面元素整理成语义树，并实时预览屏幕阅读器的朗读
顺序。纯 Python 标准库 + 原生 HTML/JS，不依赖任何在线服务或第三方包。

## 启动

```
python server.py            # 默认 http://127.0.0.1:8000 ，自动打开浏览器
python server.py --port 9000 --no-browser
```

Windows 也可以直接双击 `start.bat`。

## 功能

1. **元素录入**：角色（role）、可读名称、父元素、同级顺序，构建初始语义树。
2. **调整校验**：调整归属 / 顺序 / 角色 / 名称时，校验循环归属、孤立
   节点、必读名称缺失；非法调整整体拒绝，语义树保持原状。
3. **朗读顺序预览**：每次调整后展示先序遍历的朗读序列，以及被跳过的
   元素及原因（presentation/none 角色、无名称的非地标容器）。
4. **冲突提示**：被阻止的调整会指出具体元素与冲突关系（父子归属 /
   可读名称 / 标识）。
5. **历史方案**：每次成功调整生成一个快照，可在历史列表中来回切换；
   在旧方案上继续调整会产生新分支。

## 规则约定

- `button`、`link`、`checkbox`、`textbox` 等交互角色必须有可读名称。
- `presentation` / `none` 角色自身不朗读，但子元素仍会被读到。
- 无名称且非地标角色（如 generic/group）会被跳过。
