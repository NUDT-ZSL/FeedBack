# 坐标转换与精度推演工具（本地离线）

纯前端、零依赖、完全离线。直接用浏览器打开 `index.html` 即可使用
（双击运行 `启动.bat` 也可以，仅用于打开该页面）。

## 功能

- 点集合管理：每个点带坐标表示（WGS84 / GCJ02 / BD09 / Web墨卡托）、
  参考基准、来源精度，支持新增、修改、删除。
- 转换链管理：链由有序步骤组成，步骤含源表示、目标表示、精度损失；
  链可复用（多个点共用）、可调整（增删步骤、改参数、调顺序）。
- 基准校正：每条链可按点所属基准配置东移/北移/损失参数，
  推演时作为第 0 步应用并记入轨迹。
- 逐级推演：按步骤顺序传播坐标与精度，轨迹中给出每一步的
  中间坐标与精度变化（精度按平方和根 RSS 合成）。
- 增量重推：修改步骤或基准参数时只重推受影响的点，
  并自动校验增量结果与全量重推一致（日志栏显示校验结论）。
- 断链检测：表示不匹配、缺少转换实现、未指定链时，
  明确指出断点位置并拒绝输出该点最终坐标。
- 轨迹查看：选中任一点即可查看完整换算轨迹与每一环节的精度来源。

## 精度模型

各步骤引入的误差视为相互独立，按平方和根合成：
`acc_after = sqrt(acc_before^2 + loss^2)`。

## 数据

所有数据仅保存在本机浏览器 localStorage（键 `coordtool.state.v1`），
不上传、不联网。首次打开自动载入示例数据。

## 验证

- `node test.js`：引擎自动化测试（往返转换、精度传播、断链检测、
  增量与全量一致性）。
- `node smoke.js`：UI 初始化渲染冒烟测试（Node + 极简 DOM 桩）。
