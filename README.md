# 储能调度方案离线对比台

零依赖的本地 HTML 工具，用于比较多套储能分时段充放电方案在电价、负荷峰值、电池健康度和衰减成本变化下的经济收益、削峰效果、安全裕度与可行性。

## 启动

直接双击 `index.html`，或在 Windows 上双击 `start.bat`。不需要联网、不需要安装 Node.js、Python 或浏览器插件。

建议使用 Chrome、Edge 或 Firefox 的近期版本。数据保存在当前浏览器的 LocalStorage 中；“恢复示例”会清空当前编辑并回到内置样例。

## 功能

- 维护多套候选方案：方案名称、额定电量、额定功率和 24 小时功率安排均可编辑。
- 逐时段推演：功率正数为放电、负数为充电；自动计算 SOC、净负荷、峰荷削减、套利收益、需量收益、衰减成本和净收益。
- 参数即时重算：分时电价、24 小时原始负荷、峰谷价差系数、负荷峰值、SOH、衰减成本、需量电价和取舍权重均可调整。
- 排序翻转：对每个未锁定参数做扫描，并用二分法细化成对方案交叉点和推荐方案切换区间。
- 约束检查：标出功率超出当前 SOH 可用功率、SOC 越上下限、放电超过本地负荷、日终 SOC 不满足连续运行要求等问题。
- 锁定参数：锁定后参数不随情景按钮变化，也不参与敏感性扫描，其他参数仍统一重算。
- 固定偏好：可调整净收益、安全裕度、削峰效果三项权重，也可固定执行某方案；固定方案不改变原始经济和约束结果，只改变执行建议标识。
- 离线导出：导出当前参数、电价、负荷和方案为 JSON。

## 内置模型

- 充电能量增量：`充电功率 × 充电效率`
- 放电能量消耗：`放电功率 ÷ 放电效率`
- 内置综合效率参数为 93%，演示中对充、放电各使用其平方根，使循环总效率约为 93%。
- 当前可用电量与可用功率均按 SOH 线性折减。
- 套利收益按每小时功率与电价计算；放电为收入、充电为成本。
- 需量收益按“原峰荷 - 优化后净峰荷”估算，并按月需量电价折算到单日：`削峰(kW) × 需量电价 / 30`。
- 衰减成本：`日吞吐电量(kWh) × 基础衰减成本 × (2 - SOH)`。
- 综合分使用 0–100 的收益、安全、削峰指数，并按界面权重加权；不可行方案不参与可行排序。

## 边界说明

敏感性区间只表示工具设定的扫描范围，不向范围外外推。端点由离散网格定位后做二分细化，适合方案初选；工程执行前仍应以实测电池参数、合同电价、逆变器效率曲线和完整功率平衡模型复核。
