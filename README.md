# 假设与证据验证工作台（离线版）

一套零依赖、离线可验收的产品假设验证工作台。双击启动即用，所有数据保存在浏览器本地。

## 启动

- **Windows**：双击 `启动工作台.cmd`（或直接双击 `index.html`，推荐 Chrome / Edge）。
- **任意系统**：用浏览器打开 `index.html`。无需联网、无需 npm install、无需后端。
- 首次打开自带一套演示数据；右上角可「重置为演示数据 / 清空 / 导出 JSON」。

## 验收自检

```bash
node tests.js
```

45 项断言覆盖下面 7 条需求，全绿才视为通过；退出码非 0 即失败。另有 40 组随机增量操作的
压力测试，校验「增量重算结果 === 从头全量重算结果」。

## 需求对照

1. **假设维护**：唯一标识、判断陈述、目标人群、验证状态。陈述为空、标识缺失/重复、人群为空
   一律拒绝，错误信息指出字段位置；被拒绝时状态不发生任何改变。
2. **观察材料字段**：每条材料带来源标识、采集时刻（`YYYY-MM-DD HH:mm`）、指向假设、
   支持/反驳立场、质量与人群标签。**来源、时刻、立场任一缺失都不会默认通过**——材料仍留存在
   时间线，但被黄色标记、逐条说明原因，且不计入证据；补全更正后自动解除标记。
3. **独立性**：
   - 同一来源被引用 N 次只算一条证据（界面显示「合并记录 N 条」，质量取最强）。
   - 来源间可声明**同源**（对称等价）与**派生**（有向，原始 → 派生）。
   - 派生关系禁止成环（直接环、长链环都会被拒绝并给出现存路径）；同源组之间禁止再声明派生；
     自环、重复声明同样拒绝。
   - 独立来源组 = 同源等价类与派生边构成的无向连通分量。判定结果与登记顺序无关（有专项测试）。
4. **结论强度**：按证据质量（高/中/低 = 3/2/1）、独立来源组数、人群细分覆盖率、反证强度
   四维合成：强支持 / 支持 / 弱支持 / 证据不足 / 弱反驳 / 反驳 / 强反驳 / 无法判定。
   界面逐档列出每项硬条件及实际值；档位相同的假设按标识字典序排名。
5. **正反并存**：支持与反驳始终同时保留，量化双方权重、占比与差距；权重持平或占优方不足 2/3
   一律判「证据不足」，不强行定论。同一独立来源组内出现互相矛盾的立场时，该组不计入任何一方
   并被点名要求裁决。
6. **增量重算**：新增/更正材料、撤回证据、声明或移除来源关系、调整假设人群后，只重算受影响的
   假设；引擎每次变更都同步做一次从头全量重算并逐字段比对（界面反馈条显示 parity ✓），
   未受影响假设的结论对象保持不变。
7. **界面**：左栏假设列表（档位徽章 + 同分排名）、中部结论详情（正反条、逐档依据、独立证据单元）
   与证据时间线 / 来源依赖关系图（虚线框 = 独立来源组，红箭头 = 派生方向），右栏登记材料、
   批量粘贴、声明同源/派生。任何登记、撤回、关系变更后立即弹出：档位前后变化、判定依据、
   重算范围与拒绝原因。

## 文件

| 文件 | 说明 |
| --- | --- |
| `engine.js` | 纯函数验证引擎（浏览器与 Node 共用，UMD，零依赖） |
| `index.html` | 工作台界面（内嵌样式与 UI 逻辑，仅引用同目录 engine.js） |
| `tests.js` | 45 项离线验收 + 随机化增量一致性压力测试 |
| `启动工作台.cmd` | Windows 一键启动 |

## 评分口径（可按需调整 `engine.js` 常量）

- 质量权重：高 3 / 中 2 / 低 1；一个独立来源组的权重取组内最高质量。
- **强档**：占优方独立来源 ≥ 3、平均质量 ≥ 中、权重占比 ≥ 75%、无组内立场矛盾、
  人群覆盖充分（或未声明细分）。
- **中档（最低定论门槛）**：独立来源 ≥ 2、权重占比 ≥ 2/3、人群覆盖不为「不足」。
- 其余达到 2/3 门槛的情形为弱档；未达门槛或持平为证据不足；没有有效材料为无法判定。

## 数据与隐私

数据仅保存在当前浏览器的 localStorage 中，可随时「导出 JSON」留档；清空浏览器站点数据即删除。
