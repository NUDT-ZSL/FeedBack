# 长期资产价值轨迹工作台

一个无需构建、可在本地启动的交互式资产折旧评估工具，用于管理多项长期资产的初始投入、启用时间、预计使用年限、残值率和年度价值调整，并即时查看逐年账面价值轨迹与警戒触发点。

## 启动

```powershell
npm start
```

启动后访问：

```text
http://localhost:4173
```

也可以直接用浏览器打开 `index.html`。数据通过浏览器 `localStorage` 保存在当前浏览器与当前站点下，不会上传到服务器。

## 验证

```powershell
npm test
```

测试覆盖直线折旧、单项调整、撤销恢复、警戒年份、错误资产隔离和残值底线。

如果本地服务已启动，还可以运行真实浏览器冒烟测试：

```powershell
npm run test:browser
```

## 计算口径

- 基础折旧采用直线法：年度折旧 =（当期年初账面价值 - 残值）/ 剩余使用年限。
- 价值调整在所选使用年度的年初生效：
  - 正数表示追加投入或增值；
  - 负数表示减值。
- 调整年度及之后的折旧自动重算；最后一个使用年度通过期末折旧把账面价值收敛到残值。
- 撤销调整后，该调整不再参与计算，其他已确认年份的调整仍然保留。
- 警戒线 = 初始投入 × 全局警戒比例；某年年末账面价值严格低于该线时触发。
- 明细中会标出触发年份，并列出年末账面价值、占初始投入比例、警戒比例和警戒线金额。

## 数据约束与错误隔离

每项资产独立校验。以下情况会列出具体资产和问题，并将该资产排除在汇总与概览轨迹之外：

- 初始投入不是正数；
- 启用年份或使用年限不是有效整数；
- 使用年限不在 1 至 100 年之间；
- 残值率不在 0% 至 100% 之间；
- 调整年份超出该资产使用年度范围；
- 调整金额为 0；
- 调整后账面价值低于残值。

其他数据有效的资产仍会正常计算并纳入汇总。
