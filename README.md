# 笔记线索整理（本地交互应用）

纯 Python 标准库实现，无需安装任何依赖。

## 启动

    python server.py        # 默认 8000 端口
    python server.py 8123   # 指定端口

浏览器打开 http://127.0.0.1:8000/ ，点"载入示例"再"导入笔记"，或粘贴自己的
JSON：`{"notes":[{"id":"n1","text":"...","source":"...","time":"2026-09-01 10:00"}]}`

## 功能

- 导入零散笔记（文本/来源/时间），按字符 n-gram TF-IDF 余弦相似度自动聚类成主题线索
- 界面查看每条线索的主题词、笔记数量、最近记录时间、关联强度和笔记间关联
- 手动调整：移动笔记到其他线索、拆出笔记为新线索、合并两条线索
- 调整只重算受影响线索（响应中返回 affected 列表并高亮），未受影响线索保持不变；
  线索的主题/关联/统计是其笔记集合的纯函数，局部重算与全量重算结果一致
- 移动笔记时自动解除其原线索内的关联，不会残留旧归属（每条笔记全局唯一归属）
- 合并保留双方全部笔记并重算主题；若双方存在重复笔记归属则返回 409 并阻止，状态不变
- 撤销最近一次调整（可连续撤销）

## 文件

- `engine.py` 分词、TF-IDF 向量、余弦相似度、确定性连通分量聚类
- `threads.py` 线索存储：导入/移动/拆出/合并/撤销、增量重算、一致性校验
- `server.py` HTTP API（/api/state import move split merge undo sample）
- `static/index.html` 单页界面
- `tests.py` 行为测试（`python tests.py`）
