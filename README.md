# 交接推演台（本地离线）

责任交接场景下的上下文完整度推演工具：沿依赖关系推导每项交接的可完成性，
标出因依赖缺失 / 成环 / 时效过期而不可信的部分，来源冲突需人工裁决后才继续推导。

## 运行

纯静态、零依赖、完全离线：直接用浏览器打开 `index.html` 即可（无需服务器、无需联网）。
数据保存在浏览器 localStorage，可用界面上的「导出 / 导入 JSON」做备份与迁移。

## 功能对照

- 事项列表 + 实时完整度：启动即显示，含状态徽标（可完成 / 部分完整 / 不可信 / 待裁决）。
- 依赖推导：沿 `dependsOn` 链推导，上游不可信 / 未裁决会传导到下游。
- 来源冲突：同一事项同键的不同取值双方均保留，界面裁决「采用此版本」后才继续推导；
  被弃用版本划线保留展示，不删除。
- 增量重推：裁决或修改上下文后只重推受影响链路（反向依赖闭包），
  顶栏「一致性校验」每次变更后自动比对增量结果与从头全量重推是否一致。
- 依赖成环 / 指向缺失：相关事项标为「不可信」并在「推导依据」中说明原因，不静默跳过。
- 时效：事项截止时间、上下文有效期过期均标为不可信并给出依据。

## 目录

- `index.html` / `styles.css`：页面与样式
- `js/data.js`：内置示例数据（含冲突、过期、缺失依赖、依赖环等演示场景）
- `js/engine.js`：推导引擎（纯逻辑，无 DOM 依赖）
- `js/ui.js`：界面渲染与交互
- `test/engine.test.js`：引擎逻辑验证，`node test/engine.test.js`
- `test/dom-check.js`：界面接线静态检查，`node test/dom-check.js`
