# 离线三维空间标注审查工具

全程仅依赖 Python 标准库和 Tkinter，不需要网络或第三方包。

## 启动

```powershell
python main.py
```

Windows 也可以双击 `run_offline.bat`。启动后直接进入内置示例场景，包含层级对象、引用/从属关系、遮挡标注和双来源冲突。

## 界面操作

- 左键拖动：旋转相机；右键拖动：平移；鼠标滚轮：缩放。
- Objects 页：查看层级、新增对象、设置绝对位移/旋转/缩放、改挂父对象、删除对象。
- Annotations 页：查看每个标注的当前像素坐标、可见、遮挡、视窗外、相机后方和失效状态，也可以新增标注。
- Relations 页：声明 `reference` 或 `attachment` 关系；成环或引用不存在标注会被拒绝并显示链条。
- Conflicts 页：保留同一标注多个来源的不同锚点、对象或正文，并列出双方来源和内容。
- Evidence / Rejections 页：查看删除/改挂导致的原局部锚点、冻结世界锚点、原层级路径和拒绝原因。

## 关键规则

- 对象 ID 重复、父对象不存在、包围尺寸非正、缩放非正都会拒绝，并定位到字段。
- 有效标注保存对象局部锚点；父对象移动、旋转、缩放后自动重算世界锚点。
- 删除对象会冻结其上标注的原局部锚点、世界锚点和层级路径并标记失效，不移动到其他对象。
- 改挂的对象自身标注会冻结原世界锚点留证；子对象的局部层级关系仍保持有效。
- 视图投影不会静默隐藏：视窗外、相机后方、被 OBB 遮挡均有明确状态和画布标记。

## 自动化验证

```powershell
python -m unittest discover -s tests -v
```

测试覆盖数据校验、关系成环链条、冲突保留、删除/改挂证据、随父对象变换、无关标注不变、视窗/相机变化和遮挡分类。
