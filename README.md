# 区域仓网调拨工作台

本地启动的交互式工作台：维护多地点存量 / 在途 / 安全库存 / 未来需求，
自动生成满足缺口前提下总代价最小的调拨方案，并在无法平衡时给出取舍理由。

## 启动

```
python server.py          # 默认 8000 端口
python server.py 9000     # 指定端口
```

浏览器打开 http://localhost:8000 （仅依赖 Python 3 标准库，无需安装任何包）。

## 功能

- **库存维护**：表格直接编辑各地点现有存量、在途数量、安全库存、未来需求；
  支持新增 / 删除地点，距离矩阵对称联动编辑。
- **自动调拨建议**：净头寸 = 存量 + 在途 - 安全库存 - 需求；为负即缺口，
  为正即可支援量（安全库存不会被调出）。
- **代价模型**：线路单位代价 = 距离 × 单位运费 + 时效权重 × (距离 ÷ 运输速度)，
  三个参数均可在界面调整；用最小费用流求全局总代价最小方案。
- **统一优先级**：可支援量不足时，按缺口率（缺口 ÷ (安全库存 + 需求)）高者优先，
  取舍理由在“取舍理由与说明”面板逐条列出。
- **即时重算与高亮**：修改任意数值后 250ms 内自动重算，
  状态 / 缺口 / 调拨量发生变化的行以黄色闪烁高亮。
- **无法平衡提示**：顶部红色横幅显示硬缺口数量，汇总卡片标红未满足缺口。

## 接口

`POST /api/plan`，请求体 `{locations, distances, weights}`，
返回 `{locations, transfers, total, explanations}`，字段含义见 `solver.py`。

## 测试

```
python tests/test_solver.py
```

## 文件结构

- `solver.py` — 最小费用流求解与优先级 / 取舍理由生成
- `server.py` — 本地 HTTP 服务（标准库）
- `static/` — 交互界面（原生 HTML/CSS/JS）
- `tests/test_solver.py` — 求解器单元测试
