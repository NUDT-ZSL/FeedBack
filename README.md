# 技能训练营评分工作台

这是一个无需构建、可离线运行的静态评分工具。启动后默认进入评分工作台，教练可以选择学员、逐项打分、调整权重和维护等级规则，总分、维度等级、贡献值与评价依据会实时更新。

## 启动

```powershell
npm start
```

然后打开 `http://localhost:4173`。也可以直接用浏览器打开 `index.html`。

数据保存在当前浏览器的 `localStorage` 中；点击“恢复演示数据”会回到内置示例。

## 功能

- 维护多个评分维度、整数权重、维度等级和总评等级。
- 修改任一权重时自动按比例分摊其他权重，始终保持合计 100%。
- 每次修改原始分或权重后立即重算总分、维度等级和得分贡献。
- 中文依据说明计算式、拉高项、拉低项，以及补齐后可跨越下一等级边界的关键维度。
- 每个维度支持四种缺省策略：重新分摊、按 0 分、按满分、按其他已评均分，并标出对结果的影响。
- 权重导致总评跨边界时提示等级变化，并并列保留改动前后的依据快照。

## 验证

```powershell
npm test
npm start
# 另开一个终端
npm run smoke
```

`npm test` 覆盖评分计算、缺省策略、权重一致性和跨级检测；`npm run smoke` 使用本机 Chromium 通过 DevTools Protocol 验证真实页面交互。
