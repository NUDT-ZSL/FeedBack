# 表单分步认知负担推演工具（本地离线）

检查一份长流程表单在拆成不同步骤后，每一步的**阅读量、必填压力、跨步骤依赖**是否会让
使用者记不住或跳错。纯静态页面，无需联网、无需安装，双击 `index.html` 即可使用；
数据保存在浏览器 localStorage，可随时导入/导出 JSON。

## 使用

1. 双击打开 `index.html`（或用任意现代浏览器打开），启动即展示可操作的分步表单。
2. 字段卡片上的 `←` `→` 直接调整归属步骤；`✎` 可改阅读量、必填、**锁定步骤**、**排除字段**。
3. 右侧维护依赖关系与"对前置的填写要求"（必填 / 选填 / 只读带出 / 隐藏不填 / 有值则跳过）。
4. 顶部可切换"自动收敛归属"、手动收敛一次、增删字段/依赖、导入导出、恢复示例。
5. 所有变更都会触发**整体重推**，立即刷新每步负担与不可完成提示。

## 推演规则（`src/engine.js`）

- 依赖边 `source -> target` 表示 source 字段需要前置 target，并携带对 target 的填写要求；
  合法顺序要求 `source.step >= target.step`（同步骤视为可完成）。
- **逐步负担**：本步阅读量 = 本步字段阅读量之和；总阅读量还计入"需回忆的更早步骤前置"阅读量；
  必填数含字段自身必填与被依赖要求为必填；达到阈值标记高阅读/高必填压力。
- **不可完成**：前置被排到更靠后步骤（`future`，并指出具体依赖边）、前置被排除（`excluded`）、
  循环依赖（`cycle`），以及这些情况沿依赖链的**传递阻断**（`upstream`）。所在步骤整体标红。
- **要求冲突**：同一字段被多条依赖提出互斥要求时（如"必填"与"只读带出"），保留全部依据
  （每条边）并在右侧列出，系统不静默选择。兼容组合（如 必填 + 有值则跳过）不报警。
- **锁定/排除**：收敛用差分约束（锁定锚传播上下界 + 单调前移到不动点）：
  未锁定字段移动到满足全部依赖的位置；锁定字段位置永不移动，锁定先后冲突会保留并标红；
  排除字段不参与结构，依赖它的字段被阻断。收敛幂等，结果与整体重推一致。

## 测试

```
npm test
# 或
node --test tests/engine.test.js
```

10 个用例逐条覆盖六项需求（含传递阻断、循环、锁定冲突、冲突依据保留、整体重推一致性）。

## 文件

- `index.html` / `styles.css`：离线界面
- `src/engine.js`：纯函数推演引擎（无 DOM 依赖，浏览器与 Node 通用）
- `src/data.js`：内置示例（含锁定冲突、多依赖要求冲突、跨步骤回忆）
- `src/app.js`：状态、编辑弹窗、整体重推渲染、localStorage 持久化
- `tests/engine.test.js`：Node 内置 test runner 用例
