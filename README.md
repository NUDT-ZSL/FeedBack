# 离线共编协调台

一个零依赖、可在本地直接打开的多人共编协调工具。多个编辑者可持续提交针对同一份有序片段的修改，系统按当前所有记录重新合成最终内容，并显式保留并发冲突。

## 如何运行

直接双击打开 [index.html](index.html) 即可使用，不需要安装依赖，也不需要联网。

如需通过本地 HTTP 方式打开：

```powershell
python -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/index.html`。

数据保存在当前浏览器的 `localStorage` 中，不会上传。可以使用右上角“导出 JSON”保存包含当前状态和推导结果的快照。

## 合成规则

- 每条修改包含来源、发生顺序、操作类型和目标片段。
- 支持“改写片段”“在片段后插入”“删除片段”。
- 相同发生顺序的修改属于并发修改，不会自动选择其中一方。
- 多个改写/删除指向同一片段时也会形成冲突。
- 冲突可逐个候选槽处理：采纳某来源、保留原文、不插入，或手动改写。
- 每个冲突槽都处理后，该冲突才会从未决状态消失。
- 撤回或改写记录后，系统从基础片段和剩余有效记录重新推导，结果等价于从头合成。
- 缺少来源、顺序非法、目标片段不存在等记录会显示可读错误，不影响其他片段。
- 被撤回记录的下游修改如果暂时没有确定锚点，会显示“等待上游”，不会混入最终内容。

## 界面信息

- 左侧按最终顺序展示片段、来源、未决冲突和“撤回/改写后重新推导”标记。
- 右侧提交新修改，并列出全部有效、撤回和问题记录。
- 未决冲突以占位卡片显示，列出每个来源的具体候选内容。
- 已解决片段可展开详情后改选。

## 测试

合成逻辑位于 [js/core.js](js/core.js)，不依赖 DOM；界面状态位于 [js/app.js](js/app.js)。

运行：

```powershell
npm test
```

测试覆盖同序冲突、同片段冲突、插入冲突、即时采纳、手动改写、删除、撤回后与从头重算一致、无效记录隔离、插入片段继续修改等行为。
