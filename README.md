# 配置发布与撤回离线推演台

这是一个零依赖、可离线启动的交互工具，用于推演配置规则在多批目标上的发布、覆盖、裁决和撤回。

## 启动

Windows 下双击 `start.cmd`，或直接双击 `index.html`。

工具不访问网络、不安装第三方依赖；所有 JavaScript、CSS 和样例数据均在本地。

## 已覆盖的规则

- 规则包含配置键、配置值、作用批次、标签条件（AND）、优先级和生效批次。
- 按发布时间轴推导：目标批次晚于当前时刻则等待；规则生效批次晚于当前时刻则等待。
- 同一目标、同一键的多条命中规则全部保留为候选；当多条候选可生效时显示冲突，且生效值保持未确定。
- 系统只按优先级（更高优先）、更晚生效批次、规则 ID、版本给出稳定推荐，推荐不会自动覆盖人工裁决。
- 用户通过单选项裁决后才确定当前版本；若规则后续撤回、范围改变或版本更新，旧裁决会标记失效。
- 撤回或调整作用范围时，只重算旧范围、新范围及带有该规则裁决的目标；界面每次操作都会将增量结果与全量结果做 JSON 级对比。
- 批次未就绪、目标归属缺失批次、规则生效批次缺失、规则作用范围指向缺失批次时均标为不可信，并展示具体原因。

## 界面操作

1. 点击顶部批次时间轴，切换“当前推演时刻”。
2. 在规则区新建或编辑规则，修改键值、优先级、生效批次、作用批次和标签。
3. 点击“保存并发布新版本”进入发布链路；点击规则卡上的“撤回”输入撤回原因。
4. 在目标卡片查看所有候选及依据；冲突时选择候选后点击“裁决所选候选”。
5. 在批次可信性区切换批次就绪状态；缺失批次无法通过开关恢复，必须修正规则或批次定义。
6. 点击“一致性校验”，确认受影响重推与整体重推结果一致。

## 自动化验证

```powershell
npm test
```

或：

```powershell
node engine.test.js
```

也可以运行真实浏览器点击冒烟测试（自动寻找本机 Chrome 或 Edge）：

```powershell
npm run test:browser
```

测试覆盖优先级与批次顺序、多候选冲突与裁决、撤回、范围缩小、缺失批次、未就绪批次，以及增量重推和整体重推一致性；浏览器测试还验证编辑区打开、候选裁决、时间轴切换和一致性按钮。
