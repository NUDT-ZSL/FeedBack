# 笔记关联本

一个纯本地的个人知识整理工具：录入带标签和自由文本的零散笔记，
自动发现笔记之间的真实关联并解释原因，支持沿关联链浏览与回退。

## 运行

无需安装任何依赖，直接用浏览器打开 `index.html` 即可
（数据保存在浏览器 localStorage，不上传任何地方）。

## 功能对照

1. 左侧表单录入标题、标签（逗号分隔）、正文，保存后立即出现在列表并选中。
2. 选中笔记后，右侧按相关度从高到低列出相关笔记。
3. 每条关联卡片都给出理由：共同标签「…」与文本线索（都提到的关键词）。
4. 在“编辑这条笔记”中修改标签或正文，保存后关联立即全量重算，旧判断不保留。
5. 点击关联卡片跳到下一条笔记，顶部显示浏览线索，可点“← 返回上一条”回退。
6. 没有关联的笔记显示明确的“当前孤立”提示，不会显示空列表或误连。

## 关联算法（relations.js）

- 标签：共同标签直接连边，权重含 idf（越常见的标签贡献越小）。
- 文本：中文按二字滑窗、英文按单词提取线索词，去除停用字词；
  以 idf 加权求和作为文本相关分。
- 连边条件：有共同标签，或文本分达阈值且共享线索词 ≥ 2（防止单词泛词误连）。
- 每次数据变更后对全部笔记重新计算，不缓存旧结果。

## 测试

```
node test.js    # 关联引擎单元测试（需求 1/2/3/4/6）
node smoke.js   # 用最小 DOM 桩跑完整交互链路（含跳转/回退/编辑失效）
```
