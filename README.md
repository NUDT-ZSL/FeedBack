# 目标工作台（Goal Workbench）

本地单文件目标管理应用：围绕长期目标、阶段成果与动态变化，帮助把目标拆成可执行路径，并在条件变化时自动重新规划。

## 启动

- 双击 `启动.bat`，或直接用浏览器打开 `index.html`。
- 无需安装任何依赖，数据保存在浏览器 localStorage 中。
- 首次打开内置一个示例目标，可直接体验完整流程后删除。

## 功能

1. **创建长期目标**：名称、可量化完成条件（目标值 + 单位 + 描述）、期望周期（天）。
2. **阶段拆解**：每个目标可拆成多个阶段成果，支持设置前置依赖，表格与甘特图展示每条路径状态。
3. **动态重算**：阶段标记为完成 / 延期（输入延期天数）/ 取消后，系统基于依赖拓扑重新前推计算所有后续阶段的预计窗口与总完成时间。
4. **冲突与建议**：循环依赖、依赖已取消阶段、时间线超期都会被标红，并给出可一键执行的建议（延长周期、移除失效依赖）或压缩/并行化提示；关键路径上的受影响阶段会标注「受影响」。
5. **手动调整**：阶段可上移/下移（自动重接相邻依赖）、修改时长与依赖，所有进度视图（进度条、甘特图、时间窗口、时差）同步更新。
6. **开箱即用**：启动后直接进入目标工作台，创建 → 拆解 → 调整 → 查看反馈全流程在单页完成。
