# 活动上下文恢复工作台

一个完全本地运行、无需联网和第三方依赖的活动上下文管理工具。它为每项活动保存素材、待办、临时想法与当前进度，并根据时效、依赖和冲突裁决推导恢复顺序。

## 启动

Windows 下双击 `启动工作台.cmd`，或在本目录执行：

```powershell
npm start
```

启动后会自动打开 http://127.0.0.1:17321/ 。数据只保存在当前浏览器的 `localStorage` 中，不会上传。

## 核心规则

- 上下文条目包含来源、时效、所属活动和依赖指向。
- 未裁决的冲突会保留双方，并且阻止生成续接结论。
- 裁决可以选择任一条有效，也可以裁决双方并存；条目本身不会被删除。
- 缺失依赖、依赖到不可用条目、跨活动依赖或依赖闭环会把活动标记为“不可信”，并列出所有涉及条目。
- 续接排序先满足依赖，再综合过期程度、失效时间、条目类型和更新时间。
- 页面内的增量缓存会在修正或裁决后只使相关活动失效；测试验证其结果与整体重推一致。
