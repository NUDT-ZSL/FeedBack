# 离线自动化验证

针对订单状态流转（待处理 → 制作中 → 已完成）与原料消耗统计的自动化验证，
不依赖浏览器、不等待真实计时器，可在任何装有 Node.js 的环境离线运行。

## 运行方式

```bash
npm install
npm run verify
```

该命令先用项目自带的 TypeScript 将 `src/orderLogic.ts`、`src/data.ts` 与
`tests/` 编译到 `dist-tests/`，再由 Node 直接执行。全部用例通过时退出码为 0，
任一失败时退出码为 1，并逐条打印通过/失败明细。

## 被测对象

测试直接针对 `src/orderLogic.ts` 中的纯函数领域逻辑，该模块是应用状态流转的
唯一入口（`App.tsx` 通过 `useReducer(appReducer, ...)` 使用同一份代码），
因此离线验证的结论对浏览器内行为同样有效。

## 覆盖的风险

- `tests/idempotency.test.ts` — 制作中订单被重复触发完成时，原料只扣减一次；
  已完成/不存在/待处理订单的边界行为。
- `tests/countdownRace.test.ts` — 倒计时归零自动完成与手动点击完成的竞态：
  两种先后顺序及同批次并发下，状态与消耗均保持一致；倒计时边界判定精确到毫秒，
  通过注入 `nowMs` 实现，无需真实等待。
- `tests/recipeMatrix.test.ts` — 4 种尺寸 × 5 种口味共 20 种组合的配方消耗
  矩阵校验（测试侧独立维护规格表）；层数只影响时长不影响消耗；低库存阈值
  （剩余量 < 初始库存 20%）在边界值 ±0.1 处的稳定性。
