# 交易与采矿结算离线验证

无需浏览器、无需网络、无需安装依赖，直接使用 Node.js（v22.18+，内置 TypeScript 擦除）批量运行：

```bash
npm test
# 或
node tests/run.ts
# 按名称过滤场景
node tests/run.ts 价格
```

全部通过时退出码为 0，存在失败时为 1，可直接接入 CI 或无人值守的批量任务。

## 覆盖的不变量

| 场景 | 不变量 |
| --- | --- |
| 价格波动 | 每次波动后各站各矿物价格均在基础价的 0.5~2 倍区间（含边界取整） |
| 货舱容量 | 玩家库存总量不超容量；满载后继续采矿不改库存与累计开采量 |
| 卖出守恒 | sellAll 前后每种矿物“玩家库存 + 站点库存”之和不变，收益 = Σ 数量×单价 |
| 买入限制 | 成交量同时受货舱剩余空间与站点库存约束；站点减损量等于玩家增加量，无静默吞吐 |
| 交易历史 | 超过 10 条后只保留最近 10 条且最近优先；每条数量×单价=总价 |
| 重置 | 玩家库存、累计价值、累计开采量、交易计数归零；站点库存与价格重新生成且满足区间约束 |
| 模糊验证 | 20 个固定种子 × 300 步随机操作，每步后校验全部不变量及当步守恒关系 |

## 失败输出

失败会标明违反的**具体不变量**与定位上下文，例如：

```
失败  买入限制：受货舱空间与站点库存双重约束...
       [库存守恒] seed=7 第 12 步 buyMineral(...) 之后：玩家金矿应增加 5...
```

模糊验证的每条失败都带 `seed` 与步骤号，可用相同种子稳定复现。

## 结构

- `tests/framework.ts`：场景注册、`checkInvariant` 不变量断言与报告
- `tests/invariants.ts`：可复用的不变量断言与状态快照
- `tests/scenarios.ts`：六类行为边界的确定性场景
- `tests/fuzz.ts`：种子随机序列模糊验证
- `tests/run.ts`：入口

随机数可通过 `new TradeManager(createSeededRandom(seed))` 注入（`src/managers/random.ts`），
游戏正常运行时不传参数即使用 `Math.random()`。
