# 成绩记录链路验证

离线、无需真实网络或外部账号的自动化验证。使用 Node.js 内置 `node:test`，
每个用例在进程内启动真实 Express 服务（随机端口、`:memory:` SQLite 库），
通过 HTTP（本机回环）打接口，不依赖浏览器、外部账号或固定端口。

## 运行

```bash
npm install   # 仅需 npm registry，无原生模块编译
npm test
```

## 统一约定（契约）

- 提交：`POST /api/mazes/:id/attempts`（`/attempt` 为兼容旧客户端的别名，语义完全一致）
- 读取：`GET  /api/mazes/:id/attempts`
- 成功：`201` / `200`，响应体不含 `error` 字段
- 失败：`400`（非法输入）或 `404`（迷宫不存在），响应体统一为 `{ "error": string }`
- 非法输入：迷宫不存在、username 缺失/空/纯空白/非字符串、time_seconds 缺失/负数/非数字/非有限数
- 排行顺序：`time_seconds ASC, created_at ASC, id ASC`；相同用时按提交先后（id 升序）排列，可复现

## 覆盖的风险点

| 测试 | 覆盖风险 |
| --- | --- |
| 同一用户连续/并发提交多次成绩：排行不重复、不丢失 | 连续提交 5 次 + 并发提交 10 次，核对排行 id 集合与提交返回的 id 集合完全一致 |
| 提交与读取交错并发：每次读到的都是一致且完整的快照 | 30 轮读写交错；每个快照必须有序、行字段完整、包含读取发起前已确认的全部成绩，且不含未确认成绩 |
| 非法输入：提交与读取两端错误语义一致且可判定 | `/attempts` 与 `/attempt` 两条路径对 10 类非法输入均返回 `400 {error}`；不存在迷宫两端均 `404 {error}`；非法 JSON `400 {error}`；非法提交不得入库；边界值 `0` 合法 |
| 排行顺序稳定：相同用时的先后次序可复现 | 含同分乱序提交，校验精确名次；同库两次读取一致；全新数据库重放后顺序一致 |

失败时退出码非 0，可直接接入批量运行入口（`npm test` 即统一入口）。
