# 云锦织机状态链路离线验证

无需浏览器、无需网络、无需渲染/音频设备，对织造推进、落纱与图案联动、
卷轴状态机、边界输入四条状态链路做确定性批量验证。

## 运行

```bash
npm test          # 单次运行全部用例
npm run test:watch # 开发时监听
npm run test:batch # 批量重复 5 轮，任一轮失败即整体失败
node tests/batch.mjs 20   # 自定义批量轮数
```

依赖仅 `vitest`（devDependency），安装后所有资源均来自本地 `node_modules`。
浏览器依赖在 `tests/setup.ts` 中以替身隔离：

| 浏览器能力         | 替身处理                              |
|--------------------|---------------------------------------|
| Canvas / 2D Context | 无操作绘制方法（`tests/setup.ts`）     |
| WebAudio / Howler  | `HowlMock`，仅计数播放次数，不访问设备 |
| URL.createObjectURL| 返回固定 `blob:offline-mock`          |
| 动画计时           | `vi.useFakeTimers` 精确推进，结果可复现 |

## 覆盖的风险链路

### 织造推进（`loomWeaving.test.ts`）
- 连续投梭达到目标长度后，`onFabricComplete` **恰好触发一次**；
  完成后 `fireShuttle()` 被拒绝，织物长度与纬线行数冻结。
- 投梭飞行中重复投梭被拒绝。
- 织造途中**调高目标**：不按旧目标提前完成，织到新目标后完成一次。
- 织造途中**调低目标到当前长度**：立即按新目标完成一次（不卡死、不永不完成）。
- 完成回调 500ms 等待期内反复调目标，以最终目标判定，仍只完成一次。
- 目标长度上下限（10/50cm），以及 5 轮完整生命周期批量复现。

### 落纱与图案联动（`silkAndPattern.test.ts`）
- 同一槽位连续落纱不同颜色：经线色、梭子当前色、后续纬线色三者一致，无旧色残留。
- **投梭飞行中改色不污染进行中的这一行**：行颜色与综丝位置在投梭时刻快照，
  新颜色只影响后续行（防操作过快导致错位）。
- 应用图案后经线颜色序列与 `weaveTypes[0]` 映射
  （`warp_up→#cc2936`、`weft_visible→#ffe066`、`mixed→#1f4e79`）逐根一致。
- 每行提花序列与 `heddleSequence` 逐行对应。
- 重复应用同一图案结果完全一致；切换图案再切回结果可复现；
  映射生成函数本身确定性。

### 卷轴状态机（`scrollViewer.test.ts`）
- 完整合法迁移链：隐藏 → 悬浮 → 展开中 → 完全展开 → 回卷中 → 悬浮。
- 非法迁移（未展开就回卷、已回卷再回卷、重复展开、动画中途迁移）被拒绝
  （`unroll()/rollback()` 返回 `false`）且状态不变。
- 完全展开 15 秒后自动回卷一次，不残留。
- **旧计时无残留**：手动回卷、`hide()` 隐藏、`createScroll()` 重新创建后，
  旧的自动回卷计时均被清除；重新展开不会被旧计时提前回卷。

### 边界输入（`boundary.test.ts`）
- 目标长度：越界钳制到 `[10,50]`；`NaN/±Infinity` 保持原值且仍可正常织完。
- 槽位索引：负数、`>=108`、`NaN`、小数均被拒绝，不抛异常、不改状态。
- 图案行索引：负数取模归一化、`64` 循环到第 0 行、超大值、`NaN`、
  非整数不抛异常；空映射安全降级。
- 时间步长：`0`、负值、`NaN`、`Infinity`、超大值不抛异常、不产生 NaN 状态。
- 30 次落纱/图案/投梭/调目标快速混合操作后，模块状态仍一致且合法。

## 测试驱动发现并修复的源码缺陷

| 位置 | 修复前 | 修复后 |
|------|--------|--------|
| `src/Loom.ts` | 完成后继续投梭会继续加长度，且每超一行重复触发完成回调 | 完成为终态：投梭被拒、长度冻结、回调恰好一次 |
| `src/Loom.ts` | 完成回调 setTimeout 期间调目标长度，按旧目标提前完成 | 回调触发前以当前目标复检；目标调高时撤销已安排判定 |
| `src/Loom.ts` | 织造途中把目标下调到当前长度会永不完成 | `setTargetLength` 也会安排完成判定 |
| `src/Loom.ts` | 梭子飞行中改色/落纱，进行中的行被新颜色污染 | 投梭时刻快照行颜色与综丝位置 |
| `src/Loom.ts` | `setWarpColor(NaN/3.5)` 抛未捕获异常 | 整数越界校验 |
| `src/PatternEngine.ts` | 负/NaN 行索引直接崩溃；列数硬编码 64 | 取模归一化、NaN 降级全零、按实际映射尺寸计算 |
| `src/main.ts` | 两处语法错误（未闭合括号、模板字符串缺反引号）导致 build 失败 | 已修复 |

另：`ScrollViewer.unroll()/rollback()` 返回布尔值并新增
`hasPendingAutoRollback()`，使状态机判定结果可直接观察；
Loom 新增 `dropSilk()` 统一落纱联动（经线色 + 梭子当前色）。
