# 编队指挥推演链路（src/sim）

贯穿 **输入 → 状态推演 → 结果输出** 的编队指令链路，与渲染层解耦，可离线确定性重复执行。

## 链路结构

- `types.ts` — 指令（携带下达时刻 `issuedAt` 与执行时长 `duration`）、事件、快照等类型。
- `formations.ts` — 雁行/鱼鳞/偃月阵的标准槽位表（旗舰本地坐标系），以及补位的最近槽位匹配。
- `commands.ts` — 指令链冲突消解：同组指令（turn/turn、speed/speed、formation/disperse）
  后者截断前者的未执行部分；原始指令全部保留在指令链历史中（`status: executed/truncated/superseded`）。
- `fleetSim.ts` — 单编队推演器：按指令起止与事件时刻切分时间片，定步长积分；
  僚舰位置以“旗舰相对偏移（阵型依据）+ 误差随旗舰刚体运动携带并衰减”更新，
  变阵窗口结束时精确到位，转向/变阵重叠时无位移叠加、无跳变。
- `engine.ts` — 多编队引擎：下达指令、僚舰脱离、旗舰移除后，
  仅回滚受影响编队到受影响时刻并重推尾部区间（`stats().stepsIntegrated` 可验证重推范围）；
  `fullRecompute()` 提供整体重推基准用于一致性对照。

## 关键语义

- **阵型依据**：每艘僚舰保存其在旗舰本地坐标系下的偏移 `basis`，变阵/散开/补位/旗舰移交都会重算并留痕。
- **队形快照**：每次变阵/散开前后、补位、旗舰移交、脱离瞬间均记录 `FormationSnapshot`
  （含旗舰归属、成员相对偏移、距/方位、移交规则与原因），可随时回看对照。
- **旗舰移交**：旗舰被移除时按名册资历顺序（`seniority`）移交，以新旗舰当前位置/朝向重算
  阵型依据保证几何连续；指令链对新旗舰继续生效。全员脱离后编队停摆（defunct），
  不再执行任何编队指令，杜绝“无旗舰仍执行”的状态。
- **僚舰脱离**：脱离舰船停船退出编队，剩余舰船按当前阵型规则最近槽位自动补位。

## 离线验证

```bash
npm test          # vitest run，24 个用例
```

覆盖：指令冲突覆盖（`conflict.test.ts`）、旗舰移交（`handover.test.ts`）、
僚舰脱离补位（`detach.test.ts`）、转向/变阵时间片重叠（`overlap.test.ts`）、
增量重推与整体重推一致性（`incremental.test.ts`）、加速/散开与可重复性（`commands.test.ts`）。
