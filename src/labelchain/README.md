# Auto16 可推演标记链路

把"输入文本 → 标记序列"改造成一条可逐步推演的链路：每个位置的最终标记都能
回答"由哪条规则、依据哪些上游位置、经过哪条传播路径得出"，异常（冲突、成环、
悬空、振荡）以可观察的中间状态呈现，而不是被跳过或丢弃。

## 链路结构

```
片段提交(来源/顺序号/修订号)
  │  DocumentStore：按 (source, seq) 确定性排序；重复提交幂等忽略；
  │  同修订号内容冲突 / 过期修订号 记录为可观察日志；高修订号覆盖=中途修正
  ▼
位置序列（带版本）
  │  Engine.derive：每条规则按作用范围 + 优先级求值，全部命中候选保留
  │  最高优先级结论唯一 → resolved；同优先级分歧 → conflict（不静默择一）
  ▼
依赖传播（不动点迭代）
  │  规则声明相对依赖 deps；位置标记变化时只把下游位置入队重推；
  │  达到迭代上限仍振荡 → unconverged 如实列出；依赖成环 → cycles 列出；
  │  依赖目标不存在且被实际求值 → dangling 列出
  ▼
输出 Report
     每位置：最终标记 + 状态 + 全部候选依据（含败方）+ 传播路径 explain()
     全局：conflicts / unconverged / cycles / dangling / ingestLog 清单
```

## 关键语义

- **确定性**：文档顺序只取决于 `(source, seq)`；同优先级冲突不裁决、不随机择一，
  结果与规则注册顺序、片段到达顺序无关（验收中反转规则顺序逐位比对）。
- **增量重推**：片段修正只重推内容变化区间；规则改写只重推被改/增/删规则的
  作用范围；裁决只重推被裁决位置；三者都沿依赖边级联下游。文档增长时额外
  重推此前悬空的位置（依赖目标可能已补全），文档收缩时保守全量。
- **一致性**：`recomputeAll()` 整体重推是增量结果的对照基准，验收在每一步
  操作后逐位比对（未收敛位置只要求未收敛集合一致，振荡值不做要求）。
- **裁决**：`adjudicate(index, label)` 钉住位置标记并立即级联下游；
  `release(index)` 解除后回到规则推导。被钉住位置仍保留全部候选依据。

## 文件

| 文件 | 职责 |
| --- | --- |
| `src/labelchain/types.ts` | 链路全部类型（片段、规则、候选、报告、解释树） |
| `src/labelchain/document.ts` | 输入侧：排序、去重、修订、差异区间计算 |
| `src/labelchain/engine.ts` | 处理/收敛侧：匹配、冲突保留、传播、环/悬空检测、裁决 |
| `src/labelchain/index.ts` | 导出入口 |
| `samples/*.json` | 11 组离线样例（覆盖全部边界，见下表） |
| `tests/acceptance.ts` | 验收运行器：逐步一致性 + 确定性 + 期望值断言 |

## 离线验收

```bash
npm run acceptance        # 等价于 node tests/acceptance.ts（Node ≥ 22，无需安装依赖）
```

样例与边界的对应关系：

| 样例 | 覆盖边界 |
| --- | --- |
| 01-out-of-order | 片段乱序到达，结果与到达顺序无关 |
| 02-duplicate | 同一位置重复提交 / 同修订号内容冲突 / 过期修订号 |
| 03-correction | 片段中途修正，下游级联、无关位置不重推 |
| 04-conflict | 同优先级冲突保留各方依据，不静默择一 |
| 05-overlap-priority | 作用范围部分重叠，优先级决定重叠区 |
| 06-multi-hop | 多级依赖传播，修正后全链路旧结论清除 |
| 07-cycle | 依赖成环：环如实列出，裁决后环上仍收敛 |
| 08-dangling | 依赖指向不存在位置，补全后自动消除并补推 |
| 09-adjudication | 人工裁决后下游立即级联，不漏推 |
| 10-rule-rewrite | 规则改写只重推受影响范围 |
| 11-oscillation | 自环振荡达到迭代上限，如实列出未收敛 |
| 12-joint-evidence | 多规则同优先级同结论共同作用，全部依据保留在标记上 |

每组样例的每一步操作后都执行两项横切校验：

1. **增量 ≡ 整体**：增量快照与 `recomputeAll()` 快照逐位一致；
2. **顺序无关**：规则注册顺序反转后重放全部操作，最终快照逐位一致。
