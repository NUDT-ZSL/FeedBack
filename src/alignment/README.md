# 字幕对齐推演模块

在媒体时间轴上，依据关键锚点与字幕片段顺序推导各片段的偏移与漂移趋势，
输出可追溯的对齐结论。支持交互式录入、矛盾裁决与增量重推。

## 数据模型（types.ts）

- `MediaInfo`：媒体总时长、帧率。
- `Anchor`：关键锚点，声明"片段 X 应出现在媒体时刻 T"。
- `Segment`：字幕片段（起止时刻、文本、来源标记）。
- `Adjudication`：矛盾裁决记录（采纳方、被挂起方、时间、备注）。
- `SegmentConclusion`：每条片段的对齐结论（偏移秒/帧、漂移趋势、漂移率、
  状态标记）及其 `basis` 依据（锚点 id、裁决 id、顺序键、推导版本）。

## 推导规则（engine.ts）

- 片段按 `(start, id)` 稳定排序，顺序键写入结论依据，增删片段不改变他者顺序键。
- 有效锚点（目标片段存在）按媒体时刻排序，锚点偏移 = 媒体时刻 − 片段开始时刻。
- 两锚点之间线性插值得偏移，斜率即漂移率；超出锚点范围取最近锚点外推；
  无锚点时偏移为 0 并标记 `unanchored`。
- 异常识别：时刻倒序、区间重叠、锚点指向缺失片段、同一时刻多来源矛盾。
  矛盾片段双方均保留并标记"待裁决"，绝不静默择一；裁决后未采纳方标记
  `suppressed`（仍保留在结论中可追溯）。

## 增量重推（session.ts）

`AlignmentSession` 持有状态与最近一次推导结果，所有编辑经会话方法进入：

- 锚点增删改：只重推新旧相邻锚点开区间内的片段及锚点目标片段。
- 片段增删改：只重推自身、新旧位置相邻片段、同刻矛盾组成员；
  若片段被锚点引用，联动该锚点的影响区间。
- 裁决：只重推矛盾组成员。
- 帧率调整：重算全部帧号（秒级偏移与漂移趋势不变）；仅改时长则不重推。

未受影响片段的结论对象原样复用（`basis.version` 保持原推导版本）。
`compareWithFullRederive(session)` 可校验增量结果与整体重推逐字段一致，
测试套件对每类变更均执行该校验。

## 验收样例与测试

- `sample.ts`：含倒序时刻、重叠区间、缺失锚点、矛盾来源的验收数据集。
- `engine.test.ts`（`npm test`）：11 个用例覆盖异常识别、矛盾保留、
  裁决增量一致性、锚点/片段/帧率变更的增量一致性与可追溯性。

## 界面

`src/AlignmentPage.tsx`（导航"对齐推演"页）：媒体信息、锚点表、片段表、
异常与裁决面板、结论表（含依据列）、变更日志（每次操作重推/复用段数）。
