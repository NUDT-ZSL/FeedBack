# 焦点路径规划器

纯本地、纯键盘可操作的单页应用：从一份界面结构描述出发，推导默认焦点顺序，按优先级消解跳转约束冲突与循环，并支持逐步走查模拟。无需构建、无需联网，双击 `index.html` 即可使用。

## 运行

- 直接用浏览器打开 `index.html`（启动后自动载入内置示例，立即可操作）；
- 在底部文本框粘贴结构 JSON 后点「加载结构」，或用文件选择器导入 `.json`（参考 `sample.json`）。

## 结构描述格式

```json
{
  "root": "wizard",
  "initialFocus": "name",
  "containers": [{ "id": "step1", "label": "第一步", "parent": "wizard" }],
  "children": { "wizard": ["step1"], "step1": ["name", "email"] },
  "elements": [{ "id": "name", "label": "姓名", "required": true }],
  "constraints": [{ "id": "j1", "from": "email", "to": "submit", "priority": 10, "note": "..." }]
}
```

- `elements[].required`：必需元素。任何修改后，从初始焦点出发必须仍能到达全部必需元素，否则界面顶部红色横幅会指出断裂段及造成断裂的约束。
- `constraints[]`：跳转约束。`priority` 大的优先；同级并列时先声明的优先。

## 消解规则

- 同源冲突：多条约束从同一元素出发，只保留优先级最高的一条，其余标记「已覆盖」并注明原因。
- 循环：跳转形成环且仍有元素未覆盖时，断开环内优先级最低的约束并标记，重算直到路径可行。
- 非法端点：起点/终点不是可聚焦元素的约束被拦截为「无效」，不参与计算。

## 键盘操作

| 按键 | 作用 |
| --- | --- |
| `1` / `2` / `3` | 切换 顺序列表 / 层级视图 / 约束面板 |
| `↑` `↓` | 移动选择（列表与层级同步到同一元素） |
| `Ctrl+↑` `Ctrl+↓` | 调整选中约束的优先级 |
| `i` | 新增约束（表单内 Tab 移动，Enter 确认，Esc 取消） |
| `Delete` | 删除选中约束 |
| `w` | 开始走查 |
| `n` / 空格 | 走查推进一步 |
| `r` | 重置走查 |
| `Esc` | 退出走查 / 关闭表单 / 移出输入框 |
| `l` | 跳到 JSON 输入框 |

每次修改后立即重算焦点顺序，焦点保留在面板内不丢失；走查停在断裂处并给出可读原因，不会静默跳过。

## 测试

```
node test.js     # 核心逻辑（顺序推导、冲突/循环消解、可达性）
node uitest.js   # UI 冒烟测试（jsdom 模拟键盘操作，需先 npm install）
```
