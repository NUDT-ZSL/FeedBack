# 采药炼丹链路的离线确定性验证

不打开浏览器、不依赖网络，批量验证「地形生成 → 草药采集 → 炼丹炉投料 → 成丹」整条链路。

## 运行

```bash
npm test           # 离线批量执行全部用例，失败时退出码为 1
npm run test:typecheck   # 测试与源码的 TypeScript 严格类型检查
```

测试通过项目自带的 esbuild（vite 依赖）打包到 `dist-test/run.cjs` 后由 Node 直接执行，
不新增依赖、不访问网络、不启动浏览器。

## 确定性输入抽象（src/game/core/）

- `random.ts`：`RandomSource` + mulberry32 种子随机 `createSeededRandom(seed)` + 确定性 id 生成器。
  游戏代码不再直接调用 `Math.random()`；浏览器默认用 `mathRandomSource`，验证注入种子。
- `clock.ts`：`Clock`（now）与 `FrameRunner`（帧调度）。浏览器默认用
  `Date.now/requestAnimationFrame`；验证用 `ManualClock/ManualFrameRunner` 手动推进时间。
- `height.ts`：地形高度纯函数，渲染（TerrainGenerator）与验证共用同一份地形定义。
- `placement.ts`：草药落点约束（远离溪流 >3、距中心 <size*0.4、高度 <5）与确定性布点。
  数量严格等于配置值：随机拒绝采样耗尽后走确定性螺旋兜底，仍不满足则显式抛错，绝不静默缺数。
- `furnaceCore.ts`：熔炉纯逻辑——投料、槽位状态、炉体颜色（只由正确草药元素混合）、
  匹配度与成丹结论（品质/丹名由槽内草药元素构成哈希唯一决定）。
- `collection.ts`：采集目标的确定性选择（半径内最近，等距取最小下标）。
- `simulator.ts`：无 THREE/DOM 的 headless 全链路模拟器，供端到端用例驱动。

## 覆盖的风险点

- 地形：同种子逐点复现、数量恒为 25、拒绝次数如实记录、兜底路径可复现、不可行配置显式报错；
  20 组种子批量回归，逐株复核三类约束。
- 投料：同元素匹配、异元素接受并标记错误、占用槽/非法槽拒绝、草药消耗语义、
  120 种投料顺序全排列下槽位状态/炉色/匹配度一致。
- 门槛：不足 5 株拒绝进入炼丹并给出原因，补齐后放行；五行槽未满拒绝成丹。
- 成丹：5/5 仙品、3/5 灵品、1~2/5 与 0/5 凡品；相同元素组合任意顺序结论一致；
  结论不受随机数消费影响。
- 采集与帧时序：等距选择稳定；1 秒采集动画在手动时钟/帧调度下确定性地恰好完成。
- 端到端：固定种子跑完整链路并逐字节比较两次运行；4 种投料顺序结论一致。
