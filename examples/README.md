# 批量导入验收样例

`sample-import.json` 覆盖以下场景（共 15 条）：

- **重复**：相同外部标识（第 3/4、13/14 行）、相同片名+年份（第 5/6 行）、片名大小写与多余空格差异（第 2 行）。
- **与现有收藏冲突**：第 1 行个人评分/观看状态/观影日期与收藏不同（不得覆盖）；第 9 行片名年份匹配但外部标识冲突（进入待裁决）；第 15 行用缺失字段补齐已有记录。
- **字段缺失**：第 7 行缺标识且多字段非法；第 8 行仅片名+年份（标识缺失，待裁决）；第 11 行缺片名（跳过）。
- **格式异常**：非法年份、越界评分、非法观看状态、非法日期、`2023/11/02` 与 `8.5/10` 等需归一的变体。
- **非法记录**：第 12 行不是对象（跳过并说明原因）。

## 离线验收

```bash
node scripts/verify-import.ts
```

脚本在内存中模拟现有收藏，对同一份片单连续导入两次并执行人工裁决（新增/跳过/合并），
校验：归一化结果、去重合并、个人数据不被覆盖、冲突记录说明、重复导入幂等、裁决不被改写，
以及年份/评分/观看状态筛选与排序在合并后真实集合上的结论。

## 字段别名

标题（`title`/`片名`/`name` 等）、年份（`year`/`年份`）、标识（`id`/`imdbID`/`tmdbId` 等）、
评分（`rating`/`score`/`评分`）、日期（`watchDate`/`观影日期`）、状态（`watched`/`status`/`观看状态`）、
类型（`genre`/`类型`/`tags`）、来源（`source`/`来源`）均可自动识别；JSON 支持数组或
`{ "movies": [...] }` 包装结构，CSV 首行需为表头。
