# 离线回归验证

对盐引核验、铁券变更、月度汇总、混合搜索四条关键链路的口径做批量回归，
全程在本机进程内完成，不依赖浏览器、外部账号或任何在线服务。

## 运行

```bash
npm run verify
```

全部通过时退出码为 0；任一检查失败时退出码为 1，并打印失败项的编号、
口径名称及期望/实际差异，可直接定位被破坏的口径。

## 检查分组

| 编号前缀 | 口径 |
| -------- | ---- |
| SALT | 盐引核发/核验后状态、核验人、日期、留痕与当日统计自洽 |
| ERR | 不存在或终态盐引重复核验返回明确 4xx 错误且状态不被改写 |
| IRON | 铁券过期/撤销/续期与变更留痕、当前持有状态一致，重复变更结果可预期 |
| REPORT | 月度汇总总量、匹配率与底层记录一致，异常项可追溯且不虚报不漏报 |
| SEARCH | 盐引/铁券混合命中时排序口径固定，重复执行结论一致 |
| REPRO | 同种子同时钟冷启动与相同操作序列得到相同终态 |

## 可控性

验证固定使用种子 `73` 与冻结时钟 `2026-10-07T08:00:00Z`（见 `framework.ts`），
同一组输入每次运行结论一致。开发服务器同样支持受控运行：

- `MOCK_SEED`：初始 mock 数据与运行时编号的随机种子（默认 73）
- `FIXED_DATE`：冻结服务器时钟到指定 ISO 时间（默认使用系统时间）

## 结构

- `framework.ts`：进程内启动被测服务（随机端口）、断言与报告器
- `suites/`：按口径分组的检查实现，只通过 HTTP 接口与纯函数观察系统
- `run.ts`：入口，顺序执行全部分组并汇总结果
